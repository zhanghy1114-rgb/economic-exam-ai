# 中级经济师（金融）AI 备考工作区 🦞

> 一个用 **AI 智能体 + Python 工具链**驱动的中级经济师（金融专业）备考仓库：
> 976 道真题切成分章卷、错题自动归并为三版本知识点、考试前合成一本「终极一本通」——全程由 AI 导师讲授、判卷、复盘。

## 这是什么

这不是一份静态笔记，而是一套**人机协作的备考系统**：

| 组成 | 说明 |
|------|------|
| **真题资产库** | 976 题 / 118 卷，按 2026 官方章节重新切分（每卷 10 题、答案折叠），带质量巡检脚本，0 缺答案 0 残题 |
| **错题知识系统** | 每日错题归并为编号知识点，产出**记忆版**（晨读朗读）/ **秒杀版**（题眼→条件反射）/ **详细版**（五段式全解）三份联动文件 |
| **终极一本通** | 错题层 + 12 章必考骨架层 + 数字钉总表，三版本编号一一对应，考前唯一交付物 |
| **Python 工具链** | 真题提取、乱码修复、题库审计、出卷、判卷入档、进度统计，全流程脚本化可重跑 |
| **AI 导师人设** | `AGENTS.md` 定义讲授法：三层讲解（直觉→考点→验证）、错题三遍法、即时判卷模式 |

## 仓库结构

```
notes/                 学习笔记：官方大纲、必背清单、背诵手册、章节概念地图
exams/
  真题分章卷/          976 道真题按章切卷（核心资产）
  错题本/              Day N 三版本知识点 + 终极一本通三件套
  模考卷/              整卷模拟
tools/                 Python 工具链（提取/审计/出卷/判卷/统计）
progress/              进度追踪
AGENTS.md              AI 导师人设与应答策略（可直接复用到任意 AI 助手）
学习方法总纲.md         备考方法论总纲
```

## 工具链速览

```bash
python tools/extract_zhenti.py   # 从原始真题 PDF/文档提取题库（含 GBK 乱码逐段修复）
python tools/audit_bank.py       # 题库质量巡检：缺答案/残题/选项异常
python tools/build_drill.py 07   # 按章出卷
python tools/log_drill_errors.py # 判卷结果入档错题本
python tools/build_ultimate.py   # 合成考前终极一本通
```

> 全部脚本基于标准库 + 少量常见依赖，改改路径即可复用到其他科目备考。

## 怎么用

1. 把 `AGENTS.md` 喂给你的 AI 助手（WorkBuddy / Claude Code / Cursor 均可），它就变成一个懂考试规律的备考导师
2. 用 `exams/真题分章卷/` 按章刷题，错题由 AI 判卷并录入错题本
3. 每天结束后产出三版本知识点，第二天晨读「记忆版」+ 碎片时间刷「秒杀版」
4. 考前两周用 `build_ultimate.py` 合成一本通收口

## 学习方法论

- **以题带点，真题为王**：不重刷讲义，检索式刷题唤醒记忆
- **错题三遍法**：做 → 当天分级讲评录入 → 48h 变式复测销账
- **双版本记忆**：知识行打底（能换皮做题）+ 秒杀行反射（题眼→答案）
- **宁少选不错选**：多选题只勾「教材真这么写」的选项
