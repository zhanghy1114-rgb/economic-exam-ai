**中级经济专业技术资格考试 · 金融专业** 备考工作区——把一套完整的备考方法论写成 AI 能读懂的系统提示词，让 AI 助手当你的私人教练：先探底、再讲考点、讲完必练、错题自动归并成三版本知识点，进度沉淀成 Markdown，跨会话不丢失。

## 真题库与模考卷

| 特点 | 说明 |
|------|------|
| **重切而非堆放** | 原卷是整套真题，按章重新归类，刷一章只需翻一卷 |
| **双源答案校验** | 全库有 11 道原卷答案与教材口径不符，已在卷内校正并标注依据 |
| **零缺陷巡检** | 台账脚本巡检：0 缺答案、0 题型异常、0 选项不足 |

## 错题资产：三版本知识点

这是本仓库最核心的方法论沉淀——**错题不是用来焦虑的，是用来换资产的**。每天刷题结束后，把当天错题归并为编号知识点（`DN-01…`），产出三份联动文件：

| 文件 | 用途 | 形态 |
|------|------|------|
| `DayN_知识点_记忆版.md` | 每天早晨朗读 10 遍（≈15-20 min） | **知识行**（可独立成立的完整陈述，朗读打底、能换皮做题）+ **⚡秒杀行**（题眼→答案的条件反射），双行合一 |
| `DayN_知识点_秒杀版.md` | 碎片时间刷反射 | 纯"题眼→秒杀"表格，不含知识陈述，专攻条件反射 |
| `DayN_知识点_详细版.md` | 吃透用 | 五段式：知识点归属（章·考点名）→ 全解（定义/关系/例子/对比表/数字/推理）→ 考法 → 错因 → 记忆锚 |

**硬性规则**：

- 详细版**按知识点归属章排序**，「第 X 部分」章号必须与该条「知识点归属」的章号一致，不一致数量必须为 0
- 记忆版知识行不能只写"选 B"——必须能换皮做题
- 顶部四铁律固定：**T1 选非只勾❌｜T2 多选五字母逐个√×｜T3 绝对化先找反例｜T4 相等才最优**

### 考前终极一本通

错题层 + **12 章必考骨架层** + 数字钉总表，合成单份交付物（约 170 KB），三版本编号严格一一对应：

| 文件 | 体积 | 用途 |
|------|------|------|
| `金融·考前终极一本通.md` | 171 KB | 详细版，考前通读 |
| `金融·终极记忆版.md` | 40 KB | 晨读记忆 |
| `金融·终极秒杀版.md` | 17 KB | 考前最后一遍反射 |

> **为什么必须有骨架层**：错题只覆盖"已踩过的坑"，而真题稀薄的新增重点章（金融监管、金融工程等）错题条目少，必须靠大纲骨架补，否则必漏分。

```bash
git clone <本仓库地址>
# 用 Claude Code / WorkBuddy / 任何支持 AGENTS.md 的 AI 助手打开该目录
```

然后直接说人话：

| 你说 | AI 会做 |
|------|--------|
| `"今天学金融第 7 章 金融资产定价"` | 走五阶段：先探底问你会多少 → 知识地图 → 考点精讲 → 出 10 题 → 错题讲评 |
| `"来一套第 3 章的题"` | 读校正后的题库出卷，**3 题一批即时判卷** + 滚动战报 |
| `"我这一章错了 6 道"` | 按考点归因（A 类纯遗忘 1min 点破 / B 类混淆逐项验伪） |
| `"帮我生成今天的知识点"` | 归并错题 → 产出记忆版 / 秒杀版 / 详细版三份文件 |
| `"我学到哪了"` | 读进度文件 → 已完成 / 当前位置 / 下一章 / 距考试天数 |

AI 会在每次实质会话后更新 `progress/study-tracker.md` 和记忆文件，换设备、换会话都不丢进度。

### 方式二：只刷题库和模考卷

浏览器直接打开 `exams/模考卷/` 下任意 HTML，或直接读 `exams/真题分章卷/` 的 Markdown 卷。零依赖、离线可用。

### 方式三：改题库、重新生成卷子

`tools/` 是完整链路：题库数据存 JSON / Markdown，脚本负责提取、审计、出卷、判卷、合成。

```bash
python tools/extract_zhenti.py     # 从原始真题提取题库（含 GBK 乱码逐段修复）
python tools/audit_bank.py         # 题库质量巡检：缺答案 / 残题 / 选项异常
python tools/build_drill.py 07     # 按章出卷
python tools/log_drill_errors.py   # 判卷结果自动入档错题本（幂等，自动备份）
python tools/build_ultimate.py     # 合成考前终极一本通
```

改一处题库数据、跑一次脚本，卷子即更新——这是本仓库能持续迭代的基础。

## 教学方法论

核心理念：**备考不是"学知识"，是"练条件反射"。** 一切讲法都服务于"考场上能秒出答案"。

### 五阶段流程

| 阶段 | 目的 | 交互形式 |
|------|------|---------|
| **1. 探底** | 摸清你已知多少，决定讲多深 | 文字问答，学生自由表达 |
| **2. 知识地图** | 这章回答什么问题？三句话给框架 | 文字 + 导图 |
| **3. 考点精讲** | 逐个概念：先给例子 → 再落定义 → 点明考法 | 文字，配图配表 |
| **4. 练习** | 10 道真题一组，掐时 | 即时判卷 |
| **5. 错题讲评** | 按考点归类讲，录入错题本 | 分级讲评 |

### 讲评分级（省时间的关键）

| 类型 | 定义 | 处理 |
|------|------|------|
| **A 类纯遗忘** | 见过但想不起来 | 一句话点破（1 min），学生自查销账 |
| **B 类混淆** | 两个概念搅在一起 | 逐项验伪（7 min），出变式复测 |
| **整卷复盘** | 多题同源 | 按考点归类，同类只讲一道 |

> 时间不够**砍题不砍讲评**——错题讲评是唯一真正提分的环节。

### 即时判卷模式

**废除"整卷做完再判"**，改为**答完即判**：

- 每 **3 题一批**，作答后立刻逐题回判：✅/❌ + 正解 + 一句判据，再发下 3 题
- 每批结束附**滚动战报**：题号 / 你答 / 正解 / 得分 / 累计正确率 + 病因码
- 配速红线：单选 ≤ 50s、多选 ≤ 75s、10 题卷掐 10 分钟；到点即跳，**单选绝不空着**

### 吃透三级标准

| 等级 | 定义 | 检验方式 |
|------|------|---------|
| **L1 认得** | 有印象，见过 | — |
| **L2 能用** | 会做题 | 常规题 |
| **L3 能推** | 给起点能推出结论 | **变式题**：换皮不换骨 |

**遗忘 60-70% 是常态，不是失败。** 用检索式刷题唤醒，不重刷讲义。

### 错题三遍法

```
第 1 遍：做 → 当天分级讲评 → 录入错题本
第 2 遍：48h 内变式复测（换皮不换骨）
第 3 遍：销账（连续两次正确才算销）
```

## 出题铁律

经济师考试有确定标准答案，错题会直接浪费备考时间，所以出题有硬规矩：

- **单选答案唯一；多选 5 项中正确 2-4 个；题型必须显式标注**
- **大纲优先**：大纲定范围，真题定手法，不核对不出手
- **真题优先于自命题**：真题够用就用真题，真题稀薄的章节才用自命题补
- **自命题红线**：同章二次测试出**真题级自命题**，必须显式标注「**自命题·仿真**」，**严禁称真题、严禁标年份题号**
- **干扰项六大手法**：相邻概念错位 / 方向反转 / 主体错位 / 数值错位 / 半真半假长选项 / 绝对化收网
- **取非题密度约 25%**；每题标难度（基/真/拔）+ 硬上限秒数

> 错误的方法浪费的不止是时间，是信任。全库 11 处答案键与教材口径不符的题，都已在卷内标 ⚠ 并注明依据。

## 记忆锚速览

从实战中沉淀、经真题验证的触发词（完整版见 `AGENTS.md` 与 `notes/全科必背·一句话记忆版.md`）：

| 场景 | 记忆锚 |
|------|--------|
| **选非题** | 圈出"错误的是"→ 逐项 ✅/❌ → 只选 ❌（别顺手选对的） |
| **多选题** | 五个字母逐个落笔 √/×，勾前只问一句"教材写没写"；**宁少选不错选** |
| **绝对化选项** | 见"只能 / 必须 / 全部 / 唯一"→ 先找一个反例 |
| **数值比较题** | 只有**完全相等**才是"最优"，别把"接近"当相等 |
| **归属配对题** | 先写"概念 → 归属"对应表，再回头选，不凭印象直选 |
| **方向判断题** | 先判松紧（谁大谁小、升还是降），再算数值 |
