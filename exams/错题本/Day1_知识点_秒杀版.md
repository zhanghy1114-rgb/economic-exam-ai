# Day 1 秒杀版 · 题眼→答案 条件反射卡

> **用法**：不是背的，是"刷反射"的。早读时**看左边题眼，立刻说出右边答案**，说不出的打 △，按编号查详细版。编号 D1-xx 与 Day1 详细版/记忆版一一对应。
> **核心逻辑**：见词就选，不经过"理解"这层。

---

## 考场四大秒杀动作（先看，30 秒）

| 动作 | 触发条件 | 秒杀操作 |
|---|---|---|
| **T1 选非反着勾** | 题干含"错误/不属于/不包括/不正确" | 圈题干→草稿写❌→只勾错误项，勾完核对"我选的这句本身是错话吗" |
| **T2 多选逐个 √×** | 所有多选题 | 草稿写 A B C D E，每项落笔√或×并写半句理由，**说不出理由的×要当√** |
| **T3 绝对化先找反例** | 选项含"都是/所有/任何/必须/全部/完全/消除/最" | 默认错项，举出一个反例就划掉 |
| **T4 相等才最优** | 出现"最优/均衡/原则" | 正确项必含"相等"，含"大于/小于/高于"的一律错 |

## 第 1 章 社会主义基本经济制度

| 编号 | 题眼（看到这些字） | 秒杀（立刻想到/选） |
|---|---|---|
| D1-01 | "外资经济包括" | **外商独资 + 中外合资合作中的外资部分**；合资企业里的国有/集体成分→**混合所有制**（不是外资经济） |
| D1-02 | "全民所有制财产谁代表国家行使所有权" | **国务院**；国资委只是**出资人**职责（不是所有权代表） |
| D1-03 | "公有制经济包括" | **国有 + 集体 + 混合所有制中的国有和集体成分**；个体、私营=非公有制 |
| D1-04 | "公有制主体地位体现在" | 公有资产**占优势**（量+质）+ 国有经济**控制命脉起主导**；"吸纳就业大头"=**非公有制**（别安到公有制头上） |
| D1-05 | "按劳分配" | 多劳多得、**承认收入差别**；有劳动能力不劳动者**不得参与分配**（不劳不得） |

## 第 2 章 市场需求、供给与均衡价格

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D1-06 | "弹性"类题 | 永远是**价格变在前、数量变在后**；选项把方向写反（数量→价格）的一律错 |
| D1-07 | "需求交叉弹性" | 替代品=**正数**；互补品=**负数**；无关=**零**（"替正互负"） |
| D1-08 | "需求收入弹性" | 必需品 **0~1**；高档品 **>1**；低档品 **负数** |
| D1-09 | "需求价格弹性大的商品" | 奢侈品、**替代品多**、**用途多**、占支出比重大、考察时间长（替代越多越敏感） |
| D1-10 | "影响需求的因素" | 七项：偏好、收入、**自身价格**、替代品价、互补品价、预期、其他 |
| D1-11 | "影响供给的因素" | 六项：**产品价格、生产成本、生产技术、生产者预期、相关商品价格、生产要素价格**（+政策）；**消费者偏好/消费者预期=需求侧**，见"消费者"先警惕 |
| D1-12 | "保护价格"（支持价格） | **高于**均衡价→**过剩**→政府**收购**；不收购→变相降价/黑市。锚：保护的是**生产者（卖方）** |
| D1-12 | "最高限价" | **低于**均衡价→**短缺**→排队抢购/**配给制**。锚：保护的是**消费者（买方）** |
| D1-13 | "完全竞争要素市场，企业面对的要素供给曲线" | **水平线**（单个生产者是价格接受者）；要素使用原则 **MRP=MFC** |
| D1-14 | "向后弯曲的曲线" | **只有劳动供给曲线**（居民卖劳动侧）；企业面对的要素供给永远是水平线 |
| D1-15 | "生产要素需求的特征" | **引致需求**（派生于产品需求）+ **联合需求**（多种要素一起买）；要素间**既互补又可替代** |
| D1-16 | "工资上升的替代效应/收入效应" | 替代效应=**多干活**；收入效应=**多休息**；二者**始终反方向**；**收入>替代时**劳动供给曲线才后弯 |
| D1-17 | "劳动最优供给原则" | **劳动的边际效用 = 闲暇的边际效用**（T4 相等） |
| D1-18 | "拉弗曲线" | **税收收入与税率**的关系；税率过高→税基缩小→收入**反而下降**→涵养税源 |

## 第 3 章 生产和成本理论

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D1-19 | "生产函数" | **要素投入量 ↔ 最大产量**的关系；成本函数=一定产量的**最低成本** |
| D1-20 | "短期" | 只有**劳动可变**（资本固定）；三条产量曲线都以**技术不变**为前提 |
| D1-21 | "边际产量 MP 与总产量 TP" | MP>0→TP**增加**（哪怕 MP 递减）；MP=0→TP**最大**；MP<0→TP**下降** |
| D1-22 | "成本曲线起点" | **TVC 从原点出发**；**TC 从纵轴截点出发**（截距=固定成本）；平均固定成本一路递减 |
| D1-23 | "MC 穿过谁的最低点" | 从下方穿过 **AVC 和 ATC 的最低点**（不是 MC 自己的）；三个最低点顺序 **MC→AVC→ATC** |
| D1-24 | "科斯/企业本质" | 企业=**价格机制的替代物**，把交易**内部化**，目的是**节约交易费用**；目标=利润最大化（不是规模最大化） |

## 第 4 章 市场结构理论

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D1-25 | 四类市场身份证 | **完全竞争**：无数家、水平需求线、**有供给曲线**、例子=农产品；**垄断竞争**：较多家、**产品有差别**、**无供给曲线**、例子=日用消费品；**寡头**：少数几家、相互依存、例子=汽车钢铁；**完全垄断**：**独家**、**无供给曲线**、例子=公共事业 |
| D1-26 | "划分市场结构的依据" | 三依据：**产品差别程度、生产者数目、进入障碍**（"差别、数目、障碍"） |
| D1-27 | "完全垄断企业与行业需求曲线" | **完全一致**（企业=行业）；完全垄断**不存在供给曲线** |
| D1-28 | "价格由整个行业供求决定" | **完全竞争专属**；垄断竞争企业能**在一定程度上控制价格**（产品差别→定价权） |
| D1-29 | "价格歧视的基本原则" | 各分割市场**边际收益相等且等于边际成本**（T4：见"大于/小于"一律错） |
| D1-30 | "卡特尔" | 寡头**公开勾结**的协议组织，**违法** |

## 第 6 章 市场失灵和政府的干预

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D1-34 | "公共物品特征" | **非竞争性=主特征**（人人都有）；**非排他性只有纯公共物品才完全具备**；需求曲线=**纵向相加**（私人物品横向） |
| D1-35 | "纯公共物品" | 完全非竞争+完全非排他：**国防、外交、治安**；高速/医疗/教育/公园=**准公共** |
| D1-36 | "公共物品三种融资" | 政府融资（**税收**强制）缺点=**难满足多样化**；私人融资（自愿）优点=满足多样化、缺点=**数量不足结构不平衡**；补贴+私人出钱=**联合融资** |
| D1-37 | "公共物品强行排他（收费）" | →已生产的东西被闲置→违背**效率原则** |
| D1-38 | "公共物品递送典型方式" | **合同外包**（政府出资、市场生产）；供给主体=政府+非营利/慈善+市场签约者 |
| D1-39 | "帕累托最优" | =**不存在帕累托改进**（改不动了）=**经济效率**；成立条件=完全竞争四假设：**理性、信息完全、无外部性、完全竞争**（"财政补贴"是失灵后的补救，不是前提） |
| D1-40 | "外部性方向" | **正外部性**：私人**收益**<社会收益→产出**太少**→**补贴**矫正；**负外部性**：私人**成本**<社会成本→产出**太多**→**税收**矫正（动笔前默写这两行） |
| D1-41 | "信息不对称的表现" | **逆向选择**（事前，买前不知情）+ **道德风险**（事后，成交后偷懒）；"增加交易成本"=后果不是表现；"搭便车"属公共物品问题 |
| D1-42 | 反垄断三把尺 | **垄断协议看内容**（横向=竞争者之间、纵向=上下游）；**经营者集中看营业额**；**市场支配地位看份额**；安全港规则**只适用纵向垄断协议**；附条件：**结构性=剥离**（有形资产、知识产权），**行为性=承诺**（开放平台、终止排他、许可技术） |
| D1-43 | "平台用算法给无关联经营者优劣推荐" | **差别待遇**（滥用市场支配地位六型之一：不公平高低价/掠夺性定价/拒绝交易/限定交易/搭售/差别待遇） |
| D1-44 | "政府经济活动范围" | 公共物品、**矫正外部性**、维持有效竞争、调节收入分配、稳定经济；"遏制排他性/消除竞争性/保证盈利性"都不在列 |

## 第 7 章 国民收入核算

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D1-45 | "GDP 支出法" | **C+I+G+(X−M)**=最终消费+资本形成总额+净出口；**资本形成率/最终消费率用支出法算** |
| D1-45 | "GDP 收入法" | **劳动者报酬+生产税净额+固定资产折旧+营业盈余**（四兄弟：工资、税、折旧、利润）；**政府转移支付不计入 GDP**（白给的钱） |
| D1-46 | "乘数" | 购买支出乘数=**1/(1−MPC)**；税收乘数=**−MPC/(1−MPC)**（**永远为负**）；MPC=0.8→增税1元减收4元；MPC=0.6→减税1元增收**1.5**元 |
| D1-47 | "消费理论归属" | **凯恩斯=绝对收入**（**MPC<APC**，收入越高消费占比越低）；**弗里德曼=持久收入**；**莫迪利安尼=生命周期** |
| D1-48 | "影响总需求的因素" | 利率、货币供给量、政府购买、税收、预期（+价格总水平）；**技术进步影响总供给**（不是需求）；转移支付只间接影响 |
| D1-49 | "景气指标三类" | **先行**=信心开工（PMI、消费者信心）；**一致**=当下体温（GDP、工业增加值、用电量、货运量）；**滞后**=事后算账（**CPI**、企业利润、库存） |
| D1-50 | "全要素生产率" | **Ga = Gy − α·GK − β·GL**；例题 6%−0.4×6%−0.6×3%=**1.8%**（产出增长扣掉资本劳动贡献的剩余） |
| D1-51 | "十四五指标" | 单位GDP能耗**−13.5%**、单位CO₂排放**−18%**；**GDP不设年均5%硬目标**；**碳达峰=2030年前**（不是十四五内） |
