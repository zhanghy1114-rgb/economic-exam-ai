# Day 2 秒杀版 · 题眼→答案 条件反射卡

> **用法**：不是背的，是"刷反射"的。早读时**看左边题眼，立刻说出右边答案**，说不出的打 △，按编号查详细版。编号 D2-xx 与 Day2 详细版/记忆版一一对应。
> **核心逻辑**：见词就选，不经过"理解"这层。

---

## 考场四大秒杀动作（先看，30 秒）

| 动作 | 触发条件 | 秒杀操作 |
|---|---|---|
| **T1 选非反着勾** | 题干含"错误/不属于/不包括/不正确" | 圈题干→草稿写❌→只勾错误项，勾完核对"我选的这句本身是错话吗" |
| **T2 多选逐个 √×** | 所有多选题 | 草稿写 A B C D E，每项落笔√或×并写半句理由，**说不出理由的×要当√** |
| **T3 绝对化先找反例** | 选项含"都是/所有/任何/必须/全部/完全/消除/最" | 默认错项，举出一个反例就划掉 |
| **T4 相等才最优** | 出现"最优/均衡/原则" | 正确项必含"相等"，含"大于/小于/高于"的一律错 |

## 第 8 章 经济增长和经济发展理论

| 编号 | 题眼（看到这些字） | 秒杀（立刻想到/选） |
|---|---|---|
| D2-01 | "3-5年/8年/50-60年" | **基钦→朱格拉→康德拉耶夫**；"影响最大/最关注"→**中周期**；"一组总量指标"→正确项 |
| D2-02 | "低谷增长率仍为正" vs "增长率为负" | **正=增长型、负=古典型**（负了才叫古）；周期只有**扩张+收缩**两阶段 |
| D2-03 | "可持续发展/生态文明" | **绿色**｜"动力"→创新｜"公平正义"→共享｜"平衡"→协调｜"内外联动"→开放 |
| D2-04 | "增长率能全面反映发展质量和效益" | **错项**（T3）；"用不变价 GDP 计算增长速度"→对 |
| D2-05 | "经济增长的基本因素" | **两投入+两效率**：劳动数量、资本数量、劳动生产率、资本效率；见"消费结构"→错项 |
| D2-06 | "营商环境评价导向" | **市场主体和社会公众满意度**（服务对象打分） |

## 第 10 章 国际贸易理论和政策

| 编号 | 题眼 | 秒杀 |
|---|---|---|

| D2-13 | "倾销正常价值认定" | 三口径：国内可比价/第三国平均可比价/成本加合理费用；"外贸统计价格"→**错项** |
| D2-14 | "反倾销税性质" | **附加税**（不是普通进口关税）→**贸易救济措施**；税额≤倾销幅度 |
| D2-15 | "补贴按危害程度分类" | **禁止性、可诉、不可诉**；见"外贸补贴"→错项（造的） |
| D2-16 | "政府贸易干预措施" | 三堆：管进口＋推出口＋贸易救济；**外汇管制=金融管制→错项** |
| D2-17 | "非关税壁垒" | 全是**拦进口**的：配额/自愿出口限制/歧视性采购/技术标准/卫生检疫；推出口的（补贴/退税/信贷）全划掉 |
| D2-18 | "出口退税/出口信贷性质" | **间接补贴**｜"提高价格增加收入"→错项（出口靠降价） |
| D2-19 | "外贸依存度越高→进出口增长越快" | **错项**（体温计不是发动机） |

## 第 12 章 财政支出

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D2-25 | "直接刺激生产" vs "白给的钱" | 直接→**购买性**｜白给（社保/救助/贴息）→**转移性**；占比大→配置职能强=购买、分配职能强=转移 |
| D2-26 | "支配多少社会资源" | **规模**｜"各项占比"→结构｜"购买/转移构成"→经济性质 |
| D2-27 | 增速÷增速 还是 增量÷增量 | **增速→弹性系数**；**增量→边际倾向**（先问题目给的是 % 还是额） |
| D2-28 | "政府投资性支出三特点" | **长外非**（长期性、外部性、非营利性）；"强制/无偿/固定"→税收三性，划掉 |
| D2-29 | 理论-人名配对 | **扩张法则→瓦格纳｜梯度渐进/财政幻觉→皮考克｜进步/非进步部门→鲍莫尔｜发展阶段论→马斯格雷夫** |
| D2-30 | "民兵事业费"归谁 | **地方**｜武警/军工/地质勘探→**中央** |
| D2-31 | "国防项目效益评价" | **最低费用选择法**｜"不同时段不同价"→**负荷定价**｜"基本费+从量费"→**二部定价** |

## 第 13 章 财政收入

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D2-32 | "债务不合理无法按期偿还" | **债务危机（又称支付能力危机）**｜"一时周转不开"→流动性｜次贷=**综合性**案例（非独立分类） |
| D2-33 | "债券 vs 税收筹资等价" | **李嘉图等价**；"支出还是税收稳定就业等价"→错项（偷换主语） |
| D2-34 | "纳入预算管理的地方债" | 只勾**一般债务+专项债务**；显性/隐性/或有→维度不同，不勾 |
| D2-35 | 国债负担率警戒线 | **发达 60%、发展中 45%**；债务依存度 15%-20%；带"额/余额"→绝对、带"率/度"→相对 |
| D2-36 | "国债政策功能" | 三件套：**弥补赤字（最基本）+调节货币供应和利率+筹集建设资金**；"扩大就业"→错项 |
| D2-37 | "从收支环流中截取运用的资金占 GDP 比重" | **宏观税负** |
| D2-38 | "国库券是中期国债" | **错项**（国库券=**短期**最常见形式）｜"金边债券"→国债 |
| D2-39 | "非税收入含债务收入" | **错项**｜"社会缴款可自愿"→正确项｜财政收入最小口径=**仅税收** |
| D2-40 | 央地收入划分 | 增值税**五五**（75:25 旧数据陷阱）、个税**六四**；证券印花税/关税/海油资源税→**全中央**；烟叶税/耕地占用税→地方 |
| D2-41 | "所有权的单方面转移" | **无偿性**（税收本质）｜"对称性/等价有偿"→错项；三性=强制/无偿/固定 |
| D2-42 | 转嫁方式配对 | 顺链条抬价→**前转**｜压低进价→**后转**｜自己消化→**消转**｜未来税款折价→**税收资本化**；关键因素=**供求弹性** |
| D2-43 | "经常预算+资本预算两本账" | **复式预算**（编制更复杂）；"编入一个总预算"→单式 |

## 第 14 章 税收制度

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D2-44 | "区别税种的主要标志" | **课税对象**｜"征税广度"→税目｜"分级计算加总"→**超额累进** |
| D2-45 | "2009 年起增值税" | **消费型**｜"三型不包括"→资源型（造的）｜"第二大税种"→错项（第一） |

| D2-48 | 契税案例三问 | 境内✓转移✓承受方（买方）缴；"承包经营权/境外买房/租赁"→**不缴** |
| D2-49 | "房产税按价值和租金全额计征" | **错项**（原值减 10%-30%）｜纳税地点=**房产所在地**｜从租 12% |
| D2-50 | "遗产所得缴个税" | **错项**（我国没有遗产税）｜"残疾孤老烈属"→**减征**非免征｜"大病医疗"→**专项附加**扣除｜"完全按所得额纳税"→只勾**利息股息**｜"经营所得"→自行申报 |
| D2-51 | "属于财产税的" | **房产税、车船税、契税**；"负担不存在不公平性"→绝对化错项 |
| D2-52 | "高税率区间收入随税率增加而增加" | **错项**（拉弗曲线右半段是**减**）｜"禁区/涵养税源"→正确项 |
