## 七、第 24 章 描述统计

| 题眼 | 秒杀答案 |
|---|---|
| 集中趋势三件套 | 均值、中位数、众数 |
| 离散程度四件套 | 方差、标准差、极差、离散系数 |
| 反映"中心点位置" | **中位数**（选集中趋势家族） |
| 分布不对称性用啥测 | **偏态系数** |
| 中位数计算：奇数个 | 取正中间 |
| 中位数计算：偶数个 | 取中间**两位的平均** |
| 偏态/这组数据该用中位数的场景 | 偏态分布、严重左偏/右偏 |
| 分类数据用哪个代表 | **众数** |
| 众数三条性质 | 次数最多、不受极端值、**可能不唯一** |
| 均值怕什么 | 怕**极端值**（但利用了全部信息） |
| 标准差与方差关系 | 标准差＝**√方差**（反向写错） |
| 样本方差分母 | **n−1** |
| 方差越小 ⇒ 均值代表性 | **越好** |
| 哪些受极端值影响 | 均值、方差、标准差、极差 |
| 哪些**不**受极端值影响 | **中位数、众数** |
| 离散系数公式 | **标准差 ÷ 均值** |
| 离散系数好处 | 消除**量纲**和**水平**差异可用以比较 |
| 离散系数不受极端值影响？ | ❌ 仍受影响 |
| 经验法则 68 / 95 / 99 | 对应 **1 / 2 / 3** 倍标准差 |
| 跨分布比较相对排名 | 算**标准分数 Z**，谁大谁靠前 |
| Z 的性质 | 不改位置和偏度，均值为 0 标准差为 1 |
| 偏态系数 >0 / <0 | **>0 右偏；<0 左偏** |
| 偏态程度分级 | 0.5 轻 / 1 中度 / **>1 严重** |
| −0.33 / −1.5 / 10 | 轻度左偏 / 严重左偏 / 严重右偏 |
| r=0.6 判读 | **中度**线性正相关 |
| r 强弱分界 | 0.3 低度 / 0.5 中度 / 0.8 高度 |
| r 的取值范围 | [−1, 1]，不可能大于 1 |
| 两个定量变量用啥图 | **散点图** |
| 单变量分布 / 构成占比 | 直方图、箱线图 / 饼图 |
| 适合用中位数的用户数据 | 浏览时长、购买频次、年消费总额（数值型） |
| 适合用众数的用户数据 | 性别、商品类别（类别型） |

## 🎯 最后 10 秒冲刺（最容易错的前六条）

1. **时滞**：内在＝认识＋行政；外在＝决策＋执行＋效果
2. **方向**：提＋卖＝紧；降＋买＝松；准备金率在分母 ⇒ 提高了乘数就降
3. **三性**：相关、可测、可控（其它带"性"的都是造的）
4. **会议**：2023 匹配"经济＋价格预期"；2024＝更积极财政＋适度宽松货币
5. **经验法则**：68-95-99 → 1-2-3 倍标准差
6. **偏态**：正右负左，0.5 轻 / 1 中 / 过 1 严重
