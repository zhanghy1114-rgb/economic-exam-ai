# 一、第 17 章 财政政策（D3-01 ～ 06）

**D3-01｜财政之手 vs 货币之手**
- 知识行：财政政策的家产只有四样——税收政策、支出政策、预算政策、国债政策；利率政策、法定存款准备金率、公开市场操作都属于央行的货币政策工具。判据是"谁在操作"——涉及财政收支的是财政，涉及银行体系流动性的是货币。
- ⚡ 秒杀：题干问"财政政策包括"→选**税收/支出/预算/国债**；见"**准备金率/公开市场操作/再贴现/利率**"→不是财政，直接划掉

**D3-02｜五种时滞：内识行，外决执效** 🔴 今晚 4 连杀考点
- 知识行：内在时滞＝认识时滞＋行政时滞（政府内部"想"的阶段）；外在时滞＝决策时滞＋执行时滞＋效果时滞（走出政府后）。判据是"要不要过人大/立法机关"——要过的（决策）必属外在。
- ⚡ 秒杀：见"**认识＋行政**"连排→内在；见"**决策＋执行**"连排→外在；问"**纯行政/与立法机关无关**"→认识时滞

**D3-03｜汲水政策 vs 补偿政策**
- 知识行：汲水政策是萧条时期扩大公共投资诱导经济自发复苏的政策，单向、短期，前提是私人投资不足；补偿政策是政府主动逆风向调节，繁荣时紧缩、萧条时扩张，双向。
- ⚡ 秒杀：题眼"**萧条＋公共投资＋诱导复苏**"→汲水（多选时把"**短期**"一起勾上）；"**繁荣砍、萧条补**"→补偿

**D3-04｜财政政策乘数三件套**
- 知识行：财政政策乘数只有税收乘数、政府购买支出乘数、平衡预算乘数；乘数定义一律"国民收入变动÷引起它的某项变动"，永远是国民收入打头；平衡预算乘数＝1 且有扩张效应；购买支出乘数大于税收乘数。
- ⚡ 秒杀：投资乘数、对外贸易乘数→**不是**财政政策乘数；定义题里分子是"税收变动"的→错

**D3-05｜财政政策两把尺子**
- 知识行：按作用机制分为自动稳定的财政政策（如累进所得税、福利支出）与相机抉择的财政政策（如美国的罗斯福-霍普金斯计划、日本的时局匡救政策）；按调节国民经济总量分为扩张性、紧缩性、中性。
- ⚡ 秒杀：题干说"按调节总量划分"→只选**扩张/紧缩/中性**；凡是拿"总量"的帽子扣"自动稳定/相机抉择"的选项→错（维度拼接）

**D3-06｜蒙代尔政策指派**
- 知识行：财政管内部失衡（失业、通胀），货币管外部失衡（逆差、顺差）。衰退＋逆差＝扩张财政＋紧缩货币；通胀＋顺差＝紧缩财政＋扩张货币。
- ⚡ 秒杀：见"**衰退＋逆差**"→松财紧货；见"**通胀＋顺差**"→紧财松货

# 二、第 18 章 货币供求与货币均衡（D3-07 ～ 18）

**D3-07｜货币需求＝意愿＋能力**
- 知识行：货币需求由需求的意愿与需求的能力构成；货币需求理论的三家学说为剑桥学派现金余额数量说、凯恩斯货币需求理论、弗里德曼现代货币数量说。
- ⚡ 秒杀：选项出现"银行数量/发行基金/非银行数量"→划掉；货币需求＝**想持有＋持有得起**

**D3-08｜货币层次与货币供应量**
- 知识行：M0 等于流通中现金，M1 等于 M0 加单位活期存款，M2 等于 M1 加定期、储蓄等准货币；货币供应量等于现金加存款；外汇储备和黄金是央行资产，不是货币供应量构成。
- ⚡ 秒杀：问 M1→选**现金/单位活期**；问货币供应量→选**现金＋存款**；**黄金外汇排除**

**D3-09｜货币均衡＝大体一致**
- 知识行：货币均衡是货币供给与货币需求的大体一致，是动态过程，允许暂时偏离，不是完全相等。
- ⚡ 秒杀：见"**完全相等/精确一致**"→必错，选"**大体/动态**"

**D3-10｜货币失衡两大类**
- 知识行：货币失衡分为总量性货币失衡（供给总量过多或过少）与结构性货币失衡（结构错配）。
- ⚡ 秒杀：只有"**总量性＋结构性**"两项正确，见到"内部/外部/派生性"都是造的词

**D3-11｜通货膨胀两把尺子**
- 知识行：按成因分需求拉上型、成本推进型（工资推进＋利润推进）、结构型、输入型；按表现形式分公开型与抑制型（又称隐蔽型）。
- ⚡ 秒杀：题干问"**表现形式**"→只勾**公开型＋抑制型**；问"成本推进"→只勾**工资＋利润**（需求拉上是对立面）

**D3-12｜社会融资规模三堆归类**
- 知识行：直接融资是非金融企业境内股票筹资与企业债券融资；间接融资是人民币贷款和外币贷款；未贴现的银行承兑汇票属表外；其他方式三杂项是小贷公司贷款、保险公司赔偿、投资性房地产；政府债券融资包括国债和地方政府一般债、专项债。
- ⚡ 秒杀：**直接＝股＋债；贷款＝间接；未贴现票据＝表外**；见"**国企债券**"→不是政府融资（选非题的答案）

**D3-13｜紧缩三板斧与操作方向** 🔴 今晚头号病根
- 知识行：紧缩操作为提高法定存款准备金率、提高再贴现率、央行卖出有价证券；扩张操作为降低准备金率、降低再贴现率、央行买入有价证券。判断原则：钱流向银行体系是扩张，钱流出银行体系是紧缩。
- ⚡ 秒杀：**提＋卖＝紧；降＋买＝松**。看到央行"**买入**"先默念"掏钱＝放水"

**D3-14｜准备金率与货币乘数**
- 知识行：货币乘数约等于一除以法定准备金率，准备金率在分母上，准备金率提高则乘数下降、基础货币不变；存款转化为现金流出体系也会使乘数下降。
- ⚡ 秒杀：见"**提高准备金率**"→货币乘数**下降**（分母胖了分数瘦）

**D3-15｜制约派生存款＝三条漏出管道**
- 知识行：制约银行扩张信用、创造派生存款的因素是缴存中央银行法定准备金、企事业单位及社会公众缴付税款、提取现金。
- ⚡ 秒杀：派生存款只怕"**漏**"——准备金、缴税、提现；网点数量、消费意愿不漏钱

**D3-16｜费雪 MV=PT 与剑桥方程式**
- 知识行：费雪方程中 M 是货币量、V 是货币流通速度、P 是物价水平、T 是商品劳务交易量，其他因素不变时物价水平与货币量、货币流通速度成正比；费雪侧重流量、交易功能、宏观，剑桥侧重存量、资产功能、微观；两者都属传统货币数量论，现代货币主义专指弗里德曼。
- ⚡ 秒杀：**V＝Velocity＝流通速度**；把剑桥说成"现代货币主义"→错项

**D3-17｜数字货币分类与特点**
- 知识行：按发行人分为法定数字货币与私人数字货币；二者共同特点是可编程性、安全性、匿名性、高效率性；法偿性只有法定数字货币才有。
- ⚡ 秒杀：问"共同特点"→勾**编/安/匿/效**，见"**法偿性**"划掉；按发行人分类→选"**私人数字货币**"（"电子货币"是另一个维度）

**D3-18｜凯恩斯消费理论三假设**
- 知识行：凯恩斯消费理论的三个假设是边际消费倾向递减规律、平均消费倾向随收入增加而减少、消费是收入的函数。
- ⚡ 秒杀：**MPC 递减＋APC 递减＋C=f(Y)**；见"**人口构成/预期**"→是别人的假设，划掉

# 三、第 19 章 中央银行与货币政策（D3-19 ～ 27）

**D3-19｜2023 金融监管新格局**
- 知识行：二〇二三年机构改革后，国家金融监督管理总局统一负责除证券业之外的金融业监管，包括对金融控股公司等金融集团的日常监管；证监会专管证券业；人民银行负责宏观审慎、支付清算与经理国库。
- ⚡ 秒杀：**除证券业，其余都归金监总局**

**D3-20｜现代中央银行制度：一套三问**
- 知识行：问"这包括什么"答四支柱——现代货币政策框架、系统性金融风险防控体系、金融基础设施服务体系、国家金融协调合作治理机制；问"目标是什么"答四目标——币值稳定、充分就业、国际收支平衡、有效防范系统性金融风险；问"应坚持什么"答四坚持——党中央集中统一领导排第一，加完善内部治理、服务高质量发展、市场化法治化取向。
- ⚡ 秒杀：题干动词定答案——"**包括**"给四支柱（**不带微观审慎**）、"**目标**"给四大件（**不带"体系/机制"字样**）、"**坚持**"给党的领导打头（**不给财政赤字兜底**）

**D3-21｜央行两副面孔 + 经理国库**
- 知识行：作为银行的银行，央行为商业银行提供集中存款准备金、充当最后贷款人、组织全国银行间清算业务三项服务；作为政府的银行，央行为政府经理国库、代理发行国债、保管外汇和黄金储备。央行不经营一般性银行业务、不以营利为目的、具有相对独立性。我国实行经理国库而非代理国库。
- ⚡ 秒杀：**对商行＝准备金/贷款人/清算；对政府＝国库/国债/外汇黄金**；同题出现"受财政制约"与"相对独立"→互斥，必掐一个

**D3-22｜目标三层楼 + 中介目标三性** 🔴
- 知识行：货币政策传导链条是操作目标到中介目标再到最终目标，夹在操作目标和最终目标之间的变量是中介目标；中介目标选择原则是相关性、可测性、可控性；稳定物价是指保持物价总水平基本稳定。
- ⚡ 秒杀：三性只认"**相、可测、可控**"，见到"联系性/排他性/独立性/可行性"都是造的；问"**之间**"→中介目标

**D3-23｜货币政策工具三分法**
- 知识行：一般性三大法宝是法定存款准备金率、再贴现、公开市场操作；选择性工具包括不动产信用控制、间接信用指导等；非常规工具包括超低政策利率、资产购买计划、大规模再融资操作、前瞻指引；结构性工具是各类专项再贷款。
- ⚡ 秒杀：见"**专项再贷款**"→结构性；见"**QE/前瞻指引**"→非常规；**公开市场操作永远站一般性堆**

**D3-24｜传导有效性三条件**
- 知识行：货币政策有效传导取决于能对货币政策变动作出灵敏反应的经济主体、较为发达的金融市场、较高程度的利率汇率市场化。
- ⚡ 秒杀：**主体灵＋市场活＋价格放得开**；外向型程度、财政收入规模不沾边

**D3-25｜金融稳定 + 五篇大文章**
- 知识行：风险处置机制是市场化、法治化，中央银行兜底意味着道德风险必错；五篇大文章是科技金融、绿色金融、普惠金融、养老金融、数字金融；主要政策利率为七天期逆回购操作利率；强大的金融机构内涵是运营效率高、抗风险能力强、门类齐全、具有全球布局能力和国际竞争力。
- ⚡ 秒杀：处置＝**市场化＋法治化**（见"央行兜底/行政化"必错）；五篇大文章＝**科绿普养数**（"开放金融"不在列）；"货币发行权"是央行专属

**D3-26｜中国金融时间线** 🔴 D2-11 回炉失败两次
- 知识行：一九九四年第三季度起人民银行按季公布货币供应量；二〇〇七年 Shibor 上线；二〇一〇年后社会融资规模成为新指标；二〇一九年八月 LPR 报价行扩围，新增城商行、农商行、外资行、民营银行；二〇二三年十二月中央经济工作会议提出社融和广义货币供应量增速同名义经济增速、价格水平预期目标相匹配；二〇二四年十二月定调更加积极的财政政策与适度宽松的货币政策。
- ⚡ 秒杀：**1994 货币供应量｜2007 Shibor｜2010 社融｜2019 LPR 加城商农商外资民营｜2023 匹配＝经济＋价格预期｜2024 更积极财政＋适度宽松货币**

**D3-27｜汇率中间价与工具**
- 知识行：人民币汇率中间价由所有做市商报价的加权平均确定，二〇一七年五月起加入逆周期因子，形成收盘价、一篮子货币汇率变化、逆周期因子三因子模型；维护人民币汇率稳定用外汇存款准备金率。
- ⚡ 秒杀：**中间价＝加权平均＋三因子（收盘价/篮子/逆周期）**；**汇率题找"外汇"字头工具**

# 四、第 20 章 商业银行与金融市场（D3-28 ～ 37）

**D3-28｜商业银行三原则（安流盈）**
- 知识行：商业银行经营管理基本原则是安全性、流动性、盈利性；流动性原则要求保有一定比例的容易变现的资产；审慎性是监管要求，不属于经营原则。
- ⚡ 秒杀：三性＝**安流盈**；见"**审慎性/计划性**"→划掉

**D3-29｜操作风险认内鬼**
- 知识行：操作风险源于内部程序、人员、系统不完善或管理失误；市场风险源于利率汇率等市场价格波动导致资产价值变化；流动性风险源于资产流动性降低；信用风险源于交易对手违约。
- ⚡ 秒杀：见"**交易系统不完善/员工舞弊/流程出错**"→操作风险；"流动性降低"归流动性风险、"市场波动"归市场风险；题干"**利率、汇率**"双变量→选**市场风险**大类

**D3-30｜存款保险赔付**
- 知识行：同一存款人在同一家投保机构存款本金和利息合计最高偿付五十万元；应当偿付的情形是破产、撤销、被接管；合并与收购承接不赔付。
- ⚡ 秒杀：要赔＝**破产/撤销/被接管**（银行自己"没了"）；**合并收购＝搬家不赔**；限额 **50 万**

**D3-31｜保护债权论＝信息不对称双胞胎**
- 知识行：保护债权论认为由于信息不对称，金融机构存在事前逆向选择与事后道德风险两个严重问题，因此必须实施监管。
- ⚡ 秒杀：**逆向选择（事前）＋道德风险（事后）**；高负债、规模快增都不是论据

**D3-32｜政策性银行 vs 商业银行**
- 知识行：国家开发银行、中国进出口银行、中国农业发展银行是政策性银行，贯彻国家政策不以营利为目的；工商农中建交邮储等是商业银行，以营利为目的；人民银行不以营利为目的。
- ⚡ 秒杀：见"**农发行/进出口/国开**"→政策、不营利；问"以营利为目的"→选**商业银行**（如农业银行）

**D3-33｜分业监管 vs 综合监管**
- 知识行：对不同类型的金融机构分别设立不同的专门机构进行监管，就是分业（分头）监管体制；由一家机构统管则是综合或混业监管体制。
- ⚡ 秒杀：**"分设专门机构"＝分业**；"一家统管"＝综合

**D3-34｜专业化 vs 综合化银行制**
- 知识行：专业化银行制下银行只能经营吸收存款、发放短期工商贷款等传统业务；综合化银行制下银行可同时经营存贷、证券、保险、股权投资等全能业务。
- ⚡ 秒杀：**专业化＝被圈在传统存贷；综合化＝全能银行**。正着考反问着考都用这一句

**D3-35｜中间业务 vs 资产业务**
- 知识行：中间业务不动用银行自己的资金、只赚手续费，包括资金信托、融资性租赁、代理发行国债、结算代理、银行卡；资产业务动用自己的钱，包括贷款、有价证券投资、票据贴现；发行大额可转让存单属负债业务。
- ⚡ 秒杀：**凡是"代理/信托/租赁/银行卡"＝中间业务；"放款/投资/贴现"＝资产业务**

**D3-36｜同业拆借四特点**
- 知识行：同业拆借市场具有期限短、利率敏感性强、流动性高、交易方便四个特点。
- ⚡ 秒杀：口诀"**短敏流便**"，四选时别漏"**利率敏感性强**"

**D3-37｜金融市场零散锚点**
- 知识行：长期债券市场是交易十年期以上债券的市场；北京证券交易所按组织形式划分属场内交易市场；金融交易是指金融资产所有权发生变化的交易；高效率金融市场把有限的金融资源配置到效益最好的企业；商业银行办理境外直接投资人民币结算的四项义务是交易真实性和合规性审查、按规定报送信息、反洗钱、反恐融资。
- ⚡ 秒杀：**10 年、场内、所有权、金融资源、四义务（查真/报信/反洗/反恐）**

# 五、第 21-22 章 金融风险、监管与对外金融（D3-38 ～ 45）

**D3-38｜信用创造＝监管根源**
- 知识行：金融监管最早起源于对银行的监管，因为银行具有信用创造功能，会把单个机构的风险放大传导到整个体系。
- ⚡ 秒杀：问"监管先管银行源于银行的什么特性"→**信用创造**（不是营利性、不是风险管理）

**D3-39｜金融危机类型与慢变量**
- 知识行：货币危机是货币内外价值脱节引发的危机；银行危机、债务危机、流动性危机是另外三类。金融危机中金融资产价格、短期利率、商业破产数会急剧恶化，固定资产折旧率是慢变量。
- ⚡ 秒杀：见"**货币内外价值脱节**"→**货币危机**；选非题里"**固定资产折旧率**"是不会剧烈波动的那项

**D3-40｜人民币汇率制度沿革**
- 知识行：一九九四年一月一日汇率并轨，实行以市场供求为基础的、单一的、有管理的浮动汇率制；二〇〇五年七月二十一日改革遵循主动性、可控性、渐进性三原则；二〇一七年五月增设逆周期因子。
- ⚡ 秒杀：**1994 浮动（不是固定）｜2005 主控渐｜2017 加逆周期**

**D3-41｜布雷顿森林＝美元当家**
- 知识行：布雷顿森林体系实行以美元为中心的固定汇率制度，双挂钩是美元与黄金挂钩、各国货币与美元挂钩，储备货币是美元；特里芬难题指保证国际清偿力与维持对美元信心之间的两难。
- ⚡ 秒杀：凡是问"中心/储备/信心对象"→**一律美元**，黄金只是美元背后的锚

**D3-42｜特别提款权双锚**
- 知识行：特别提款权是国际货币基金组织分配给成员方的账面资产，俗称纸黄金，不能用于流通；它按一篮子货币定值，篮子由美元、欧元、人民币、日元、英镑构成。
- ⚡ 秒杀：问"定值方式"→**一篮子货币**；问"什么资产"→**账面资产**

**D3-43｜牙买加调节四路 + IMF 两手**
- 知识行：牙买加体系下经常账户失衡通过汇率机制、利率机制、国际金融市场融通、国际货币基金组织调节四种方式实现；基金组织的主要手段是指导监督逆差国与顺差国双方承担调节义务、向逆差国提供贷款。
- ⚡ 秒杀：**四路＝汇率/利率/市场融通/IMF**；**IMF 两手＝出主意＋掏贷款**；"世界银行""调整黄金价格"都是干扰

**D3-44｜储备功能边界 + 份额 25/75**
- 知识行：国际储备用于应对临时性国际收支不平衡，对付长期性国际收支赤字能力有限；国际货币基金组织份额百分之二十五以储备资产缴纳、百分之七十五以本币缴纳；储备管理的商业性原则是管理流动性风险、管理信用风险、管理市场风险、取得合理收入。
- ⚡ 秒杀：**救急不救穷**；**份额＝25 硬通货＋75 本币**；商业性＝**三风控＋赚钱**

**D3-45｜时期数 vs 时点数**
- 知识行：时期数是一段时期内累计的量，可相加、与时期长短有关，如年广告支出；时点数是某一瞬间的量，不可相加，如外汇储备余额、职工人数、城镇化率。
- ⚡ 秒杀：带"**余额/率/人数**"＝**时点**；带"**年/月＋流量词**"＝**时期**

# 六、第 23 章 统计与数据科学（D3-46 ～ 59）

**D3-46｜变量三分法**
- 知识行：分类变量只能归类别且没有顺序，如性别、学科类别、城乡属性；顺序变量的类别之间有高低先后，如受教育程度、工人工资等级；定量变量能用数字计量并可运算，如销售额、年龄、产量、天然气产量。
- ⚡ 秒杀：带"**等级/程度/级别**"＝**顺序**；带"**类别/属性**"＝**分类**；带金额数量＝**定量**

**D3-47｜总体 vs 样本**
- 知识行：总体是构成调查对象的全部单位的集合，样本是从中抽取的那部分单位；以"某数据"形式表述的选项不是单位集合。
- ⚡ 秒杀：问"总体"→找含"**所有/全部**"的那个；看到"**XX 数据**"的选项直接排除

**D3-48｜抽样方法五兄弟**
- 知识行：分层抽样先把总体切成互不重叠的层再从每层抽取；整群抽样随机抽若干群并调查群内全部单位；多阶段抽样是一级一级往下抽的系统过程；系统抽样按固定间隔抽取。
- ⚡ 秒杀：题干是"**箭头式逐级描述**（省→县→村→户）"→**多阶段**；"每省都抽"是分层、"抽中后全查"是整群

**D3-49｜概率抽样 vs 非概率抽样**
- 知识行：概率抽样的每个单位都具有已知或可计算的被抽中机会，四大方法是简单随机、分层、整群、系统；非概率抽样凭主观或方便选取，包括方便抽样、判断抽样、配额抽样、雪球抽样。
- ⚡ 秒杀：概率四大＝**随机/分层/整群/系统**；见"**方便/判断/配额/雪球**"→非概率

**D3-50｜普查 vs 抽样调查**
- 知识行：普查属于全面调查，规范化程度高并规定统一的标准调查时间，规定标准时点是为了保证普查结果的准确性；抽样调查时效性强、成本低、适用范围广。
- ⚡ 秒杀：问"全面调查"→**普查**；问"抽样优势"→**时效性强**；问"标准时点的作用"→**准确性**

**D3-51｜一手数据 vs 二手数据**
- 知识行：一手数据由使用者自己通过调查或实验取得，是社会统计的主要来源；二手数据是指他人的调查或实验数据，从统计年鉴、公报、数据库中获取，属于间接来源。
- ⚡ 秒杀：**年鉴/他人成果＝二手（间接）**；把"他人的数据"说成"直接来源"→错项

**D3-52｜描述统计 vs 推断统计**
- 知识行：描述统计用图表或综合指标刻画已有数据；推断统计是从样本推断总体，包括参数估计与假设检验。
- ⚡ 秒杀：见"**估计/推断/检验/置信**"→推断统计；见"**图表/描述**"→描述统计

**D3-53｜散点图的能力边界**
- 知识行：散点图能看出相关方向、相关强弱和是否线性，但无法判断因果关系。
- ⚡ 秒杀：见"散点图**无法**判断"→**因果关系**

**D3-54｜监督 vs 无监督 vs 降维**
- 知识行：监督学习的数据有标签，包括线性回归、逻辑回归、决策树、随机森林；无监督学习没有标签，包括聚类分析、主成分分析、因子分析、基于密度的方法；降维方法只有主成分分析法与因子分析法。
- ⚡ 秒杀：名字带"**回归/树/森林**"＝监督；"**聚类/主成分/因子/密度**"＝无监督；**降维只认主成分＋因子**

**D3-55｜回归系数 β 的含义**
- 知识行：一元线性回归中自变量 X 用于预测和解释因变量 Y，回归系数表示 X 每变动一个单位时 Y 的平均变动量；决定系数不等于相关系数。
- ⚡ 秒杀：选项"**平均**变化量"是对的，"**绝对**变化量"是错项

**D3-56｜样本量 + 无回答误差**
- 知识行：样本量取决于总体离散程度、可接受误差水平、调查经费与无回答情况；无回答误差来自被调查者拒绝、因病无法接受、不在家。
- ⚡ 秒杀：**样本量＝离散＋精度＋钱＋无回答率**；无回答三缺＝**拒答/生病/不在家**

**D3-57｜大数据 5V 与非结构化**
- 知识行：大数据具有数据量大、类型多样、处理速度快、价值密度低四个特征，起始计量单位达 PB 以上并符合一秒定律；价值密度与数据总量成反比；非结构化数据包括图像、音频、视频、PDF 文档，关系型数据库的数据表属于结构化数据。
- ⚡ 秒杀：**大数据≠结构化**；"价值密度与总量成正比"＝错；**非结构化＝图文视频音频 PDF；数据库表＝结构化**

**D3-58｜统计数据质量六标准** 🔴
- 知识行：真实性指源头数据必须符合调查对象实际情况；准确性指误差必须控制在允许范围内；完整性指全面系统反映客观实际；适用性指最大限度为用户所用并侧重用户满意度；及时性侧重统计数据生产效率；经济性侧重成本效益。
- ⚡ 秒杀：六字诀——**真源头、准误差、整全面、适满意、及效率、经成本**

**D3-59｜会计计量属性五项**
- 知识行：会计计量属性包括历史成本、重置成本、可变现净值、现值、公允价值；机会成本不是会计计量属性。
- ⚡ 秒杀：**五属性＝历成/重置/可变现/现值/公允**；只要出现"**机会成本**"直接划掉

# 七、第 24 章 描述统计（D3-60 ～ 71）

**D3-60｜集中趋势 vs 离散程度**
- 知识行：集中趋势的测度是均值、中位数、众数；离散程度的测度是方差、标准差、极差、离散系数；分布形状用偏态系数与峰度系数；相关关系用 Pearson 相关系数。
- ⚡ 秒杀：**集中＝均/中/众；离散＝方差/标准差/极差/离散系数**；问"中心点位置"→选**中位数**

**D3-61｜中位数**
- 知识行：计算中位数须先排序，样本量为奇数取正中间那个，为偶数取中间两位的平均数；中位数不受极端值影响，适合分布不对称的定量数据，但不利用全部数据信息。
- ⚡ 秒杀：**奇数取中间，偶数取中间两位的平均**；偏态找中位、对称找均值、分类找众数

**D3-62｜均值与众数**
- 知识行：均值利用全部数据信息但对极端值敏感，是对称分布的代表；众数是出现次数最多的数值，不受极端值影响、可能不唯一，适合描述分类数据。
- ⚡ 秒杀：适合用众数测度的→**分类/属性类数据**（城乡属性、性别、商品类别）

**D3-63｜方差与标准差**
- 知识行：方差是各数值与均值离差平方的平均数，样本方差的分母是样本量减一；标准差是方差的平方根并与原始数值同计量单位；二者对极端值敏感，方差越小则均值的代表性越好。
- ⚡ 秒杀：**标准差＝√方差**（反过来写就错）；**样本方差分母 n−1**；越小⇒均值代表性越好

**D3-64｜离散系数**
- 知识行：离散系数等于标准差除以均值，不受观测水平和计量单位影响，可用于不同水平或量纲数据的离散程度比较，但仍受极端值影响且不适用分类与顺序数据。
- ⚡ 秒杀：**CV＝标准差÷均值**；用于**跨量纲比较**；"不受极端值影响"是错项

**D3-65｜经验法则 68-95-99.7** 🔴
- 知识行：数据服从对称钟形分布时，约百分之六十八落在均值加减一个标准差内，约百分之九十五落在均值加减两个标准差内，约百分之九十九落在均值加减三个标准差内。
- ⚡ 秒杀：**68-95-99 对应 1-2-3 倍标准差**，换算区间为均值加减 k 倍标准差

**D3-66｜标准分数 Z**
- 知识行：标准分数等于数值减均值再除以标准差，表示数值距离均值的相对位置，它不改变原分布的偏度和位置，标准化后均值为零、标准差为一，核心用途是比较两个不同分布的相对排名。
- ⚡ 秒杀：**跨分布比排名＝算 Z，谁的 Z 大谁靠前**；Z 不改位置和形状、均 0 差 1

**D3-67｜偏态系数判读** 🔴
- 知识行：偏态系数大于零为右偏，小于零为左偏；绝对值在零到零点五之间为轻度，零点五到一为中度，大于一为严重；偏态系数用于测度数据分布的不对称性。
- ⚡ 秒杀：**正右负左；0.5 轻 / 1 中 / 过 1 严重**。例：−0.33 轻度左偏、−1.5 严重左偏、10 严重右偏

**D3-68｜Pearson 相关系数**
- 知识行：相关系数取值在负一到正一之间，等于零表示不存在线性相关，小于零为负线性相关，等于一为完全正线性相关；绝对值大于零点八为高度相关，零点五到零点八为中度，零点三到零点五为低度。
- ⚡ 秒杀：**0.3 低度 / 0.5 中度 / 0.8 高度**；r 不可能大于 1

**D3-69｜抗极端值 vs 敏感统计量**
- 知识行：中位数和众数不受极端值影响；均值、方差、标准差、极差对极端值敏感。
- ⚡ 秒杀：**抗打击＝中位数、众数；怕极端＝均值、方差、标准差、极差**

**D3-70｜图表选择**
- 知识行：呈现两个定量变量的相关关系用散点图，单个变量分布用直方图或箱线图，构成占比用饼状图或条形图，时间序列用折线图。
- ⚡ 秒杀：**两列数值＝散点图；一列分布＝直方图；占比＝饼图**

**D3-71｜中位数/众数适用数据**
- 知识行：适合用中位数测度集中趋势的是定量且可能偏斜的数据，如浏览时长、购买频次、年消费总额；适合用众数测度的是分类数据，如性别、商品类别、城乡属性。
- ⚡ 秒杀：**数字型/可能偏斜→中位数；标签/类别→众数**
