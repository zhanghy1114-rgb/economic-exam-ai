# 第一部分 · 第 28 章 会计概论（D4-01～D4-24）

## D4-01　会计规范体系：法 / 准则 / 制度 / 规则四层

- **知识点归属**：第 28 章 · 会计法规体系
- **知识点全解**：我国会计规范从高到低四层，各管一件事：

| 层级 | 名称 | 管什么 | 关键词识别 |
|---|---|---|---|
| 1（最高） | **会计法** | 会计工作的根本大法：谁来做、违法怎么罚 | "法律责任""主管部门" |
| 2 | **企业会计准则** | 确认、计量、报告的**原则**（基本准则 + 具体准则） | "确认、计量、报告" |
| 3 | **企业会计制度** | **具体操作**：会计科目及其使用方法、报表格式及编制方法 | "会计科目怎么用、报表怎么编" |
| 4 | **财务规则** | 行政事业单位的财务管理规范 | "行政事业单位""财务管理" |

  另有 **会计标准** 概念——准则、制度都算"标准"，但《会计法》《预算法》是**法律**，不属于"标准"。

- **考法**：给一段定义描述问"这是哪一层"；或问"属于会计标准的有"。前者看描述里是"原则"还是"操作"，后者见《XX法》直接排除。
- **错因**（卷01 Q10、卷07 Q8 连错）：把"会计科目及其使用方法、报表格式及其编制方法"当成会计准则；把《会计法》当"会计标准"。
- **记忆锚**：**法管罚、准则管算、制度管做、规则管事业单位**；见《会计法》跳出事外——法是法律，不是标准。

## D4-02　会计四假设

- **知识点归属**：第 28 章 · 会计基本假设
- **知识点全解**：四个假设是会计核算的前提，缺一不可：
  1. **会计主体**——为谁记账（空间范围，不等于法人）
  2. **持续经营**——假设企业不会破产清算，正常经营下去
  3. **会计分期**——把持续经营切成一段段（年/季/月）
  4. **货币计量**——用货币统一度量（我国以人民币为记账本位币）

  易混项：会计**要素**（资产负债权益收入费用利润）、会计**科目**、会计**报表**都不是假设。
- **考法**：多选题问"会计基本假设包括"。四个全给对，另塞一个"会计要素"或"权责发生制"作干扰。
- **错因**（卷02 Q10）：只过了 A、C、E 三个字母就交卷，漏 B、D，还勾了"会计要素"。T2 未执行。
- **记忆锚**：**主体、持续、分期、货币**——"谁、多久、切段、用钱量"。

## D4-03　会计核算四环节与最终产品

- **知识点归属**：第 28 章 · 会计核算
- **知识点全解**：会计核算四个环节按顺序：
  **确认 → 计量 → 记录 → 报告**

  - 确认：这笔业务算不算会计事项、算哪个要素
  - 计量：用多少钱记（五属性选一个）
  - 记录：登账、编凭证
  - 报告：编报表

  **最终产品是会计报表**（对外交付物），账簿只是中间加工站。审计不属于核算环节——它是独立鉴证业务，站在旁边看。
  常见七环节展开（含细节）：填制审核凭证 → 设置科目 → 登记账簿 → 成本计算 → 财产清查 → 编制报表。
- **考法**：问"最后一个环节"或"包括哪些"。干扰项常设"登记账簿"（倒数第二）、"审计"（不是核算）。
- **错因**（卷02 Q8、卷05 Q3）：把账簿当终点；四环节漏"确认"只勾三个。
- **记忆锚**：核算四步"**认、量、记、报**"，终点是**报表**；审计不干这活。

## D4-04　会计要素两堆：资产负债表 vs 利润表

- **知识点归属**：第 28 章 · 会计要素
- **知识点全解**：六大要素按报表分两堆，绝不能串：

| 报表 | 要素 | 性质 |
|---|---|---|
| **资产负债表** | 资产、负债、所有者权益 | **静态**（某一时点） |
| **利润表** | 收入、费用、利润 | **动态**（某一期间） |

  陷阱项：**未分配利润**虽带"利润"二字，住在**资产负债表**（属所有者权益）；**利润**才是利润表的要素。政府会计同理——资产负债表要素是资产/负债/**净资产**，收入费用表要素只有**收入、费用**。
- **考法**：问"反映经营成果的要素"（答收入费用利润）或"反映财务状况的要素"（答资产负债权益）；多选题把"未分配利润"塞进利润表堆。
- **错因**（卷03 Q10、卷05 Q4）：把"未分配利润"当经营成果要素；政府题里把"净资产"塞进收入费用表。
- **记忆锚**：**两张表两堆人**——"资负权"站静态，"收费利"站动态；未分配利润是"穿了利润衣服的权益"。

## D4-05　资产三特征（"拥有或控制"，不是"必须所有权"）

- **知识点归属**：第 28 章 · 资产的定义
- **知识点全解**：资产三个特征缺一不可：
  1. 由**过去的交易或事项**形成
  2. 由企业**拥有或控制**
  3. 预期会带来**经济利益**

  关键在"**或控制**"——融资租入固定资产、经营租入固定资产的改良支出，企业并不拥有所有权，但因能控制其带来的利益，照样确认为资产。
- **考法**：多选题给五条特征，其中一条写成"必须是企业享有**所有权**的资源"。这句是绝对化，也是与"拥有或控制"互斥。
- **错因**（卷02 Q9）：勾了 B"拥有或控制"又勾了 E"必须享有所有权"——**同题两个互斥项同时勾上，自相矛盾**。
- **记忆锚**：资产三特征"**过去＋控制＋有利益**"；见"必须所有权"必划——融资租入就是反例。

## D4-06　资产的确认时点 vs 收入的确认时点

- **知识点归属**：第 28 章 · 会计要素确认
- **知识点全解**：
  - **资产**确认：看**取得所有权（或控制权）的交易发生之时**——东西到手/控制权转移那一刻
  - **收入**确认：看**取得收取款项的权利**形成、且经济利益很可能流入
  - **负债**确认：**现时义务**形成之时（过去交易导致的、将来必须偿付）

  三者对应三个不同的"那一刻"，考点就是把收入的时点安到资产头上。
- **考法**：单问"资产应在何时确认"，干扰项给"取得收入权利时""实际收到款项时"。
- **错因**（卷01 Q6）：选了"取得收入权利"——那是收入确认的口径。
- **记忆锚**：**资产看东西到手，收入看权利到手，负债看义务上身**。

## D4-07　五计量属性全表（历史成本是默认项）

- **知识点归属**：第 28 章 · 会计计量
- **知识点全解**：五种计量属性，一句一辨识：

| 属性 | 定义 | 何时用 |
|---|---|---|
| **历史成本** | 取得时**实际支付**的金额 | **一般应当采用**（默认项） |
| **重置成本** | **现在重新购买**相同或相似资产需支付的金额 | 盘盈固定资产（不知原价） |
| **可变现净值** | 估计售价 − 至完工估计成本 − 估计销售费用 − 相关税费 | 存货期末减值 |
| **现值** | 未来净现金流入**折现**后的金额 | 长期资产/负债 |
| **公允价值** | 公平交易中**脱手价**（自愿双方） | 金融资产等 |

  ⚠️ 主体错位陷阱：**"现在重新购买"对资产，"现在偿付债务"对负债**——问资产别选负债口径。
- **考法**：单问"一般应当采用哪种"（答历史成本）；或给一段描述问是哪种属性。带"减法三项"的必是可变现净值。
- **错因**（卷01 卷 1 相关题、卷05 Q1、卷07 Q1）：默认项误选重置成本；把负债的重置成本口径安到资产上。
- **记忆锚**：五属性"**历史是默认、重买对资产、重还对负债、售价减三项=可变现、未来折现=现值、脱手价=公允**"。

## D4-08　存货期末计量：成本与可变现净值孰低

- **知识点归属**：第 28 章 · 存货计量
- **知识点全解**：
  - **初始计量**：按**成本**入账（采购价 + 运输费 + 装卸费等）
  - **期末计量**：按**成本与可变现净值孰低**——谁低用谁，这是谨慎性在存货上的落地

  跌价了就把账面价值减到可变现净值，差额计提**存货跌价准备**（备抵科目）。
- **考法**：问"期末按什么计量"，干扰项给"历史成本""公允价值"。
- **错因**（卷03 Q2、卷05 Q7）：两次都选历史成本——把初始计量当期末计量。
- **记忆锚**：存货"**入账用成本、期末比孰低**"；比出低的就是谨慎性。

## D4-09　流动资产 vs 非流动资产（看名字就能判）

- **知识点归属**：第 28 章 · 资产的分类
- **知识点全解**：
  - **流动资产**（一年内变现或耗用）：货币资金、交易性金融资产、应收票据、应收账款、预付款项、**存货**
  - **非流动资产**：长期股权投资、**开发支出**、固定资产、**在建工程**、**无形资产**、长期待摊费用、递延所得税资产

  判据：名字里带"**长期 / 固定 / 在建 / 无形 / 开发 / 递延**"→ 非流动；带"**货币 / 交易性 / 应收 / 预付 / 存货**"→ 流动。
- **考法**：多选"属于非流动资产的有"，塞一个"应收票据"或"存货"作干扰。
- **错因**（卷02 Q4、卷06 Q7）：把"长期债券投资"当流动（名字带长期却选了）；漏"长期股权投资""开发支出"。
- **记忆锚**：**"长固在建无开递"是非流动七字诀**；存货是流动资产的招牌。

## D4-10　资产负债表的格式：账户式（左资产右权益）

- **知识点归属**：第 28 章 · 会计报表
- **知识点全解**：
  - **账户式**（我国采用）：左右排，**左方列资产，右方列负债和所有者权益**——像 T 型账户
  - **报告式**：上下排，先资产、再负债、最后所有者权益

  排列规则：资产按**流动性**（变现速度快慢）自上而下，越靠上越好变现；负债按**到期日远近**排列，越靠上越早到期。
- **考法**：问"我国采用什么格式"（答账户式）；问"资产类项目排列顺序"（答变现速度快慢）。
- **错因**（卷01 Q3、卷07 Q9）：明知账户式是"左资产"仍选右方（E1 方向反转）；把排列顺序记成"取得时间先后"。
- **记忆锚**：账户式"**左资产、右负债权益**"；资产看"**多快变成钱**"，负债看"**多久要还钱**"，"取得时间"是明细账逻辑不是报表逻辑。

## D4-11　财务比率全家桶（分子定名法）

- **知识点归属**：第 28 章 · 财务报表分析
- **知识点全解**：

| 指标 | 公式 | 看什么 |
|---|---|---|
| **流动比率** | 流动资产 ÷ 流动负债 | 短期偿债（含存货） |
| **速动比率** | **（流动资产 − 存货）÷ 流动负债** | 短期偿债（剔存货） |
| 现金比率 | 现金 ÷ 流动负债 | 最严的短期偿债 |
| **资产负债率** | 负债总额 ÷ 资产总额 | 长期偿债/杠杆 |
| **产权比率** | 负债 ÷ **所有者权益** | 资本结构 |
| **资本保值增值率** | **期末所有者权益 ÷ 期初所有者权益 × 100%** | 资本保全 |

  **分子定名法**：分子是什么就叫什么比率。分子是流动资产=流动比率；分子是速动资产=速动比率；分子是负债、分母是权益=产权比率。
  ⚠️ **资本保值增值率必须是"期末权益 ÷ 期初权益"**，先减负债得权益，再相除。题目给两期资产+两期负债共 4 个数字，**只用 2 个相除的必错**。
- **考法**：直接问公式；或给 4 个数字算保值增值率（干扰项设"资产÷负债""负债÷资产"）。
- **错因**（卷01 Q7、卷06 Q6）：把"流动资产÷流动负债"记成产权比率；算保值增值率时用 2600÷1600（资产÷负债）得 162.5%，而正确是 (2600−1600)÷(2000−1200) = 125%。
- **记忆锚**：**分子定名**；保值增值率"**先减负债、再期末比期初**"；只用了 2 个数字的算法一定是坑。

## D4-12　会计等式的要素变动（还债＝资产负债双降）

- **知识点归属**：第 28 章 · 会计等式
- **知识点全解**：基本等式 **资产 = 负债 + 所有者权益**。四类业务：

| 业务 | 变动 |
|---|---|
| 赊购存货 | 资产↑ 负债↑（同增） |
| **支付应付账款** | **资产↓ 负债↓（同减），权益不动** |
| 收回应收账款 | 资产一增一减（内部搬家） |
| 所有者投入 | 资产↑ 权益↑ |

  还债不产生损益，所以**所有者权益纹丝不动**。权益变动只有三个来源：业主投入/撤资、当期利润、直接计入权益的利得损失。
- **考法**：给一笔业务问"哪些要素变动"。干扰项常把"权益增加"塞进还债业务。
- **错因**（卷01 Q8）：选"负债减少+所有者权益增加"——那是**债转股/债务豁免**才有的效果。
- **记忆锚**：**还债＝资产负债双降，权益看戏**；权益只有在"投钱、赚钱、直接记权益"时才动。

## D4-13　谨慎性 vs 实质重于形式（最容易互串的一对）

- **知识点归属**：第 28 章 · 会计信息质量要求
- **知识点全解**：
  - **谨慎性**：不高估资产或收益、不低估负债或费用。落地动作：**加速折旧、计提减值准备、存货跌价准备、预计负债**。
  - **实质重于形式**：按**经济实质**而非法律形式处理。典型：**融资租入固定资产当自有资产**、**售后回购不确认收入**、附回购条件的销售不算销售。
  - 其他六项：可靠性、相关性、可理解性（简明易懂）、可比性、及时性、重要性。
- **考法**：问"加速折旧体现哪个质量要求"（谨慎性）；问"融资租入按自有资产核算体现哪个"（实质重于形式）。
- **错因**（卷04 Q2）：加速折旧选了"实质重于形式"。
- **记忆锚**：**见"多提/少估"→谨慎；见"法律形式≠经济实质"→实质重于形式**。加速折旧不提"形式"，只提"别高估"。

## D4-14　重要性：只看性质和金额两面

- **知识点归属**：第 28 章 · 会计信息质量要求
- **知识点全解**：重要性判断两个维度：
  1. **性质**——事项本身是否影响决策（如舞弊、关联交易，金额小也重要）
  2. **金额**——占报表项目的比重是否够大

  **仅此两项**。教材没有"发生时间""发生地点"这类第三维。
- **考法**：单选问"从哪几方面判断"，干扰项把两项扩成三方面（加"时间"）。
- **错因**（卷05 Q9）：选了含"发生时间"的三方面选项。
- **记忆锚**：重要性"**看性质、看金额**"，仅两项；凡出现"三方面"先数项。

## D4-15　对外报表四表一注

- **知识点归属**：第 28 章 · 会计报表体系
- **知识点全解**：企业对外提供的财务报表至少包括：
  1. **资产负债表**
  2. **利润表**
  3. **现金流量表**
  4. **所有者权益变动表**
  5. **附注**

  不对外：**银行存款余额调节表**（核对工具）、试算平衡表（内部检查）、成本计算表。
- **考法**：多选"对外报表至少包括"，塞"存款余额调节表"作干扰。
- **错因**（卷05 Q2）：只勾了两个，漏现金流量表和所有者权益变动表。
- **记忆锚**：对外四表"**资、利、现、权**"＋附注；调节表、试算表都在门内，不对外。

## D4-16　现金流量表：只认跨越现金池边界的进出

- **知识点归属**：第 28 章 · 现金流量表
- **知识点全解**：现金流量表记录**现金及现金等价物**的流入流出。判据是"**是否跨越现金池边界**"：
  - **不算流量**：从银行提取现金（银行存款→库存现金，池内搬家）、以固定资产清偿债务（非现金交易）、以固定资产对外投资（非现金交易）
  - **算流量**：销售收现、购买商品付现、借款收到现金、偿还债务付现

  三分类：经营活动、投资活动、筹资活动。
- **考法**：多选"不会影响现金流量表的业务"，塞"提现"和"以物抵债"。
- **错因**（卷03 Q1）：漏了"从银行提取现金"——误以为动了现金就算流量。
- **记忆锚**：现金池"**内部搬家不算、以物换物不算**"；只有跨越边界（收到钱/付出钱）才算流量。

## D4-17　备抵科目：只有"三产"带备抵

- **知识点归属**：第 28 章 · 资产负债表编制
- **知识点全解**：报表上按"**总账余额 − 备抵科目余额**"填列的资产只有三个：

| 资产 | 减什么备抵 |
|---|---|
| **固定资产** | 累计折旧 + 固定资产减值准备 |
| **无形资产** | 累计摊销 + 无形资产减值准备 |
| **在建工程** | 在建工程减值准备 |

  负债类按总账余额**直接填**（长期借款仅把一年内到期部分重分类到"一年内到期的非流动负债"，不涉及备抵）。
- **考法**：多选"需要减去备抵科目后填列的项目"，塞"长期借款""应收账款"作干扰（应收账款按净额填但一般算减值，不属"三产"备抵口径）。
- **错因**（卷05 Q10）：把"长期借款"勾进来；把资本公积当备抵。
- **记忆锚**：备抵只认"**固定、无形、在建**"三产；负债不玩备抵。

## D4-18　所有者权益的构成：留存收益只有两项

- **知识点归属**：第 28 章 · 所有者权益
- **知识点全解**：所有者权益 = **实收资本（股本）+ 资本公积 + 其他综合收益 + 留存收益**，其中：

  **留存收益 = 盈余公积 + 未分配利润**（就两项）

  - 实收资本、资本公积是**投入**的（业主放进来、股本溢价）
  - 留存收益是**留下**的（赚了没分掉）
  - **利润**是利润表概念，不是权益项目；"未分配利润"才是权益里的留存部分
- **考法**：多选"留存收益包括"，塞"利润""资本公积""实收资本"。
- **错因**（卷08 Q2 已答对，巩固）：排除"利润"和"资本公积"。
- **记忆锚**：留存收益"**盈公 + 未分配**"两项；**投入的（实收/资本公积）≠ 留下的（留存收益）**。

## D4-19　政府会计：双报告 + 两表分家

- **知识点归属**：第 28 章 · 政府会计
- **知识点全解**：
  **双报告**：
  | 报告 | 反映什么 | 基础 |
  |---|---|---|
  | **政府财务报告** | **财务状况、运行情况**（资产/负债/净资产/收入/费用） | 权责发生制 |
  | **政府决算报告** | 年度**预算收支执行结果** | 收付实现制 |

  **两表分家**：
  - 资产负债表要素：**资产、负债、净资产**
  - 收入费用表要素：**只有收入、费用**

  **政府资产四特色**（考到必勾）：**文物文化资产、政府储备资产、保障性住房、公共基础设施**。
- **考法**：问"综合反映预算收支执行结果的文件"（决算报告）；多选"政府会计主体资产"（四特色一定要勾）；多选"收入费用表要素"（只有两项）。
- **错因**（卷05 Q4、卷06 卷、卷07 Q3）：把净资产塞进收入费用表；把"预算收支执行结果"答成财务报告；政府资产题里勾了"应付款项"（那是负债）。
- **记忆锚**：见"**预算**"→决算报告、见"**财务状况**"→财务报告；政府资产四特色"**文物、储备、保障房、基础设施**"；"应付/应交"字头一律负债。

## D4-20　政府非税收入：收、罚、专、资 + 基金

- **知识点归属**：第 28 章 · 政府收入分类
- **知识点全解**：政府收入四块预算：**一般公共预算（税收 + 非税）、政府性基金预算、国有资本经营预算、社会保险基金预算**。

  **非税收入**包括：
  - **行政事业性收费**收入
  - **专项**收入
  - **罚没**收入
  - **国有资本经营**收入
  - 国有资源（资产）有偿使用收入
  - 政府性基金收入

  **不属于非税收入**的：
  - **债务收入**（国债、地方债）——借来的钱要还本付息，政府收入里单列
  - **彩票销售收入**——进政府性基金的是**彩票公益金**，销售收入本身不是非税收入
- **考法**：多选"属于非税收入的有"，塞"债务收入"；或选非"不包括"，塞"行政事业性收费"（这是正解项，不该勾）。
- **错因**（卷03 Q5 选非勾了正解项、卷08 Q1 多勾债务收入）：边界不清——知道有哪些，不知道哪些不在里面。
- **记忆锚**：非税收入"**收、罚、专、资 + 基金**"；见"**债务/借款/发债**"一律不勾——**借来的不是挣来的**。

## D4-21　中央固定收入 vs 共享税

- **知识点归属**：第 28 章 · 政府收入（税收划分）
- **知识点全解**：
  - **中央固定收入**：**消费税、关税、海关代征的消费税和增值税、证券交易印花税、车辆购置税**
  - **共享税**：**增值税**（中央地方分成）、企业所得税、个人所得税
  - 非税收入不属于"税收"
- **考法**：多选"属于中央固定收入的有"，塞"增值税"（共享）或"建设用地有偿使用收入"（非税）。
- **错因**（卷03 Q7）：漏了证券交易印花税；增值税误判。
- **记忆锚**：中央独吞"**消费税 + 关税 + 车购税 + 证券交易印花税**"；**增值税永远共享**。

## D4-22　收入分配：居民收入四源 + 私营企业主两项

- **知识点归属**：跨章（第 28 章卷内混入，实为收入分配考点）
- **知识点全解**：
  **居民收入四条线**：
  1. **劳动收入**（按劳动要素获得的报酬）
  2. **财产性收入**（按资产分配获得：利息、租金、红利、专利收入）——靠"让渡资产"取得，人不在经营现场
  3. **经营性收入**（自己下场经营所得）
  4. **转移性收入**（政府支付的保障性收入、救济、补贴）——别人给的

  另：按投入资本等生产要素分配获得的报酬也计入居民收入。
  **不算收入**：银行贷款（负债，借来要还）。

  **私营企业主收入**（教材口径两项）：
  - 作为**管理者获得的劳动报酬**
  - 根据**投入的资本获得的投资报酬**
  - 不含财产性收入（那是让渡资产的收益）、不含转移性/再分配性收入（那是别人给的）
- **考法**：多选"居民获得的收入有"；多选"私营企业主收入主要有"。
- **错因**（卷06 Q2 漏保障性收入、卷06 Q8 多勾财产性收入）：只想到"要素分配"一条线，忘了"再分配"；把"投资报酬"和"财产性收入"混为一谈。
- **记忆锚**：收入四源"**劳、财、经、转**"；私营企业主"**劳动 + 投资**"两项，是"人在场"的钱；财产性收入是"人不在场、钱在场"。

## D4-23　重置成本 / 可变现净值的口径边界（资产 vs 负债）

- **知识点归属**：第 28 章 · 会计计量（与 D4-07 互为补充）
- **知识点全解**：
  - **资产**的重置成本：现在**重新购买**相同或相似资产需支付的金额
  - **负债**的重置成本：现在**偿付债务**所需支付的金额
  - **资产的公允价值**：公平交易中**出售**该资产能收到的金额（脱手价）
  - **负债的公允价值**：公平交易中**转移**负债需支付的金额
  - **可变现净值**：估计售价 − 至完工估计成本 − 估计销售费用 − 相关税费

  记忆要点：同一属性用在资产和负债上，措辞完全不同（买 vs 还、卖 vs 转）。题干问"资产"就只认"买/卖"，出现"偿付债务"直接排除。
- **考法**：单选问"资产的重置成本是指"，干扰项给负债口径。
- **错因**（卷05 Q1）：问资产的重置成本，选了"现在偿付债务所需支付的现金"。
- **记忆锚**：**资产端用"重买/卖出"，负债端用"重还/转移"**——主体错位一眼识破。

## D4-24　跨章混入题速览（金融监管 / 央行表 / 巴塞尔 / 明斯基 / 分类回归 / 双随机 / WTO）

- **知识点归属**：跨章（28 章综合卷串板题，属金融 8/11/12 章、统计 26 章、市场监管、对外经济）
- **知识点全解**：
  1. **金融监管总局五大监管**（金融 12 章）：2023 年组建，强化「**机构监管、行为监管、功能监管、穿透式监管、持续监管**」。审慎监管**不在这五类**（那是银行业传统监管手段）。
  2. **央行资产负债表**（金融 11 章）：**资产方**=对政府债权、对其他存款性公司债权、对其他非金融性公司债权、国外资产；**负债方**=储备货币、发行债券、政府存款、国外负债、自有资金。**"债权"永远在资产方；"存款/债券/储备货币"永远在负债方**（一字之差：权/券）。
  3. **巴塞尔Ⅲ计量修订三目标**（金融 12 章）：**可比性、简单性、风险敏感度**（"可比、简单、敏感"）。
  4. **明斯基金融不稳定性假说**（金融 8 章）：根源是**部分准备金制度**（内生不稳定）；克瑞格是"安全边界说"。
  5. **监督学习两支**（统计 26 章）：**分类**（离散标签）——支持向量机、随机森林、决策树；**回归**（连续数值）——线性回归、非线性回归。名字带"回归"必属回归支。
  6. **"双随机、一公开"**（市场监管）：随机抽取**检查对象** + 随机选派**执法检查人员** + **抽查事项及查处结果**向社会公开。**检查时间不随机**。
  7. **WTO 正常价值三标准**（对外经济）：**原产国标准、第三国标准、结构价格**。结构价格=生产成本 + 合理的销售费用、管理费用、一般费用 + 利润。凡压成"成本 + 某百分比"的都是错项。
- **考法**：这些题在会计卷里出现时，考的仍是原章知识点——**看到题干不像会计，先判它属于哪一章，用那章的规则答**。

- **记忆锚**：串板题"**先认章、再用该章规则**"，别在会计思维里硬套。

# 第二部分 · 第 25-27 章 统计（D4-25～D4-48）

## D4-25　估计量的三大性质：无偏 / 有效 / 一致

- **知识点归属**：第 25 章 · 抽样调查 · 估计量的性质
- **知识点全解**：评价一个估计量好不好，看三条，三者各管一件事：

| 性质 | 判据 | 一句话 |
|---|---|---|
| **无偏性** | 所有可能样本估计值的**平均值 = 总体参数** | 平均下来不偏不倚 |
| **有效性** | **方差越小越有效** | 波动小的更精准 |
| **一致性** | 随**样本量增大**，估计值趋向总体参数 | 样本越大越靠得住 |

  三者互不替代：无偏说的是"平均准"，有效说的是"波动小"，一致说的是"样本量越大越准"。
- **考法**：单选给一句定义问是哪条性质；或给 V(θ₁) 与 V(θ₂) 的大小问谁更有效。
- **错因**（卷01 Q2、Q6）：把"n 增大趋向参数"（一致性）答成无偏性；V(θ₁)＞V(θ₂) 时选错方向。
- **记忆锚**：**无偏看平均、有效看方差、一致看样本量**。见 V( ) 比较先画箭头：**大 V = 差 = 无效**。

## D4-26　抽样误差 vs 非抽样误差

- **知识点归属**：第 25 章 · 抽样调查 · 误差分类
- **知识点全解**：
  - **抽样误差**：由**随机因素**产生（抽到哪些样本是随机的），不可避免但可计算、可通过增大样本量缩小
  - **非抽样误差**：抽样以外的一切误差，包括
    - **抽样框误差**（名单不全/重复/过时）
    - **无回答误差**（**拒答**、**不在家**）
    - **计量误差**（**提供虚假信息**、计算错误、问卷诱导、记录错误）

  判据：**只有"随机性"归抽样误差**，其余全归非抽样误差。
- **考法**：多选"属于非抽样误差的有"，塞"随机因素"作干扰；或选非"不属于非抽样误差"。
- **错因**（卷01 Q5）：漏"拒绝回答"和"提供虚假信息"两个典型非抽样误差。
- **记忆锚**：非抽样误差"**框、答、量**"（抽样框 / 无回答 / 计量）；**唯"随机"二字归抽样误差**。

## D4-27　分层抽样 vs 整群抽样（一对镜像，务必背反）

- **知识点归属**：第 25 章 · 概率抽样方法
- **知识点全解**：

| | **分层抽样** | **整群抽样** |
|---|---|---|
| 怎么分 | 把总体按某标志分成**层**，每层都抽 | 把总体分成**群**，只抽**部分群**，群内全查 |
| 理想结构 | **层内差异小、层间差异大** | **群内差异大、群间差异小** |
| 误差 | **可以降低**抽样误差 | 群内同质（差异小）⇒ **误差大** |
| 成本 | 需要**辅助信息**才能分层 | **成本低、抽样框编制简单、实施效率高** |
| 抽样框 | 需要 | 只需群的名单（**编制简单**） |

  原理：分层是"同类归堆，每堆都取样"，堆内越同质越好；整群是"抽中一个群代表全体"，所以群内要杂（越像总体越好），群间要像（抽哪个都差不多）。
- **考法**：问"分层抽样的优点"（降低抽样误差）；问"整群抽样的特点"（成本低、框简单）；问"分层分层的原则"（层内小、层间大）。
- **错因**（卷01 Q7、Q9）：整群四特点全记反（把成本高、框复杂当特点）；分层题选"不需要辅助信息"（恰恰需要）。
- **记忆锚**：**分层"层内小、层间大"求精准；整群"群内大、群间小"求省事**——一个花小钱办大事，一个省事但误差大。

## D4-28　等距（系统）抽样的间隔公式

- **知识点归属**：第 25 章 · 概率抽样方法
- **知识点全解**：等距（机械/系统）抽样：把总体单位按某标志排序，按**固定间隔**抽取。

  **抽样间隔 = 总体规模 ÷ 样本量**（即 N/n）

  例：总体 12000 家单位，抽 200 家 → 间隔 = 12000 ÷ 200 = 60，即每 60 家抽 1 家。
  首个样本在 1~间隔 之间随机确定，之后每隔一个间隔抽一个。
- **考法**：给总体规模和样本量算间隔；或问"等距抽样的前提"（需要排序名单）。
- **错因**：卷02 已答对（间隔 = 总体规模 ÷ 样本量），保持。
- **记忆锚**：**间隔 = N ÷ n**；先算间隔，再定起点。

## D4-29　相关分析 vs 回归分析（谁依靠谁）

- **知识点归属**：第 26 章 · 回归分析 · 基本概念
- **知识点全解**：

| | 相关分析 | 回归分析 |
|---|---|---|
| 研究什么 | 变量间相关的**程度**和方向 | 变量间数量关系的**具体形式** |
| 分不分主次 | **不分**自变量/因变量 | **分**自变量与因变量 |
| 能否推测 | **不能** | **能**（用 X 推测 Y） |
| 相互关系 | **相关分析需要依靠回归分析**来表明数量相关的具体形式 | **回归分析需要依靠相关分析**来表明相关程度 |

  教材原话就是这一句"相关分析需要依靠回归分析来表明现象数量相关的具体形式"，反向同理。
- **考法**：单选问两者关系；干扰项常设"完全相关时才能做回归分析"（绝对化，不完全相关也能做）。
- **错因**（卷01 Q5）：没拦"完全相关才可以进行回归分析"这个绝对化错项。
- **记忆锚**：**相关看"程度"、回归看"形式"**；相关不分因果，回归分主次；见"**完全相关才能**"直接划。

## D4-30　决定系数 R²：分子分母都是 Y

- **知识点归属**：第 26 章 · 回归分析 · 拟合优度
- **知识点全解**：

  **R² = 回归平方和 ÷ 总平方和 = 模型能解释的 Y 的变化 ÷ Y 的总变化**

  分子分母**都是因变量 Y**，与 X 的"总变化"无关。含义：因变量的变化中有多大比例能被模型解释。
  - R² = 0：一点都解释不了
  - R² = 1：**全部解释**，残差为 0，拟合完美
  - R² = 0.64：解释 64% 的 Y 变化
- **考法**：单问 R² 的含义；给 R²=1 问结论（答"能解释因变量的所有变化"）；给 R²=0.64 问"解释了多少"（答 64%）。
- **错因**（卷01 Q1、卷02 Q2）：把分母写成"自变量总变化"；R²=1 时选成"自变量对因变量没有显著影响"（方向反转）。
- **记忆锚**：**R² 上下都是 Y**（Y 的解释 ÷ Y 的总量）；取值 0→1，**0＝全不会，1＝全会**，别往"没影响"上想。

## D4-31　相关系数 r = ±√R²（正负看斜率）

- **知识点归属**：第 26 章 · 回归分析 · 相关系数与决定系数的关系
- **知识点全解**：一元线性回归中：

  **r = ±√R²**，符号与回归系数 β₁ 的符号一致（斜率为正取正，为负取负）

  例：R² = 0.64 → |r| = 0.8；若 Ŷ = −50 + 0.8X（斜率为正）→ r = +0.8。
  - 常见错误：把 r 直接当成 R²（0.64），少开一次方
- **考法**：给 R² 求 r；给回归方程和 R² 求 r（含符号）。
- **错因**（卷02 Q1）：选项 C 写"r = 0.64"是错的（应为 0.8），你划对了✅——保持。
- **记忆锚**：**R² 是 r 的平方，所以 r 要开根号**；**符号跟斜率走**，斜率为负则 r 为负。

## D4-32　随机误差项 ε 的含义

- **知识点归属**：第 26 章 · 回归分析 · 一元线性回归模型
- **知识点全解**：一元线性回归模型 Y = β₀ + β₁X + ε 中：

  **ε = 除 X 与 Y 的线性关系之外，其他随机因素对 Y 的影响**（模型解释不了的那部分）

  - **β₀ + β₁X**：X 的线性影响，**能解释的部分**
  - **ε**：残差项，**解释不了的部分**（含测量误差、遗漏变量、随机波动）
  - 假定：E(ε)=0、方差恒定、相互独立
- **考法**：单问"ε 反映什么"，干扰项给"由 X 变化引起的 Y 变化"（那是 β₁X 的活）。
- **错因**（卷01 Q3 错，卷02 Q3 回炉成功✅）：曾把 ε 说成"X 引起的 Y 变化"。
- **记忆锚**：**β₁X 是"说得清"的，ε 是"说不清"的**；ε 永远代表"线性关系之外"。

## D4-33　回归"模型" vs 回归"方程"（差一个 ε）

- **知识点归属**：第 26 章 · 回归分析 · 模型形式
- **知识点全解**：

| 提法 | 表达式 | 关键 |
|---|---|---|
| **理论模型** | **Y = β₀ + β₁X + ε** | **含随机误差项 ε** |
| **回归方程（期望形式）** | **E(Y) = β₀ + β₁X** | **不含 ε**，是期望值 |
| 估计的回归方程 | **Ŷ = β̂₀ + β̂₁X** | 用样本估计值（带帽子） |

  判据：**见"模型"找 ε；见"方程"找 E(Y)**。
- **考法**：单问"一元线性回归方程的形式"，四个选项里只有一个带 E(Y)。
- **错因**（卷01 Q8）：问"方程"却选了含 ε 的模型式。
- **记忆锚**：**模型带 ε，方程带 E(Y)**——"方程"是把随机性抹掉之后的期望关系。

## D4-34　最小二乘法：残差平方和最小

- **知识点归属**：第 26 章 · 回归分析 · 参数估计
- **知识点全解**：最小二乘法的原理是使

  **Σ(观测值 − 估计值)² = Σ(残差)² 达到最小**

  - "二乘" = 平方；"最小" = 残差平方和最小
  - 不是"残差和最小"（正负相消会得 0），不是"标准差最小"，不是"均值相等"
  - 对 Ŷ = β̂₀ + β̂₁X，解出来的 β̂₁ = 协方差 ÷ X 的方差
- **考法**：单问"最小二乘法的基本思想"，干扰项设"残差和为零""残差绝对值最小""均值相等"。
- **错因**（卷01 Q9）：选错。
- **记忆锚**：**二乘＝平方，最小＝平方和最小**；先平方再求和，正负不抵消。

## D4-35　t 检验 vs F 检验（分工不同）

- **知识点归属**：第 26 章 · 回归分析 · 显著性检验
- **知识点全解**：

| 检验 | 检验什么 | 原假设 |
|---|---|---|
| **t 检验** | **单个回归系数**是否显著（该自变量对因变量有无显著影响） | H₀: β₁ = 0 |
| **F 检验** | **整个回归模型**是否显著（模型整体有无解释力） | H₀: 所有系数同时为 0 |

  一元回归中两者等价（结论一致），但**用途表述不同**：问"某个自变量有无显著影响"答 t 检验，问"模型整体是否显著"答 F 检验。
  正态性、线性、方差齐性都是**假设前提**，不是检验的目的。
- **考法**：单问"t 检验的用途"；或问"检验模型整体显著性用哪个统计量"（F）。
- **错因**（卷01 Q10）：把 t 检验的用途选成"检验模型正态性"。
- **记忆锚**：**t 管单个系数，F 管整个模型**；正态性是前提，不是目的。

## D4-36　p 值：是概率，不是幅度

- **知识点归属**：第 26 章 · 回归分析 · 显著性判断
- **知识点全解**：

  **p 值 = 在原假设成立的前提下，观察到当前（或更极端）结果的概率**

  判据一句话：**p < 0.05 → 显著；p > 0.05 → 不显著**（常用 α=0.05）
  - p = 0.03 ⇒ 显著，说明自变量对因变量有显著影响
  - p = 0.08 ⇒ 不显著
  - ⚠️ p 值**不是效应大小**：p=0.08 不等于"提高 8%"，它只是"8% 的概率"。
- **考法**：给 p 值问结论（显著/不显著）；干扰项把 p 值当百分比效应。
- **错因**（卷01 Q7）：把 p=0.08 读成"康复率提高 8%"。
- **记忆锚**：**p 是概率不是幅度**；**比 0.05 小才显著**，小越小越显著。

## D4-37　回归系数的口径：只说"平均"，不说"必然"

- **知识点归属**：第 26 章 · 回归分析 · 回归系数的解释
- **知识点全解**：Ŷ = 50 + 2X 中，β̂₁ = 2 的正确解释是：

  「X 每增加 1 个单位，Y **平均**增加 2 个单位」

  关键词是"**平均**"。因为回归线是拟合的平均关系，个体可能偏离：
  - ✅ "平均增长 2 万元"
  - ❌ "**必然**增长 2 万元"（绝对化，个体可能增 0.2 万或 3 万）
  - 斜率不变时，**增加方向与减少方向两个表述都成立**（"每增 1 增 2"与"每减 1 减 2"是同一句话的镜像）

  截距 β̂₀ = 50：X=0 时 Y 的平均值为 50（若无实际意义则不解释）。
- **考法**：多选给若干种表述，一句写"平均"、一句写"必然"，只勾"平均"那句；或两句话是镜像，勾一必勾另一。
- **错因**（卷02 Q1 漏镜像项、卷02 Q4 勾了"必然"）：自相矛盾的漏选；绝对化未拦。
- **记忆锚**：**回归系数只说"平均"**，见"必然/一定/肯定"全划；**镜像句勾一必勾另一**。

## D4-38　时间序列四堆归类（本章头号病根）

- **知识点归属**：第 27 章 · 时间序列分析 · 种类
- **知识点全解**：时间序列按指标性质分四类，**归类是本章第一道坎**：

| 类型 | 判据 | 典型例子 |
|---|---|---|
| **总量指标 · 时期序列** | 数值**可累加**，反映一段时间的流量 | 工业总产值、GDP、销售额、商品房**销售面积**、年广告支出 |
| **总量指标 · 时点序列** | 数值**不可累加**，反映某时刻的存量 | 年末**总人口**、**就业人数**、库存、存款**余额** |
| **相对数序列** | 两个数**相比**得到（比重、率、增速） | 城镇化人口**比重**、GDP **增长率**、第三产业**比重** |
| **平均数序列** | 带"**平均/人均**"字样 | 城镇居民**平均**消费支出、人均 GDP |

  易错点：
  - **销售面积**能累加 → 时期（不是相对数）
  - **比重**是比出来的 → 相对数（"城镇化"三个字会晃人）
  - **GDP 增长率**是比出来的 → 相对数（**不是**平均数，也不因为带 GDP 就是时期）
  - **就业人数**是某时点数人头 → 时点
- **考法**：给一个指标问"属于哪种时间序列"。四个选项就是四堆。
- **错因**（卷01 Q1/Q7、卷02 Q5/Q6 —— **四堆归类全章 4 题全错🔴**）：销售面积→相对数（错）；就业人数→时期（错）；城镇化比重→时点（错）；GDP 增长率→平均数（错）。
- **记忆锚**：**能加的是时期，不能加的是时点；比出来的是相对数；带"平均"的是平均数**。四句连念，见指标先问"能不能加"。

## D4-39　时期序列 vs 时点序列的深度区分

- **知识点归属**：第 27 章 · 时间序列分析（与 D4-38 互为补充）
- **知识点全解**：
  - **时期序列**：每项是**一段时间内**的累计量（流量），各项**可以相加**，相加后有意义（1 月+2 月=前两月总量）。特点：数值大小与**时期长短**直接相关。
  - **时点序列**：每项是**某一瞬间**的状态（存量），各项**不能相加**（把每天的人数加起来毫无意义）。特点：数值大小与**间隔长短**无直接关系。
  - 判断小技巧：问自己"这个数能不能把两个月的加起来当成两个月的总量？"——能就是时期。
- **考法**：多选"属于时期序列的有"；单问某指标归类。
- **错因**（卷01 Q7）：把"个体就业人数"当时期序列。
- **记忆锚**：**产值/收入/GDP/销售量/面积 = 时期（流量）；人数/余额/库存/价格 = 时点（存量）**。

## D4-40　环比 vs 定基（轮流坐庄 vs 死盯基期）

- **知识点归属**：第 27 章 · 时间序列的速度分析
- **知识点全解**：

| | **环比** | **定基** |
|---|---|---|
| 基期 | **前一时期**（逐期更换） | **固定某一基期**（通常最初一期） |
| 描述 | 各时期发展水平**交替作为报告期与基期**的循环对比 | 各期都与同一基期比 |
| 关系 | 环比发展速度**连乘 = 定基发展速度** | 定基发展速度 = 各环比之积 |

  - 环比发展速度 = 报告期水平 ÷ **前期**水平
  - 定基发展速度 = 报告期水平 ÷ **固定基期**水平
  - 环比增长速度 = 环比发展速度 − 1
- **考法**：单问"各期交替作为报告期与基期"是哪种（答环比）；问两者的数量关系（连乘）。
- **错因**（卷01 Q2）：把"交替作为报告期与基期"的特征安到定基头上。
- **记忆锚**：**环比＝轮流坐庄；定基＝死盯一个**；环比连乘得定基。

## D4-41　增长速度与平均发展速度

- **知识点归属**：第 27 章 · 时间序列的速度分析
- **知识点全解**：
  - **增长速度 = 增长量 ÷ 基期水平**（环比增长用前期，定基增长用固定基期）
  - 增长速度 = 发展速度 − 1（发展速度是比值，增长速度是净增比率）
  - **平均发展速度**：常用**几何平均法**（各期环比发展速度连乘后开 n 次方）
  - **平均增长速度 = 平均发展速度 − 1**
  - ⚠️ **出现 0 或负数时不宜计算速度**（分母为零或负，比率失去意义）
- **考法**：多选"关于速度分析的正确说法"；计算题给若干环比增速求定基增速（连乘后减 1）。
- **错因**（卷01 Q2 相关项、卷02 Q7）：连乘减 1 的方法已用对✅。
- **记忆锚**：**速度＝报告期÷基期，增长＝速度−1**；平均发展速度用**几何平均**；**遇 0 或负数不算速度**。

## D4-42　累计增长量 vs 平均增长量（和 vs 均值）

- **知识点归属**：第 27 章 · 时间序列的水平分析
- **知识点全解**：
  - **逐期增长量** = 报告期水平 − **前期**水平
  - **累计增长量** = 报告期水平 − **固定基期**水平 = **各逐期增长量之和**（"和"，不是平均）
  - **平均增长量 = 累计增长量 ÷ 期数（n−1）**（逐期增长量的个数）
  - 关系：**累计增长量 = 逐期增长量之和**；平均增长量 = 累计 ÷ (n−1)

  一字之差就是陷阱："和" vs "算术平均数"。
- **考法**：多选给几种表述，把"累计增长量等于各逐期增长量的算术平均数"塞进来（错项）。
- **错因**（卷02 Q4）：勾了"累计=逐期之算术平均"，漏了"平均增长量=累计÷期数"。
- **记忆锚**：**累计＝逐期相加；平均＝累计÷(n−1)**。见"累计=平均"直接划。

## D4-43　定基增长速度 = 各环比发展速度连乘 − 1

- **知识点归属**：第 27 章 · 时间序列的速度分析
- **知识点全解**：
  - 定基**发展**速度 = 各环比**发展**速度连乘（Π）
  - 定基**增长**速度 = 定基发展速度 − 1 = (Π 环比发展速度) − 1
  - 例：三年环比发展速度 1.05、1.10、1.15 → 定基发展速度 = 1.05×1.10×1.15 = 1.32825；定基增长速度 = 32.825%
  - ⚠️ 不能用环比增长速度连乘（1.05×1.10×1.15 ≠ 1.05%+10%+15% 的简单相加，也不是增长率相乘）
- **考法**：计算题给三个环比增速求真基增速。
- **错因**：卷02 Q7 已答对✅（连乘−1 用对了），保持。
- **记忆锚**：**连乘用"发展速度"，最后减 1 得"增长速度"**；增长率不能直接相乘。

## D4-44　序时平均数的四种算法（按数据形态选）

- **知识点归属**：第 27 章 · 时间序列的水平分析
- **知识点全解**：

| 数据形态 | 算法 |
|---|---|
| **时期序列** | **简单算术平均**（各期数值直接平均） |
| **连续时点、逐日登记** | **简单算术平均**（逐日数值直接平均） |
| **间断时点、间隔相等** | **首末折半法**：首项和末项各取一半，中间全取，除以 (n−1) |
| **间断时点、间隔不等** | **两次加权平均**（先按间隔长度加权求各段平均，再以间隔为权求总平均） |

  判据链：**能不能加 → 是时期还是时点 → 时点是否连续 → 间隔是否相等**，一路问下来定方法。
- **考法**：给数据形态问用哪种方法；给一组时点数据算序时平均数。
- **错因**（卷02 Q1）：逐日登记的连续时点，选了需"两次平均"的方法（那是间隔不等的专用法）。
- **记忆锚**：**逐日登记→直接平均；间断+间隔相等→首末折半；间断+间隔不等→两次加权**。方法是跟着数据形态走的。

## D4-45　指数平滑法：越近越重

- **知识点归属**：第 27 章 · 平滑预测法
- **知识点全解**：一次指数平滑法：

  **Fₜ₊₁ = αYₜ + (1−α)Fₜ**（0 < α < 1）

  - α 为平滑系数，**α 越大，近期数据权重越大**（对变化反应快，但越不平滑）
  - 权重随**时间由近及远呈指数递减**：Yₜ 权 α、Yₜ₋₁ 权 α(1−α)、Yₜ₋₂ 权 α(1−α)² ……
  - ⚠️ 权重只看**时间远近**，与观察值**大小无关**（"与数值大小成正比"是造的错项）
  - 例：α = 0.8，Y = 100，F = 90 → Fₜ₊₁ = 0.8×100 + 0.2×90 = 98
- **考法**：单问"权重特点"（答近期权重大、远期权重小）；给 α、Y、F 算下一期预测值。
- **错因**（卷01 Q3）：选"权重与观察值大小成正比"。
- **记忆锚**：**指数平滑＝越近越重**；权重随时间衰减，**不看数值大小**。

## D4-46　时间序列的四个构成成分（按时间尺度分堆）

- **知识点归属**：第 27 章 · 时间序列的构成
- **知识点全解**：

| 成分 | 时间尺度 | 特征 |
|---|---|---|
| **长期趋势（T）** | 长期（数年及以上） | 持续上升/下降/平稳的**基本方向**，可线性也可非线性 |
| **季节变动（S）** | **一年内** | 每年重复出现的周期性波动（如空调销量、春节消费） |
| **循环波动（C）** | **数年** | 周期较长的起伏（经济周期） |
| **不规则变动（I）** | 无固定周期 | 随机波动（自然灾害、突发事件、测量误差） |

  分析模型：加法模型 Y=T+S+C+I；乘法模型 Y=T×S×C×I。
- **考法**：多选"属于长期趋势的有"，把"一年内重复出现的周期性波动"塞进来（那是季节）；或问某现象属于哪种成分。
- **错因**（卷02 Q3）：把"一年内重复"当成长期趋势。
- **记忆锚**：**趋势看长期方向、季节看一年内、循环看数年、不规则看随机**——按时间尺度自上而下分堆。

## D4-47　速度分析的三条禁区

- **知识点归属**：第 27 章 · 速度分析注意事项
- **知识点全解**：
  1. **基期为 0 或负数时，不宜计算速度**（分母为零或负，比率无意义）
  2. **不能直接对增长速度连乘**（要连乘的是**发展速度**，连乘完再减 1）
  3. **相对数序列求序时平均，不能直接平均**（要先分别对分子、分母求序时平均，再相除）
  4. 时点序列**不能直接算术平均**（要看连续/间断、间隔是否相等，见 D4-44）
  5. 平均发展速度用**几何平均法**，不是算术平均
- **考法**：多选"关于速度分析的正确/错误说法"，上述任一条都会成为考点。
- **错因**（卷02 Q4 勾了"累计=逐期算术平均"）："和"与"平均"一字之差。
- **记忆锚**：**零负不算速、增速不连乘、相对数不直均、时点不硬均、平均用几何**——五句连念。

## D4-48　第 25-27 章总复盘：三把尺子

- **知识点归属**：第 25-27 章 · 综合
- **知识点全解**：三章失分集中在三把"尺子"没立起来，各对应一个判断动作：

| 尺子 | 动作 | 覆盖知识点 |
|---|---|---|
| **尺子一：能不能加** | 见时间序列指标先问"两期数值能不能加" | D4-38、D4-39（时期/时点/相对数/平均数） |
| **尺子二：小还是大** | 见"方差/差异/误差"先问"小的是好的还是坏的" | D4-25（有效＝方差小）、D4-27（分层要层内小、整群要群内大） |
| **尺子三：单还是整** | 见检验/模型先问"管单个还是管整体" | D4-30（R² 全是 Y）、D4-35（t 管系数、F 管模型） |

  本章四堆归类的 4 题全错（卷01 Q1/Q7、卷02 Q5/Q6），说明"能不能加"这把尺子完全没立；而 26 章的 6 连错集中在"Y 还是 X""单个还是整体"上。
- **考法**：所有归类题、所有判"哪个更优"的题、所有判"检验什么"的题。
- **错因**：Day 4 三章合计 22 道错题，其中归类类 8 道、方向类 5 道、混概念类 9 道。
- **记忆锚**：**能不能加、小还是大、单还是整**——三句话，进考场前默念一遍。

# 第三部分 · 第 29 章 会计循环（D4-49～60）

## D4-49　试算平衡表 ↔ 资产负债表（查错 vs 看家底）

- **知识点归属**：第 29 章 · 会计循环 · 记账检查
- **知识点全解**：借贷记账法下，期末依据「**资产 = 负债 + 所有者权益**」的恒等关系，以及「有借必有贷、借贷必相等」的记账规则，把所有账户的**借方余额、贷方余额**分别合计，看是否相等，这就是**总分类账户试算平衡表**。
  - **试算平衡表**：内部工作底表，**负责查错**，依据是恒等关系 + 记账规则
  - **资产负债表**：对外报表，反映**某一时点**财务状况，**不查错**
  - 银行余额调节表：只核银行存款账实；资金平衡表：旧口径/另一套表述
- **考法**：题干给"依据资产与权益的恒等关系与借贷记账规则，检查所有账户记录是否正确"→ 问编什么。
- **错因**（卷01 Q1）：选成资产负债表（E2）。卷面原答案键错标 D，已修正为 B。
- **记忆锚**：**查记账对不对 → 试算平衡表；给人看家底 → 资产负债表**。

## D4-50　会计工作全链条（起点是凭证，终点是报表）

- **知识点归属**：第 29 章 · 会计循环
- **知识点全解**：**填制和审核会计凭证（起点）** → 设置账户、复式记账 → 登记账簿 → 成本计算 → 财产清查 → **编制会计报表（终点）**
- **考法**：单问"会计工作开始于"（答填制和审核会计凭证）。
- **错因**（卷01 Q8）：选成"编制报表"（E1 第 12 次，方向反转）。
- **记忆锚**：**从凭证开始，到报表结束**；把"报表"当开始的，是顺序倒背了。

## D4-51　登账前一步 = 编制会计分录

- **知识点归属**：第 29 章 · 会计循环 · 账务处理程序
- **知识点全解**：链条是 **原始凭证 → 记账凭证（含会计分录）→ 登记账簿**。"设置账户"是建账阶段的准备工作，与登账并不相邻。
- **考法**：单问"在登记账簿之前进行的会计工作"。
- **错因**（卷01 Q6）：选成设置账户（E2）。
- **记忆锚**：**分录是指令，账簿是执行**；登账前一步永远是做分录。

## D4-52　借贷方向（资费借增，负债权益收入贷增）

- **知识点归属**：第 29 章 · 借贷记账法
- **知识点全解**：

| 账户类型 | 借方 | 贷方 | 余额方向 |
|---|---|---|---|
| **资产** | 增加 | 减少 | 借方 |
| **费用**（含成本） | 增加 | 减少 | 借方 |
| **负债** | 减少 | 增加 | 贷方 |
| **所有者权益** | 减少 | 增加 | 贷方 |
| **收入** | 减少 | 增加 | 贷方 |

- **考法**：多选"借方登记增加额的账户有"（答**资产 + 费用**）；单问负债类账户规则（答**借减贷增、余额在贷方**）。
- **错因**（卷01 Q10）：勾了 E 负债、漏了 B 资产（E4+E5）；卷02 Q6 同类题已答对✅。
- **记忆锚**：**资费借增，负债权益收入贷增**——五字起头"资费借增"。

## D4-53　复式记账三法（借贷 / 增减 / 收付）

- **知识点归属**：第 29 章 · 记账方法
- **知识点全解**：**借贷记账法**（世界公认、最广泛使用）、**增减记账法**、**收付记账法** 三种。结绳记账、四柱清册属于古代**单式**记账法，不算。
- **考法**：多选"属于复式记账法的有"。
- **错因**（卷01 Q3）：漏了增减记账法（E5）。它现在不用了，但教材仍列在复式记账法里。
- **记忆锚**：复式三法"**借贷、增减、收付**"；**结绳、四柱是单式**。

## D4-54　凭证、账簿相对报表的三条不足

- **知识点归属**：第 29 章 · 会计信息载体
- **知识点全解**：与会计报表相比，会计凭证和会计账簿的不足是：**比较分散、不能概括、无法满足使用者便捷获取信息**。
  - B"比较概括"与 C"不能概括"是反义陪绑项
  - E"比较复杂"是编造项，教材无此表述
- **考法**：多选，干扰项是"比较复杂"和"比较概括"。
- **错因**（卷02 Q1）：多勾 E、漏 A（E4+E5）。
- **记忆锚**：凭证账簿的毛病是"**散、不全、查着累**"；说"复杂"一律不勾。

## D4-55　对账频率：至少每年进行一次

- **知识点归属**：第 29 章 · 对账
- **知识点全解**：为做到**账证相符、账账相符、账实相符、账表相符**，对账工作**至少每年进行一次**。制度给出的是**最低标准**；每季度、每月是企业内部管理的加码要求。
- **考法**：单问频率，四个选项按"每年一次 / 每年两次 / 每季 / 每月"排列。
- **错因**（卷02 Q4）：选成"每季度进行一次"（E2，把企业习惯当制度）。
- **记忆锚**：**对账每年至少一次**；见"每季/每月"先想是不是把习惯当制度。

## D4-56　账户的三套分类体系（问的是哪一套）

- **知识点归属**：第 29 章 · 账户分类（本章头号陷阱）
- **知识点全解**：

| 按什么分 | 分成什么 |
|---|---|
| **经济业务的具体内容** | 资产类、负债类、所有者权益类、收入类、成本类、费用类（损益类） |
| **提供指标的详细程度及统驭关系** | **总分类账户 / 明细分类账户** |
| **用途和结构** | 盘存、资本、结算、调整、集合分配、成本计算、跨期摊配 |

  ⚠️ 另外两套不在账户分类里：**序时账/分类账/备查账簿**是**账簿**分类；**科目汇总表/日记账**是账务处理程序的组成。
- **考法**：单问"按所反映的经济业务的具体内容进行分类，账户可以分为"→ 答第一套。
- **错因**（卷02 Q7）：选成第二套"总分类账户和明细分类账户"（E2）。
- **记忆锚**：**问内容答资负权收成损；问详细答总分类与明细**。

## D4-57　会计凭证的两层分类

- **知识点归属**：第 29 章 · 会计凭证
- **知识点全解**：

  - **第二层（记账凭证按使用范围）**：**收款凭证、付款凭证、转账凭证**
- **考法**：多选"按填制程序和用途的不同可分为"→ 只答第一层的两张。

## D4-58　会计确认的三条一般标准

- **知识点归属**：第 29 章 · 会计确认
- **知识点全解**：
  1. 项目由**经济业务活动产生**，其交易性质**符合会计要素的界定**
  2. 相关**未来经济利益流入/流出的不确定性可以明确地评估**
  3. 项目具有**可计量属性、能够可靠地计量**
- **考法**：多选；干扰项是"企业无法准确计量"（反义）、"能产生现金流量"（编造）。
- **错因**（卷03 Q1）：漏第 ② 条（E5）。干扰项 D、E 都成功拦下✅。
- **记忆锚**：**来源合规、不确定性可评、计量可靠**；中间那条最易漏。

## D4-59　会计计量是贯穿全过程的核心

- **知识点归属**：第 29 章 · 会计计量
- **知识点全解**：教材原话——**会计计量是贯穿于会计确认、记录、报告全过程的核心问题**。会计核算（认、量、记、报）是四个环节的**总称**，不是其中之一，因此不能充当"贯穿四环节的核心"。
- **考法**：单问"贯穿于会计确认、记录、报告全过程的核心问题"。
- **错因**（卷03 Q2）：选成"会计核算"（E2，总称当其一）。
- **记忆锚**：**四环节"认、量、记、报"，量在中间、量是核心**；核算是总和。

## D4-60　财务会计报告的三个组成部分

- **知识点归属**：第 29 章 · 财务会计报告
- **知识点全解**：**会计报表 + 会计报表附注 + 其他应当在财务会计报告中披露的相关信息和资料**

  - 审计报告：由**会计师事务所**出具，是鉴证意见，**不属于**财务报告内容
- **考法**：多选；干扰项是"财务分析报告"和"审计报告"。
- **错因**（卷03 Q4）：漏了"其他应披露的相关信息和资料"（E5）。两个干扰项都排除✅。
- **记忆锚**：**三张表 + 附注 + 其他信息**；**审计报告是别人审出来的**。
