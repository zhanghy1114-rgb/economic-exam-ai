## 第四部分  第 34 章 物权（D5-16～27）

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D5-16  | "丢失/被盗后被转卖" |  **不适用善意取得**，原所有人仍有所有权、转让人无权处分；"丢的偷的不适用，借的租的才适用" |
| D5-17 | "处分按份共有的不动产" |  **占份额 2/3 以上**；重大修缮同；日常事务才是过半数 |
| D5-18 | "物权的法律特征" |  **支配、绝对、法定、优先**；见"债权优先于物权"划掉 |
| D5-19 | "物权优先效力" |  **物权＞债权；先登记＞后登记；先租＞后抵** |
| D5-20 | "排斥他人干涉" |  **独占性**；"四项权能集于一身"＝全面性 |
| D5-21 | "不动产内容发生变化" |  **变更登记**；过户＝转移；写错＝更正；不服＝异议 |
| D5-22 | "不动产统一登记范围" |  **房、地、宅、役、居**；见"船舶/车/航空器"＝动产，划掉 |
| D5-23 | "有期限物权" |  **除所有权外全勾**（居住权、承包经营权、地役权最易漏） |
| D5-24 | 质权选非题 |  **质权标的是动产或权利**，不动产只能抵押；"质押不动产"必错 |
| D5-25 | "善意取得的构成要件" |  **善意、合理价、登记或交付**；见"公告/审批/公证"划掉 |
| D5-26 | 物权客体选非题 |  **物权客体是"物"，债权客体是"行为"**；见"行为"划掉 |
| D5-27 | 用益物权 / 相邻关系 |  **用益＝地宅居住役；担保＝抵质留**；**相邻关系法定、地役权约定** |

## 第五部分  第 35 章 合同（D5-28～41）

| 编号 | 题眼 | 秒杀 |
|---|---|---|
| D5-28 | "合同的担保制度" |  **保、抵、质、留、定**；见"违约金/抵销/提存"划掉 |
| D5-29 | "缔约过失责任发生在" |  **合同订立过程**；履行阶段是违约责任 |
| D5-30  | 要约 vs 要约邀请 |  **"我出这个价"＝要约；"大家来报价"＝要约邀请**；明码标价、自动售货机、举牌＝要约；招标公告、拍卖公告、价目表＝要约邀请 |
| D5-31 | 撤销权期限 |  **误解 90 日、被骗被逼 1 年、最长 5 年** |
| D5-32 | "实践合同" |  只有 **借、保、定、自然人借款**；其余全诺成（含抵押合同） |
| D5-33 | 抗辩权 |  **"我先给怕你付不出"＝不安；"你该先给却不给"＝先履行；同时履行＝同时给**；先诉抗辩权是保证人的，不勾 |
| D5-34 | 知识产权转让生效 |  **专利登记、商标核准公告、著作权合同成立** |
| D5-35 | "催告后未作表示" |  **视为拒绝追认**；沉默＝拒绝 |
| D5-36 | "年末编报前必须做" |  **财产清查**；审计/税务审查都不是 |
| D5-37 | 债权/债务转让选非题 |  **换债权人＝通知；换债务人＝同意**；见"债权转让须经债务人同意"错项 |
| D5-38 | 定金 |  **20%、交付才成立、与违约金二选一** |
| D5-39 | 保证方式选非题 |  **一般保证有先诉抗辩权，连带没有**；两句话拧在一起的自相矛盾项必错 |
| D5-40 | "合同保全制度" |  **代位权 + 撤销权**；押/质/留是担保不是保全 |
| D5-41 | 担保 vs 责任的边界 |  **先给的＝担保；后罚的＝责任**；两堆不交叉 |

## 一页纸速记（考前最后 60 秒）

**三堆归类**：还得上＝偿债（流动速动现金负债率利息倍数）｜周转快＝营运（周转率天数）｜带率字＝盈利（利润率收益率市盈率）

**效力三分类**：违法内容无效｜程序瑕疵可撤销｜没开没表决没过数不成立

**合同四组**：借保定自然人借款＝实践，其余诺成｜焚烧懈怠＝勤勉、谋私＝忠实｜换债权人通知、换债务人同意｜90 日 / 1 年 / 5 年

**物权四句**：丢的偷的不适用善意取得｜只有所有权无期限｜不动产只能抵押不能质押｜相邻法定地役权约定

**公司法数字**：催缴 60 日｜回购 6 个月｜简易注销 20 日｜定金 20%｜请求资本公积＝溢价+无面额超出+财政规定｜国有独资没股东会董事长靠指定｜查出资催出资是董事会

**37 章两句**：平台知情不管连带、查无此人先赔再追｜"连带"必得法条点头

**答题顺序**：先排除明显编造项  再套以上六组  剩余项逐个问"教材原句能不能写出来"，写不出来就不勾。
