# 经基·考前锚点播客（对谈版文字稿）

【开场】

康：早上好，BOSS。今天是十一月八号，经济基础考试日。这份音频不是新课，全部内容都来自你自己做错过的四百零六道题——每一条都是你踩过坑之后自己写下的锚点。咱们按失分从重到轻过六章，最后再过十二条最高频病根。通勤路上听完，进考场前心里就有底了。

雅：等一下，开场先给我几句最要紧的答题口诀吧，我怕上了考场手忙脚乱。

康：好，五句话记牢。第一句，多选题永远不要五项全勾——六百九十三道真题里，全选一次都没出现过。

雅：五项全选，零次？

康：零次。正确答案要么三项要么四项，占七成半。第二句，多选只勾两项就交卷，等于白丢一半分，因为正确项三项以上的占四分之三。但是补第三项有门槛，得有三分之二的把握才补。

雅：把握不够就不补？

康：对，因为错一个字母整题归零，少选一项只扣半分，风险回报比是四比一。第三句，你的单选有个习惯，纠结的时候总往 D 上放，但你错得最多的题，正确答案在 C 的最多。所以犹豫时先回头看 C。

雅：哈哈，被数据抓到了。第四句呢？

康：第四句，取非题先圈题干里的"不"字，逐项打勾打叉，最后只选打叉的，勾完数一遍个数。第五句，多选五个字母逐个问一句——教材写没写？写了的勾，没写的不勾，不许凭整体感觉选。

雅：明白！那开始过章吧，从失分最重的来。

【第28章 会计概论 失分五十六分】

康：第二十八章，会计概论，你失了五十六分，全卷第一大户。先上总钥匙：会计要素怎么分？

雅：日期是照片，看家底；时期是录像，看成果！

康：没错。资产负债表是日期的照片，配三兄弟——资产、负债、所有者权益；利润表是时期的录像，配成果三兄弟——收入、费用、利润。所以题目问静态、问财务状况，只配资产负债所有者权益这一组，收入费用永远不上资产负债表。

雅：那所有者权益怎么记？

康：资产减负债，就像扣掉房贷之后房子的净值。老板的本钱是所有者权益，我拥有的实物和权利是资产。

雅：预收和预付老是搞混，怎么破？

康：看谁欠谁。预收，是我先收了钱、还欠客户货，那是负债；预付，是我先付了钱、对方欠我货，那是我的权利，算资产。应收也一样，先发货对方欠我钱，是资产。

雅：资产和收入的确认时点呢？

康：资产看所有权或者控制权到手那一刻；收入看权利形成的那一刻。

雅：账户式和报告式资产负债表怎么分？

康：账户式像 T 型账户，左边借方是资产，右边贷方是负债和所有者权益；报告式才是上下排。

康：再记两条容易混的。债权永远在资产方，债券、存款、货币永远在负债方——一字之差，权对券错。见到长期、固定、在建、无形这些字眼，都是非流动；存货是流动资产的招牌。

雅：会计四大假设是哪四个？

康：主体、持续、分期、货币。注意，要素、科目、报表都不是假设，这是干扰项的老位置。

雅：现金流量怎么判断？

康：只认跨越现金池边界的进出。提现不算，以物抵债不算，以物投资也不算——钱没动就没流量。

雅：最后一条，实质重于形式。

康：见到实质、形式、里子面子这些字眼，答案就是实质重于形式，经典例子是融资租赁。

【第19章 央行与货币政策 失分二十九分】

康：第十九章，中央银行与货币政策，失二十九分。这章最容易考的是方向题。紧缩三板斧？

雅：提高再贴现率、提高存款准备金率、卖出证券！

康：对，见到降低、买入，就是扩张。你在这里连错两次，方向题先判断松还是紧，再看动词。

雅：准备金率的作用机制？

康：它是货币乘数公式的分母——分母胖了分数就瘦。提高准备金率，乘数变小，货币供应收缩。

雅：二零二三年金融监管新格局？

康：金监总局管除证券业之外的都管；证监会管证券业；央行管宏观加支付加金库。

雅：央行对商业银行和对政府的服务怎么分？

康：对商业银行三件事——集中存款准备金、充当最后贷款人、组织银行间清算。对政府——经理国库、代理发行国债、保管外汇黄金储备。注意，中国是经理国库，自己的事自己办，代理国库是干扰项。

雅：货币政策传导靠什么？

康：三件套：经济主体反应灵敏、金融市场较为发达、利率汇率市场化程度较高。外向程度和财政收入不沾边。

雅：中介目标的三性？

康：相关性、可测性、可控性。见到联系性、排他性，都是造出来的词。

雅：三层目标楼？

康：操作目标在底层，中介目标在中层，最终目标在顶层。题目问"之间"，答案就是中介目标。

康：再补两条。二零二四年十二月双定调：更积极的财政政策加适度宽松的货币政策，见到稳健、从紧都是旧词。结构性货币工具是定向滴灌，专项再贷款、定向额度；公开市场操作永远站在一般性那一堆。

【第14章 税收制度 失分二十八点五分】

康：第十四章，税收制度，失二十八点五分。先记累进税的坑：超额累进是分级计算加总；全额累进是整个所得按一个档次一次算，税负重、临界点跳档。

雅：契税谁缴？

康：承受方缴。三问：在境内吗？产权转移吗？谁是承受方？土地承包经营权转移不缴契税。

雅：房产税的税率？

康：比例税率，从价百分之一点二，从租百分之十二。从价是按原值减除百分之十到三十之后计，不是全额。

雅：个税里哪些所得没有费用扣除？

康：利息、股息红利，全额纳税。稿酬减征百分之三十，租赁和劳务报酬都有扣除。免税收抚恤金、国债利息、退休费；减征收残疾、孤老、烈属。

雅：专项扣除和专项附加扣除？

康：专项扣除是三险一金；专项附加是七项——子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、还有三岁以下婴幼儿照护。大病医疗在附加里，不在专项里。

雅：个税九项所得？

康：工资薪金、劳务报酬、稿酬、特许权使用费、经营、利息股息红利、财产租赁、财产转让、偶然所得。注意我国没有遗产税。

雅：增值税和消费税的性质？

康：增值税是价外税；消费税是间接税；车船税是地方税。复合计税只有卷烟和白酒，小汽车不是。

雅：拉弗曲线那道题？

康：高税率区间，收入随税率增加而减少，这正是曲线右半段。财政收入职能之外，还有涵养税源、适度宏观税负。

【第35章 合同法律制度 失分二十五分】

康：第三十五章，合同法律制度，失二十五分。解除权三分法：事先约好叫约定解除，事后商量叫协议解除，法律直接给叫法定解除。

雅：协议解除和约定解除的关键区别？

康：协议解除必须有双方合意；约定解除和法定解除都是单方通知就生效。甲单方通知就解除了，那不可能是协议解除。

雅：担保方式有几种？

康：五项：保证、抵押、质押、留置、定金。违约金是罚，不是保。

雅：缔约过失和违约责任？

康：没签成合同，是缔约过失，赔信赖利益；签成了不履行，是违约责任，赔履行利益。

雅：要约和要约邀请？

康：有价有量是要约；公布名单招人上门是要约邀请。"我出这个价"是要约，"大家来报价"是要约邀请。

雅：撤销权的时间？

康：重大误解九十天；被骗被逼一年；最长五年。

雅：实践合同有哪些？

康：只记四个字：借、保、定、自然人借款。要交出东西才成立。

雅：不安抗辩和先履行抗辩？

康：我先给、怕你付不出，是不安抗辩；你该先给却没给，是先履行抗辩。

雅：债权债务转让？

康：换债权人，通知对方就行；换债务人，必须对方同意——因为换了人还钱，风险变了。

【第36章 公司法律制度 失分二十二点五分】

康：第三十六章，公司法律制度。出资看什么？能不能估价，加能不能转让。债权能转让所以能出资；劳务长在人身上，转让不了，不能出资。

雅：股东知情权？

康：三件套：能查、能起诉、能请中介。全资子公司也允许查。

雅：董监高的忠实义务？

康：报告加决议两步走，光报告不算完。干了违规的，赚的钱归公司。

雅：决议瑕疵三分法？

康：内容违法，无效；程序违法，可撤销；没开会的、没表决的、票数没过的，不成立。

雅：公司给股东担保？

康：三件套：股东会决议、其他股东过半数同意、被担保的股东回避。见到登记、百分之三十上限，一律是干扰。

雅：催缴出资的宽限期？

康：不少于六十日。三十日、六个月都是干扰数字。

雅：回购的股份？

康：半年内必须处理，不能捂在手里。一年、两年是干扰。

雅：审计委员会？

康：三人以上、过半数通过、一人一票、可以替代监事会，职工代表允许进。

【第18章 货币供求与货币均衡 失分二十一点五分】

康：第十八章，货币供求。货币需求是什么？想持有加强持有得起，两个条件。银行数量是干扰项。

雅：M1 的口径？

康：现金加单位活期存款。越往存款方向走，越往外圈，M2 就包含定期和储蓄。

雅：通货膨胀的两把尺子？

康：一把看成因——需求拉上、成本推进、结构；另一把看表现——公开的和抑制的。抑制就是压着不让涨，隐蔽型。

雅：成本推进通胀？

康：工资加利润，成本的两张脸。需求拉上是另一半。

雅：派生存款的漏损？

康：只怕漏——准备金、提现、缴税会漏；网点数和消费意愿不漏钱。

雅：凯恩斯的三大假设？

康：边际消费倾向递减、平均消费倾向递减、消费是收入的函数。人口和预期都不是他的假设。

雅：费雪方程的字母？

康：V 是流通速度，P 是价格，T 是交易量。

康：再记一句：社融和 M2 增速要同什么匹配？经济增长加价格水平预期目标，两个匹配对象。

【结尾 十二条最高频病根】

康：最后，十二条最高频病根，考前就背这个。雅雅，你念题眼，我给答案。

雅：第一条，选非题。

康：先圈错误或者不正确，逐项打勾打叉，只选打叉的。

雅：第二条，多选。

康：每个字母先问教材写没写，没写的不勾。错选归零，少选还有半分。

雅：第三条，绝对化。

康：仅、只、完全、必须、一律，先找反例，找到就划。注意，是先找反例，不是见词就划。

雅：第四条，数字题。

康：先问这是谁的数。数字对、主体错，是最像答案的坑。

雅：第五条，会计六要素。

康：日期是照片看家底，时期是录像看成果。

雅：第六条。

康：所有者权益等于资产减负债，扣掉房贷后的净值。

雅：第七条。

康：收入和费用不上资产负债表。

雅：第八条。

康：存货是库房所有家当打包算，别漏了在产品。

雅：第九条，计量属性。

康：五兄弟：历史、重置、可变现、现值、公允。

雅：第十条。

康：见实质、形式、里子面子，选实质重于形式。

雅：第十一条，弹性。

康：弹性大于一，降价收入涨；弹性小于一，涨价收入涨——这就是谷贱伤农。

雅：第十二条，自动稳定器。

康：三件套：累进税、转移支付、农产品价格维持。

雅：好了！最后还有什么要嘱咐的吗？

康：三句话。单选绝不空着一分，蒙也有四分之一。多选宁缺毋滥，错一个字母整题归零。取非题先圈"不"字。今天卷子上的题，一大半你都见过同款——你错过的那四百零六道题，每一条锚点都是替今天的你埋的路标。正常发挥就够。去吧，BOSS。
