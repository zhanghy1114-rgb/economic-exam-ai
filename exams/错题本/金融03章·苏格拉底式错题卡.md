## 第一组 · 数字钉子（7 题全灭，本章头号失血）

### S-23（对应 R2/R3/R10/R12/R14/P6/P11）
**问自己**：不翻任何材料，把下面 7 组数字**说出口**——
1. 私募理财合格投资者：法人净资产 ≥ ？；个人金融资产 ≥ ？或年收入 ≥ ？
2. 我国资本充足率三层：核心一级 ≥ ？、一级 ≥ ？、总 ≥ ？
3. 集中度三线：单一集团客户 ≤ ？、单一客户 ≤ ？、全部关联方 ≤ ？（分母都是什么？）
4. 金融租赁：对单一股东关联方合计 ≤ ？、单一关联方 ≤ ？、同业拆入 ≤ ？
5. 成本收入比监管线 ？%；营业费用 80 亿、营业收入需要多少才达标？
6. LCR ≥ ？%；「流动性比例 25%」是哪个指标的线？
7. 我国杠杆率 ≥ ？%（巴塞尔是 ？%）

<details><summary>核对</summary>
① <b>1000 万</b>（法人）；个人 <b>300 万</b>金融资产或近 3 年年均收入 ≥ <b>40 万</b>　② <b>5 / 6 / 8</b>（凡见 4%、4.5% 是巴塞尔/旧口径，划掉）　③ <b>15% / 10% / 50%</b>，分母全是<b>资本净额</b>　④ <b>50% / 30% / 100%</b>　⑤ <b>45%</b>；80 ÷ 45% ≈ <b>178</b>（反过来：营业费用 80、收入 178 → 比率 45%）——若题给收入 80，则费用上限 = 80×45% = <b>36</b>（R14 正是这样问的）　⑥ <b>100%</b>；25% 是<b>流动性比例</b>的线，专门骗人安到 LCR 头上　⑦ <b>4%</b>（巴塞尔 3%），分母是<b>不加权的表内外资产余额</b>
</details>

**⚡收口锤**：03 章数字题=**送分题**。这 7 组每天早上念一遍，11-04 复测数字题必须 7/7。

### S-24（对应 R3·错把巴塞尔当我国口径）
**问自己**：
- 我国核心一级资本充足率是 5% 还是 4.5%？为什么比巴塞尔高？
- 选项里出现「4%」「4.5%」「6%」时，你的第一反应应该是什么？

<details><summary>核对</summary>我国口径 <b>5 / 6 / 8</b>——银保监在巴塞尔底线（4.5/6/8）上<b>加码</b>（+0.5/0/0，另加储备资本 2.5% 等）。见 4%、4.5% → 那是<b>巴塞尔原文</b>，考"我国"必错；见 6% 出现在核心一行 → 错（6% 是<b>一级</b>的线）。口诀：<b>「五六八，只升不降」</b>。</details>

### S-25（对应 R22/P8·两道选非全错）
**问自己**（这两题是选非，先圈"不属于"再动笔）：
- 核心一级资本里有没有优先股？（优先股在哪层？）
- 「超额贷款损失准备」是扣减项还是加项？进哪层？
- 扣减项三件套是什么？

<details><summary>核对</summary>优先股 → <b>其他一级资本</b>，核心一级只有"普通股+留存收益"类（实收资本/资本公积/盈余公积/未分配利润）。超额贷款损失准备 → <b>二级资本的加项</b>，绝不是扣减项。扣减三件套：<b>商誉、其他无形资产、（递延税净额）</b>。选非题动作：<b>圈"不属于" → 逐项打 ✅❌ → 只选 ❌</b>。</details>

### S-26（对应 R17/P7·资本工具对号入座）
**问自己**：把这 6 样工具逐个分进三层——普通股、利润留存、优先股、永续债、二级资本债、超额贷款损失准备。

<details><summary>核对</summary>核心一级：<b>普通股、利润留存</b>（股+留存收益）；其他一级：<b>优先股、永续债</b>；二级：<b>二级资本债、超额贷款损失准备</b>。记忆锚：<b>"股留核心，优永其他，拨备垫底"</b>。</details>

## 第二组 · 三桶归类（存款准备金/资产负债/表外）

### S-27（对应 R1/R20/P9·"见准备金就选央行"条件反射）
**问自己**：
- 法定存款准备金由谁保管？超额存款准备金呢？
- 为什么超额的部分归商业银行自己支配？
- 「吸收存款」「向央行借款」「发行债券」是资产还是负债？「发放贷款」「投资债券」呢？

<details><summary>核对</summary>法定 → <b>央行</b>（强制缴存）；超额 → <b>商业银行</b>自己（存放央行超出法定要求的部分，随时可动用，所以它的多寡由银行自己决定——这就是 R1 的答案逻辑）。负债桶：<b>吸收存款、拆入、向央行借款、发行债券</b>；资产桶：<b>发放贷款、投资、存放央行/同业</b>。口诀：<b>"吸收来的都是债，放出去的才是产"</b>。</details>

### S-28（对应 P3/P4·表外 vs 中间 vs 资产负债）
**问自己**：保函、信用证、贷款承诺、衍生工具——各进哪个桶？"不占资金收手续费"说的是哪个概念？它和表外业务的判据一样吗？

<details><summary>核对</summary>保函/信用证/承诺/衍生 → <b>表外业务</b>（不进表、有<b>或有</b>风险）。"不占资金收手续费"= <b>中间业务</b>的判据。两者有交集但<b>判据不同</b>：表外看"进不进表、有没有或有风险"，中间看"占不占用资金"。一句话：<b>"有或有→表外；只收手续费→中间"</b>。</details>

## 第三组 · 方向与关系（E1/E2）

### S-29（对应 R4·流动性陷阱的图）
**问自己**：货币需求图的横轴是什么、纵轴是什么？流动性陷阱时曲线长什么样？"平行于纵轴"是哪个学派的情形？

<details><summary>核对</summary>纵轴 = <b>利率 i</b>，横轴 = <b>货币量 L</b>。流动性陷阱：利率极低时再发货币利率也不降 → 需求曲线<b>躺平 = 平行于横轴</b>。平行于纵轴 = <b>古典情形</b>（货币需求只由收入决定、与利率无关）。画面记忆：<b>"陷阱里躺着"</b>。</details>

### S-30（对应 P5/R26·缺口方向）
**问自己**：正缺口是谁多？升息时正缺口银行赚还是亏？那负缺口怕什么？给自己编一个 500/400 的算例验证。

<details><summary>核对</summary>正缺口 = <b>资产</b>（利率敏感资产 > 负债）→ 利率升 → 资产重定价快 → <b>赚</b>；所以<b>正缺口怕降息</b>。负缺口 = 负债多 → <b>怕升息</b>。算例：资产 500、负债 400（正 100），利率 +1% → 资产多收 5、负债多付 4 → 净赚 1（利率升对正缺口有利）。两句话钉死：<b>"正怕降、负怕升"</b>。</details>

### S-31（对应 R5/R13/R15/R19/R18/R21·概念速判五连）
**问自己**（每题 10 秒内出答案）：
1. 三性原则之间的关系，教材的官方说法是哪四个字？
2. 商业银行区别于其他金融机构的"唯一性标签"是什么？
3. 银行服务营销的中心是产品还是客户？
4. "四自"是哪四个词？出现"分摊风险/自我开发"对不对？
5. 黄金的价格波动，我国监管把它归入汇率风险还是商品风险？

<details><summary>核对</summary>
1. <b>对立统一</b>（又矛盾又依存）——见"相互矛盾/相互独立/同一关系"这类单向绝对词一律排除。
2. <b>吸收活期存款 + 创造信用货币</b>——围绕它：历史最久✓、业务最广✓；凡"××机构也能吸活期/也创造货币"必错。
3. <b>客户</b>——服务/产品/利润都是围绕客户的派生。
4. <b>自主经营、自担风险、自负盈亏、自我约束</b>——"分摊风险"不是"自担"，"自我开发"不是"约束"，都是干扰。
5. <b>汇率（外汇）风险</b>——这是我国监管口径的特例（国际口径里黄金才是商品），题干见"我国商业银行"就选汇率。
</details>

## 第四组 · 多选防线（E4×9 + E5×5，丢分 33 分的大头）

### S-32（对应 R6/R7/R8/R9/R11/R23/R24/R26/R27/P9/P11 的多选纪律）
**问自己**：
1. 这次 9 道多选错选，每一道都是"多勾几个字母归零"——具体是哪 9 个字母？（背不出就回错题本看）
2. "宁少选不错选"的数学依据是什么？（少选拿多少？错选拿多少？）
3. 下次多选的动作序列是什么？（三步，每步一个动作）

<details><summary>核对</summary>
1. 多勾的 9 个字母：<b>C/D/E/A/A/D/D/C/D</b>（R6-C、R7-D、R8-E、R10-A、R12-A、R13-D、R24-D、R26-C、P9-D）——全是"看着眼熟"的词。
2. 数学依据：少选每正确项 <b>0.5 分</b>（5 项选 2 = 1 分保底）；错选 <b>0 分</b>。勾一个不确定的字母 = 拿全部已确定的分去赌 0.5。
3. 动作序列：①先写总数值 N（如"风险结构=3"）→ ②A-E 逐个落笔 √/× → ③<b>√ 要理由，× 也要理由；理由写不出的按"宁少选"处理——不勾</b>。
</details>
