# 双支柱 · 归属二分表（11-P18 单点终结卡）

> 变式三连：V3 全对、V1 选 A（写成货币政策的活）、V2 勾 BCDE（取非方向反了）。
> 病灶一句话：**你认得整段话，但拆成单项就抓不住主语。**
> 这张表只有一个用法——看到任何选项，先问「主语是哪根支柱」。

## 一、两根支柱，各管各的（背这一张就够）

| | 货币政策（第一支柱） | 宏观审慎政策（第二支柱） |
|---|---|---|
| **管什么** | 总量、物价（总需求） | 杠杆、系统性风险 |
| **靶子** | 通胀 / 通缩、经济过热或过冷 | 顺周期性、跨机构风险传染 |
| **工具** | 存款准备金率、公开市场操作、再贴现、利率 | MPA、逆周期资本缓冲、LTV 首付比上限、系统重要性附加资本、LCR/NSFR |
| **实施主体** | 人民银行 | 人民银行（宏观审慎管理局） |
| **不管** | 单个机构的杠杆与传染 | 物价总水平 |

**一句话分工**：货币管**水位**，审慎管**哪家在裸泳**。

## 二、串门即错（V1 就栽在这）

| 选项里的说法 | 归属 | 判定 |
|---|---|---|
| 调节社会总需求、稳定物价总水平 | 货币政策 | ❌ 不是宏观审慎 |
| 抑制顺周期性与跨机构风险传染 | 宏观审慎 | ✅ 这是它的身份标签 |
| 通过公开市场操作调节流动性 | 货币政策 | ❌ 不是宏观审慎 |
| 通过财政收支调节总供求 | 财政政策 | ❌ 双支柱里根本没有财政 |

## 三、三大绝对化钉子（见到就判错）

| 钉子 | 为什么错 |
|---|---|
| 宏观审慎**可以替代**货币政策 | 双支柱的立论前提就是不可替代；若可替代则无需「双」 |
| 物价稳定**就意味着**金融稳定 | 2008 年危机推翻的观点，正是设第二支柱的理由 |
| 货币政策**能管住**单一机构风险 | 它是总量工具，管不了微观杠杆与传染 |

## 四、取非题四步（V2 就栽在这）

V2 你答 BCDE，正解 BC——**勾了 3 个正确表述**。取非题不是"再选一遍"，是"反着选"：

1. **圈题干**：把「错误」「不正确」「不属于」圈出来，写在草稿纸最上面
2. **逐项标**：A ✓、B ✗、C ✗、D ✓、E ✓（每项都落笔，不许跳）
3. **反向勾**：只勾标了 ✗ 的 → **BC**
4. **数一遍**：勾了几项？和你的标记数一致吗？不一致就是手滑

> 死记：**取非题勾的永远是"看着对但不该选"的那些**。凡是温和表述（不同、配合、主要管），在取非题里一律不勾。

## 五、考前 30 秒默念
