| 三兄弟 | 谁决定 | 一句话 |

### 第 01 章 金融学基础　`🎯 错 11/27 道（41%）`

**总纲**：利率是价格，汇率是比价，国际货币体系是规则。

| 口诀 | 人话 | 题眼 |
|---|---|---|
| 利率市场化「**先市场、后存贷**」 | 货币市场、债券市场利率先放开；存贷款利率风险外溢最大，放最后 | 见「先放开存贷款」直接划 |
| 下一程「**自律、合理、调控、传导**」 | 改革方向是打破协同、允许差异化定价 | 见「协同定价 / 一致定价」直接划 |
| 利率决定三大家「**古典=储投、凯恩斯=货币、可贷=综合**」 | 古典看储蓄投资、凯恩斯看货币供求、可贷资金两者都看 | 「利率由什么决定」的四种问法 |
| 期限结构三理论「**预、分、流**」 | 预期理论、分割市场理论、流动性溢价理论 | 见「流动性陷阱 / 古典」直接划（那是别的概念） |
| 风险结构三件套「**违约、流动、税**」 | 同一期限不同债券的利差来源 | 见「手续费 / 增值税」直接划 🎯**错×3**（01-R6） |
| 汇率按制度性质「**固定 vs 浮动**」 | 这是唯一按"制度"分的角度 | 名义/实际、买入/卖出、有效汇率是另外三套 |
| 国际货币体系三核心「**调节、储备、汇率**」 | 国际收支怎么调、储备用什么、汇率怎么定 | 见「基准利率 / 账户开放」不入列 |
| 时间价值四因「**利、险、胀、机会**」 | 利息、风险、通胀、机会成本 | 汇率不掺和 |
| 购买力平价「**← 一价定律**」 | 一物一价推出一国物价与汇率的关系 | 绝对购买力平价的基础 |

**金本位 vs 布雷顿森林（必考对比）**

| | 国际金本位制 | 布雷顿森林体系 |

| 中心 | **黄金**中心 | **美元**中心 |
| 汇率 | **固定**（死汇率） | **可调整**的固定汇率 |
| 关键词 | 「**自发**」形成 | 「**可调整**」平价 |
| 五要素 | 金自由、金储备、自动调、死汇率、锚铸币 | 双挂钩（美元挂黄金、他国挂美元） |

> 记忆钩：**"自发"是金本位的词，"可调整"是布雷顿的专利**。看到"黄金在国际间自由流动不受限制"——对，这是金本位。
