# 第 01 章 金融学基础（F-01～F-10）

> 真题池 29 题 ｜ 你的错题 10 条 ｜ 大纲：无变化 ｜ 优先级 🟠 中

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 利率分类与时间价值（单选送分，别丢）

| 分类角度 | 结果 | 题眼 |
|---|---|---|
| 是否剔除通胀 | **名义利率 / 实际利率** | 实际 ≈ 名义 − 通胀率 |
| 借贷期内是否调整 | 固定利率 / 浮动利率 | 长期贷款多用浮动 |
| 利率决定方式 | 市场利率 / 官定利率 / 公定利率 | 央行定的=官定 |
| 信用行为主体 | 中央银行利率 / 商业银行利率 / 市场利率 | 再贴现、再贷款=央行利率 |
| 是否优惠 | 一般利率 / 优惠利率 | — |

- **单利** I = P·r·n，F = P(1 + r·n)；**复利** F = P(1 + r)ⁿ（利滚利，终值更大）
- **现值** P = F/(1+r)ⁿ｜**终值** F = P(1+r)ⁿ → **r 越大、n 越长，现值越小**
- 货币时间价值影响因素（多选）：**资金额、时间长短、利率（收益率）、通货膨胀率、风险**
  ⚠️ 见「资金的使用方式 / 借贷主体 / 币种」是干扰项，不在五因素里

### A2. 利率决定理论四大家（高频配对题）

| 理论 | 利率由谁决定 | 题眼 |
|---|---|---|
| **古典利率理论**（实际利率理论） | **储蓄 S 与投资 I** | 见"储蓄与投资"必选 |
| **凯恩斯流动性偏好理论** | **货币供给 Ms（外生）与货币需求 Md** | 见"流动性偏好/货币量"必选 |
| **可贷资金理论** | 可贷资金的供给与需求（储蓄+信用+窖藏） | 综合二者 |
| **IS-LM 模型** | 商品市场与货币市场**同时均衡** | 见"两个市场同时均衡" |

⚠️ 干扰手法：把「储蓄与投资」塞进凯恩斯、把「货币供求」塞进古典——**理论与人头必须配对**。

### A3. 利率的风险结构 vs 期限结构（年年考，先分清楚再背）

| | 问的是 | 三件套 |
|---|---|---|
| **风险结构** | **期限相同**的债券，利率为何不同 | 违约风险、流动性、**所得税** |
| **期限结构** | **风险相同**的债券，**不同期限**利率之间的关系 | 预期理论、分割市场理论、流动性溢价理论 |

- 收益曲线三形态：向上倾斜（正常）、水平、向下倾斜（倒挂）
- ⚠️「流动性**陷阱**」属凯恩斯货币需求（第 9 章）、「古典利率理论」属利率**决定**——都不是期限结构理论

### A4. 汇率与汇率制度

- **直接标价法**：1 单位外币 = ? 本币（**我国采用**）→ 汇率数值↑ = **本币贬值**
- **间接标价法**：1 单位本币 = ? 外币（英美）→ 汇率数值↑ = 本币升值
- 汇率分类四角度（别混）：
  - 按**制度性质** → 固定汇率 / 浮动汇率（F-04）
  - 按是否剔通胀 → 名义 / 实际汇率
  - 按银行买卖 → 买入价 / 卖出价（**买入价 < 卖出价，银行低买高卖**，中间价是基准）
  - 按衡量总体变动 → **有效汇率**（指数）
- 汇率制度按弹性从小到大：**货币局制 → 传统固定钉住 → 爬行钉住 → 浮动**（F-107）
- 汇率决定理论：**购买力平价**（绝对←一价定律；相对←两国通胀率之差）、利率平价、国际收支说、资产市场说（F-10）
- 汇率变动对经济的影响（多选高频）：本币贬值 → **出口增加、进口减少** → 贸易收支改善；同时带来**输入性通胀压力**；影响资本流动、外汇储备估值

### A5. 国际货币体系演变（时间轴单选）

**金本位制**（1880-1914，金币自由铸造/自由兑换/自由输出入、黄金作储备、汇率固定、国际收支自动调节）
→ **布雷顿森林体系**（1944-1973，**双挂钩**：美元钉黄金 35 美元/盎司、其他货币钉美元；可调整钉住；IMF 与世界银行成立）
→ **牙买加体系**（1976-，黄金非货币化、浮动汇率合法化、储备资产多元化）
（详见 F-07）

## F-01　利率市场化改革的顺序：先金融市场利率、后存贷款利率

> 题源：D6-01

- **知识点归属**：第 01 章 · 利率市场化改革
- **知识点全解**：我国推进利率市场化改革的总体思路是——
  1. **先放开货币市场利率和债券市场利率**（同业拆借、债券回购、国债收益率等先行市场化）
  2. **再逐步推进存、贷款利率市场化**（存款利率自律上限、LPR 报价机制改革在后）

  ⚠️ 顺序是"**先市场、后存贷**"，因为存贷款利率直接涉及社会融资成本和银行利差，风险外溢最大，必须放在最后。干扰项一律把「存贷款」提到前面。
- **考法**：单选给四个排列组合，问"总体思路是"；也可能在多选题里把"先存贷款"当错误项（见 D6-02 的 B）。
- **错因**：（Q2 选 D 先资本市场+债券）：E2 顺序记反。
- **记忆锚**：利率市场化「**先市场（货币+债券）、后存贷**」；见"先放开存贷款"直接划。

## F-05　利率期限结构三理论：预、分、流 ｜ 利率期限结构·预期理论三推论

> 题源：D6-06 + D7-38（同考点合并）

- **知识点归属**：第 01 章 · 利率期限结构
- **知识点全解**：**〔D6-06〕** 解释利率期限结构（不同期限利率之间的关系）的三种主要理论：
  1. **预期理论**：长短期利率由市场对未来短期利率的预期决定
  2. **分割市场理论**（市场分割理论）：不同期限市场各自独立、互不影响
  3. **流动性溢价理论**（期限选择与流动性升水）：长期债券需给流动性补偿——**第三种就是它**

  ⚠️ 「流动性**陷阱**」是凯恩斯货币需求概念、「古典利率理论」是利率**决定**理论，都不是期限结构理论。

  **〔D7-38〕** 预期理论三大推论：
  1. 不同期限债券利率**同向运动**（长期利率=未来短期利率预期的平均）
  2. 短期利率偏低（预期升）→ 收益率曲线**向上倾斜**
  3. 短期利率偏高（预期降）→ 曲线**向下倾斜**
  - ⚠️ 与另外两论对比：分割市场理论（各期限市场独立）、流动性溢价理论（预期+风险溢价）
- **考法**：〔D6-06〕单选填空"预期理论、分割市场理论和（）理论"。 ｜ 〔D7-38〕直接考"趋势是同向/反向/先涨后跌"
- **错因**：〔D6-06〕（Q8 选 C 古典利率理论）：E2。 ｜ 〔D7-38〕（Q7 选 D 先涨后跌）：E2 与流动性溢价混淆。
- **记忆锚**：〔D6-06〕期限三论「**预、分、流**」；见"陷阱""古典"直接划。 ｜ 〔D7-38〕"预期理论=**同向**"

## F-06　利率的风险结构：违约、流动、税

> 题源：D6-07

- **知识点归属**：第 01 章 · 利率风险结构
- **知识点全解**：**到期期限相同**的债券利率之所以不同，由三个因素造成：
  1. **违约风险**（B）—— 风险越高利率越高（风险溢价）
  2. **债券流动性**（C）—— 流动性越差利率越高
  3. **所得税因素**（E）—— 免税债券利率较低

  ⚠️ 手续费（D）、增值税（A）属于**交易成本/税负**但与债券定价的风险结构三因素无关，是典型干扰项。
- **考法**：多选「到期期限相同的债券导致利率不同的因素主要有」，五个选项塞手续费、增值税。
- **错因**：（Q71 勾 D 手续费、漏 E 所得税，0/2）：E4。
- **记忆锚**：风险结构三件套「**违约、流动、税**」；见"手续费/增值税"直接划。

## F-07　国际金本位制：金自由、金储备、自动调、死汇率、锚铸币 ｜ 金本位 vs 布雷顿森林体系（含 Q96 布雷顿内容）

- **知识点归属**：第 01 章 · 国际货币体系（金本位）
- **知识点全解**：**〔D6-08〕** 国际金本位制的特征——
  - **黄金是主要的国际储备资产**（B ✓）
  - **存在国际收支的自动调节机制**（C ✓）—— 物价-现金流动机制（休谟机制）
  - **实行固定汇率制度**（D ✓）

  **〔D7-49〕** 两套体系一字之差定生死：

  - Q96 全解：ACDE 全对——A 经常账户放开+资本管制✓、C 双挂钩✓、D 永久 IMF✓、E 稀缺货币条款✓；B"以黄金为中心的**自发**固定"❌（那是金本位）
- **考法**：〔D6-08〕多选五句辨真假；"购买力平价"顶替"铸币平价"是最高频的偷换。 ｜ 〔D7-49〕选非题考特征归属；多选考体系内容
- **错因**：〔D6-08〕（Q72 勾 A、漏 C、D，0/2）：E4+E5。 ｜ 〔D7-49〕（Q11 选非勾了正确项 D；Q96 错选 B 漏选 E）：E3+E4+E5。
- **记忆锚**：〔D6-08〕金本位「**金自由、金储备、自动调、死汇率、锚铸币**」。 ｜ 〔D7-49〕"**美元中心=布雷顿、黄金中心=金本位**；'自发'是金本位的词、布雷顿='可调整'"

# 第 03 章 商业银行（F-20～F-42）

> 真题池 50 题 ｜ 你的错题 23 条 ｜ 大纲：新增经营四原则 ｜ 优先级 🔴 高（最厚+最弱）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 经营原则（★2026 教材新增四原则）

| 原则 | 内涵 |
|---|---|
| **"三性"原则** | **安全性（前提）、流动性（条件）、盈利性（目标）**——对立统一（F-23） |
| **审慎经营原则** | 风险管理、内控、资本约束、拨备充足（F-14/D6-14 审慎经营规则） |
| **分业经营原则** | 不得混业从事信托、证券、保险等非银行业务 |
| **金融创新原则** | 创新须**合法合规、风险可控、信息披露充分** |

配套：**"四自"经营原则**（自主经营、自担风险、自负盈亏、自我约束）（F-36）
⚠️ 三性的关系考"对立统一"——盈利性与安全性/流动性冲突，安全性与流动性一致。

### A2. 三大业务（归类题年年有）

| 业务 | 内容 | 题眼 |
|---|---|---|
| **负债业务** | 吸收存款、同业拆入、发行金融债券、向央行借款 | 存款是**银行的负债**（F-37） |
| **资产业务** | 贷款、债券投资、现金资产（准备金、存放同业） | 贷款是资产 |
| **表外业务** | 担保类、承诺类、金融衍生交易类、代理投融资服务类 | **不进资产负债表、形成或有负债** |

- **中间业务**（结算、代理、咨询、托管、银行卡、担保承诺）：**不占用自有资金、收手续费**
  ⚠️ 中间业务 ≠ 表外业务：中间业务强调"不占资金收手续费"，表外业务强调"不进表、有或有风险"，二者有交集

### A3. 资产负债管理

- **利率敏感性缺口** = 利率敏感性资产 − 利率敏感性负债
  - **正缺口**（资产多）→ 怕**降息**（资产收益降得更多）；**负缺口** → 怕**升息**（F-42）
- **久期缺口**、**流动性缺口**也是常用工具
- 流动性监管指标：**流动性覆盖率 LCR ≥100%、净稳定资金比率 NSFR ≥100%、流动性比例 ≥25%**

### A4. 资本与资本充足率（★高频计算+数字）

- 资本三级：
  - **核心一级资本**：实收资本/普通股、资本公积、盈余公积、一般风险准备、未分配利润、少数股东资本可计入部分
  - **其他一级资本**：优先股、永续债
  - **二级资本**：二级资本债、超额贷款损失准备
  - ⚠️ **扣减项三件套**：**商誉**、其他无形资产（土地使用权除外）、对未并表金融机构的资本投资（F-34）
- **资本充足率三档（我国）**：核心一级 **≥5%**、一级 **≥6%**、总资本 **≥8%**（F-22）
- **巴塞尔 III 裸标准**：核心一级 4.5% / 一级 6% / 总 8%，另加储备资本缓冲 2.5%、逆周期 0-2.5%、系统重要性 1-3.5%
- **杠杆率**：我国 **≥4%**（巴塞尔 3%）
- 资本补充渠道：内源（利润留存）＋外源（增资扩股、发行优先股/永续债/二级资本债）

### A5. 监管指标数字串（★全在这一块，必须一次记死）

| 指标 | 数字 |
|---|---|
| 单一客户贷款集中度 | ≤ **10%** |
| 集团客户授信集中度 | ≤ **15%** |
| 不良贷款率 | ≤ **5%** |
| 不良资产率 | ≤ **4%** |
| **成本收入比** | ≤ **45%**（F-31） |
| 存款保险最高偿付 | **50 万元** |
| 村镇银行最低注册资本（县/区） | **100 万元**，且须有发起行（F-25） |
| 金融租赁监管指标 | 50 / 30 / 30 / 100（F-29） |

### A6. 内控与治理

- **内控四则**：制衡、审慎、全覆盖、相匹配（F-26）
- **董监高任职资格**：合规、品行、履历、独立（F-28）
- **风险管理流程**（识别→计量→监测→控制）≠ **风险管理策略**（规避/分散/对冲/转移/补偿/承受）——**对冲属策略不属流程**（F-41）

### A补充 · 缺口加深：杠杆率的计算

- **杠杆率 = 一级资本净额 ÷ 调整后表内外资产余额 × 100%**；我国要求 **≥4%**（巴塞尔 ≥3%）
- 特点：**风险不敏感**（不按风险权重加权），是资本充足率的**补充指标**
- ⚠️ 作用：防止银行通过"把资产腾挪到低风险权重科目"套利压低资本要求
- 与资本充足率的区别：分母是**表内外全部资产余额**（不加权），不是风险加权资产

## F-26　商业银行内控四则：制衡、审慎、全覆盖、相匹配

## F-30　商业银行的三个特点

> 题源：D6-27

- **知识点归属**：第 03 章 · 商业银行概述
- **知识点全解**：- ✓ **A**：在所有金融机构中，商业银行是**历史最悠久、资本最雄厚、体系最庞大、业务范围最广**的金融机构
  - ✓ **B**：与其他金融机构相比，最明显的特征是**吸收活期存款、创造信用货币**
  - ✓ **C**：以**吸收存款、发放贷款、办理结算和金融服务**为主要业务，以**盈利为目的**的金融企业
  - ❌ **D**：构成货币供给或交换媒介重要组成部分的是**存款货币**（"各项存款和所有者权益"把所有者权益混进来，表述错位）

# 第 04 章 保险公司（F-43～F-48）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 保险功能与原则

- **功能**：经济补偿（基本）、资金融通、社会管理
- **四大原则**：**最大诚信原则、保险利益原则、近因原则、损失补偿原则** → 口诀「**诚信·利益·近因·补偿**」
  ⚠️ 干扰手法：把"最大诚信"换成"自愿"、"损失补偿"套到人身险（人身险是**给付**不是补偿）

### A2. 保险合同主体（★配对题）

| 主体 | 是谁 | 干什么 |
|---|---|---|
| **保险人** | **保险公司** | 收取保费、承担赔付责任（**承保人签字**） |
| **投保人** | 买保险的人 | **交保费** |
| **被保险人** | 受保障的标的（人/财产） | 享有保险金请求权 |
| **受益人** | 投保人指定 | 领取保险金 |

（详见 F-44）

### A3. ★2026 新增三块（承保 / 理赔 / 再保险）

- **保险营销四要素**（4P）：**产品、价格、渠道、促销**
- **承保**：承保人职能=核保、风险评估、签发保单；承保过程=投保申请→核保→签单→**续保**（续保规则：可无条件续保 vs 可拒保）
- **理赔程序**（顺序题）：**报案（出险通知）→ 查勘定损 → 审核单证 → 责任认定 → 理算 → 赔付**
- **再保险业务种类**：
  - **比例再保险**：成数再保险、溢额再保险
  - **非比例再保险**：超额赔款再保险、赔付率超赔再保险
- **再保险安排方式三种**（选非题高频）：**临时再保险、合同再保险、预约再保险**（F-45）

### A4. 保险资金运用（★2026 改口径：特点、形式和策略）

- 可投：银行存款、债券（国债/金融债/企业债）、股票与基金、不动产、股权投资
- **不可投**：**不得直接从事房地产开发建设、不得向企业发放贷款**（F-47）
- 原则：**安全性 > 流动性 > 收益性**，分散投资、资产负债匹配

### A5. 信托（本章含信托，★2026 仍考）

- **信托当事人三方**：委托人、受托人、受益人（F-46）
- **信托财产**：名义所有权与权利**都归受托人**；范围=**装权利不装债务**（F-43）
- **财富管理服务信托三件套**：家族信托、保险金信托、遗嘱信托（F-48）

### A补充 · 缺口补空：承保过程 / 承保管理 / 续保 / 理赔责任认定 / 再保险责任分担

- **承保过程**（顺序题）：**投保申请 → 风险评估（核保）→ 承保决策 → 签单出单 → 续保**
- **承保决策四种**：**正常承保、加费承保、除外责任承保（批单除外）、拒保**
- **承保管理**：承保标准制定 → **核保权限分级**（分级授权）→ 风险选择（优选/劣选/拒保）→ 再保安排 → 承保质量监控与考核
- **续保规则**：
  - **保证续保**：保险公司**不得因被保险人健康状况变化或历史理赔**拒保、加费
  - **非保证续保**（一年期短期险）：期满需重新核保，公司可拒保或调整费率
  - ⚠️ 题眼：见"不得因健康状况变化拒绝续保"＝**保证续保**
- **理赔责任认定逻辑**：按**近因原则**判断致损的**最直接、最有效、起决定作用的原因**是否属于保险责任范围 → 属于才赔；**多因连续**看最先发生的、**多因间断**看新介入的独立原因
- **再保险责任分担模式**（★2026 新增，原缺口）：
  | 模式 | 分担方式 | 题眼 |
  |---|---|---|
  | **成数再保险**（比例） | 按**固定比例**分出，保额、保费、赔款同比例分 | 比例固定 |
  | **溢额再保险**（比例） | 先定**自留额**，超过部分按比例分出（可分层） | 见"自留额/线数" |
  | **超额赔款再保险**（非比例） | 赔款超过**起赔点（自负额）**以上由再保人承担 | 见"起赔点/超赔" |
  | **赔付率超赔再保险**（非比例） | 年度**赔付率**超过约定水平以上由再保人承担 | 见"赔付率" |
  ⚠️ 判别：**比例类按"保额"分，非比例类按"赔款/赔付率"分**

## F-43　信托财产：名义和权利都在受托人（🔴 本章全灭，最高优先） ｜ 信托财产范围（装权不装债）

- **记忆锚**：〔D6-28〕信托财产「**名义在受托人、权利归受托人**」；受益人只拿钱。 ｜ 〔D7-19〕"信托装'**权**'不装'**债**'"

# 第 05 章 证券公司与基金管理公司（F-49～F-64）

> 真题池 29 题 ｜ 你的错题 16 条 ｜ 大纲：内容有增加 ｜ 优先级 🔴 高（最弱）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 证券公司

- **性质**：金融中介机构 + 金融机构；**四大身份**：经纪商（**代客**）、做市商、自营商、承销商（F-54）
- **主要业务**：证券经纪、证券承销与保荐、证券自营、资产管理、融资融券、证券投资咨询、代销金融产品、IB 业务
- **主要股东**：持股 **5% 以上**（F-53）
- **内控原则**：**健全、合理、制衡、独立**（F-57）
- **市场退出监管**：由**证监会**负责（F-58）
- **任职资格核准范围**：高管需核准，**部门负责人不需要**（F-61）
- **证券投资咨询准入**：专职人员 **5 人**（F-63）

### A2. 证券投资基金三主体（★必考）

| 主体 | 是谁 | 干什么 |
|---|---|---|
| **基金份额持有人** | 投资者 | **所有者**，享有收益与监督权 |
| **基金管理人** | **基金管理公司** | 募集、投资运作、信息披露、收益分配（**可参与收益分配** F-59） |
| **基金托管人** | **商业银行** | 保管财产、复核净值、监督投资、办理清算 |

⚠️ 托管人**不保证收益、不承担亏损**（F-56）；管理人**不保管资金**（钱在托管行）

### A3. 基金类型判据（数字分类法）

| 判据 | 结果 |
|---|---|
| 80% 以上资产投**股票** | 股票型基金 |
| 80% 以上资产投**债券** | 债券型基金 |
| 仅投货币市场工具 | 货币市场基金 |
| 运作方式 | 封闭式 / 开放式 |
| 组织形式 | **契约型 / 公司型**（**我国公募基金=契约型** F-62） |
| 募集方式 | 公募 / 私募 |

- **货币市场基金**：高流动性资产占比 **≥5%**（教材口径，F-49）

### A4. ★2026 新增：基金费用种类与计算（必考计算）

| 费用 | 付给谁 | 计提 |
|---|---|---|
| **管理费** | **基金管理公司** | 按前一日基金资产净值 × 年费率 ÷ **365** 逐日计提，**按月支付** |
| **托管费** | **托管银行** | 同上 |
| 销售服务费 | 销售机构 | 同上（C 类份额常见） |
| 申购费 / 赎回费 | 销售机构 / 基金财产 | 一次性，按申购/赎回金额或份额 |
| 交易费用 | 券商/交易所 | 发生时计入当期损益 |

**公式**：每日应计提费用 = **前一日基金资产净值 × 年费率 ÷ 365**
⚠️ 题眼：**管理费找基金公司、托管费找托管行**（见 F-52）；分母按 **365 天**不是 360

### A5. 基金管理公司与托管人职责

- **管理公司职责**：依法募集基金、投资运作、信息披露、收益分配、办理份额登记
- **托管人法定职责**：安全保管基金财产、开设账户、复核审查净值与申购赎回价格、监督投资运作、办理清算交割、保存资料、信息披露（F-56）
- **基金销售机构名单**：**商业银行、证券公司、期货公司、保险公司、证券投资咨询机构、独立基金销售机构** → 口诀「**银证期保咨独**」（F-64）

### A6. 私募资产管理（★数字钉）

- **合格法人投资者**：净资产 **≥1000 万元**（F-21）
- 私募资管三数字钉：**1000 万 / 90 天 / 30-40-100 万**（F-21）
- **推介渠道**：**不得通过公开媒体（电视、广播、互联网公众平台、公开传单）推介**（F-60）
- **承销方式**：只有**代销与包销**（含余额包销）两种（F-55）

### A补充 · 缺口补空：证券投资基金的特点 + 托管人市场准入

- **证券投资基金五大特点**（大纲原文"理解…特点"，原缺口）：
  1. **集合理财、专业管理**（小额资金汇集，专家运作）
  2. **组合投资、分散风险**（"不把鸡蛋放一个篮子"）
  3. **利益共享、风险共担**（**基金不保本、不保收益**——这是与存款/保险的本质区别）
  4. **独立托管、财产独立**（**基金财产独立于管理人、托管人的固有财产**，不被其债权人追偿）
  5. **严格监管、信息透明**（强制信息披露、净值每日公布）
  ⚠️ 干扰手法：把"保本保收益""管理人自有财产"塞进特点里——**全是错项**

- **基金托管人市场准入条件**（★大纲明确要求"熟悉…市场准入条件"，原缺口）：
  1. 净资产与风险控制指标符合规定（商业银行须**资本充足率达标**）
  2. 设有**专门的基金托管部门**
  3. 取得基金从业资格的人员**不少于法定人数**，核心业务岗位具备相应资质
  4. 具备**安全保管基金财产**的条件（独立托管系统、安全高效的清算交割系统）
  5. 有符合要求的营业场所，配备**独立的监控系统**
  6. **最近 3 年无重大违法违规记录**
  7. 须经**中国证监会会同国务院银行业监督管理机构核准**（我国托管人以**商业银行**为主）
  ⚠️ 题眼：见"3 年无重大违规""专门托管部门""双头核准"＝托管人准入

## F-55　证券承销方式：只有代销与包销（含余额包销）

## F-56　基金托管人职责：管钱、出意见、办清算、披露（不保收益）

- **知识点全解**：《证券投资基金法》规定的托管人职责：

# 第 07 章 金融资产定价（F-79～F-85）

> 真题池 9 题 ｜ 你的错题 7 条 ｜ 大纲：★★★ 核心大改 ｜ 优先级 🔴 高（★★★大改+真题稀）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 收益与风险的度量

- 预期收益率 **E(R) = Σ pᵢ · Rᵢ**；风险 = **方差 σ² / 标准差 σ**
- 两项资产组合：σ²p = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρ₁₂σ₁σ₂
- **相关系数 ρ**：ρ = +1 完全正相关（**分散化无效**）；ρ = −1 可构造无风险组合
- ⚠️ 铁律：**分散化只能降低非系统风险（特有风险），不能降低系统风险（市场风险）**
- 有效边界（有效前沿）：给定风险下收益最高的组合集合；只有**多种风险资产**才形成曲线（F-81）

### A2. ★★★ 三大绩效指数（2026 核心新增：夏普 + 特雷诺 + 詹森）

| 指数 | 公式 | 分母含义 | 适用 |
|---|---|---|---|
| **夏普比率** Sharpe | **(Rₚ − R_f) / σₚ** | **总风险（标准差）** | 非充分分散化组合、评价全部风险 |
| **特雷诺指数** Treynor | **(Rₚ − R_f) / βₚ** | **系统风险（β）** | 已充分分散化的组合 |
| **詹森指数** Jensen | **α = Rₚ − [R_f + βₚ(Rₘ − R_f)]** | 无（**超额收益的差值**） | 绝对业绩，α>0 跑赢市场 |

⚠️ 秒杀配对：**夏普用 σ、特雷诺用 β、詹森是个差**；三者都是**越大越好**
⚠️ 干扰手法：把夏普的分母换成 β、把特雷诺的分母换成 σ——**分母是唯一区分点**

### A3. CAPM / 因素模型 / APT

- **资本市场线 CML**（有效组合）：E(Rp) = Rf + [(Rm − Rf)/σm]·σp
- **证券市场线 SML / CAPM**（任一资产）：**E(Rᵢ) = R_f + βᵢ(Rₘ − R_f)**
  - βᵢ = Cov(i, m) / σ²ₘ；**β 衡量系统风险**；β=1 与市场同步，β>1 激进
  - ⚠️ CAPM 求 β：**β = (组合收益率 − 无风险利率) ÷ (市场收益率 − 无风险利率)**，分子分母**都减 Rf**（F-84）
- **因素模型**：Rᵢ = αᵢ + βᵢF + εᵢ（单因素）；多因素模型加入多个因子
- **套利定价理论 APT**：E(Rᵢ) = R_f + βᵢ₁λ₁ + … + βᵢₖλₖ（**多因素、不要求市场组合**）
  ⚠️ CAPM 是 APT 的特例（单因子=市场因子）

### A4. 债券与股票估值

- **债券**：价格 = 未来现金流（利息 + 面值）按市场利率折现之和
  - **市场利率↑ → 债券价格↓（反向）**；期限越长、票面利率越低 → 对利率越**敏感**
- **股票**：
  - 零增长模型 **P = D / r**
  - 固定增长（戈登）模型 **P = D₁ / (r − g)**，反求 **r = D₁/P + g**（F-80）
  - **市盈率 P/E = 股价 ÷ 每股收益**
- **有效市场三形态**：弱式（历史价格信息）→ 半强式（全部公开信息）→ 强式（含内幕信息）

### A5. ★2026 新增：期权价值结构与影响因素

- **期权价值 = 内在价值 + 时间价值**
- 五个影响因素：**标的资产市场价格、执行价格、到期期限、标的资产波动率、无风险利率**（F-82）
- **看涨期权**：买方付期权费，**最大损失=期权费（有底）、收益理论无限**；行权条件 **市价 > 执行价**（F-85）
  ⚠️ 干扰："买方最大收益是期权费"——那是**卖方**

### A6. ★2026 新增：看涨看跌期权平价关系

**欧式期权平价**：**C + K·e^(−rT) = P + S**
其中：C=看涨期权价格、P=看跌期权价格、S=标的资产现价、K=执行价格现值（PV(K) = K·e^(−rT)）
变形记忆：**C − P = S − PV(K)**（买看涨卖看跌 = 买标的 + 借钱）
⚠️ 只适用于**欧式期权**（不能提前行权）；美式期权只能写成不等式关系

### A补充 · 缺口加深：三指数算例 + 远期/期货/期权定价方法

**① 三大指数算例（同一组数据，一次算清）**
设：组合收益率 Rp = 12%，无风险利率 Rf = 3%，市场收益率 Rm = 10%，组合标准差 σp = 15%，组合 β = 1.2

| 指数 | 代入 | 结果 |
|---|---|---|
| **夏普** | (12% − 3%) ÷ 15% | **0.60** |
| **特雷诺** | (12% − 3%) ÷ 1.2 | **7.5** |
| **詹森 α** | 12% − [3% + 1.2 × (10% − 3%)] = 12% − 11.4% | **+0.6%（跑赢）** |

⚠️ 三个都用**同一组数据**考时，分母是唯一区分点：**σ / β / 差值**

**② 远期与期货定价（无套利 + 持有成本）**
- **无风险套利原理**：远期价格 = 现货价格 + 持有成本（**持有成本模型**）
- 连续复利式：**F = S · e^((r + c) · T)**（r=无风险利率，c=存储/保险等持有成本率，T=期限）
- 含便利收益 y：**F = S · e^((r + c − y) · T)**
- 黄金等无收益资产：**F = S · e^(rT)**
- ⚠️ **期货价格 ≈ 同期限远期价格**（当利率确定时两者相等；利率随机时有差异，中级层面考"约相等"）
- 判别：**溢价（Contango）= F > S**（持有成本为正的正常市场）；**现货溢价（Backwardation）= F < S**（便利收益高）

**③ 期权定价方法（中级层面考到什么程度）**
- **二叉树模型**：单步 u / d 与**风险中性概率 p* = (e^(rT) − d) / (u − d)**，到期 payoff 折现
- **布莱克-斯科尔斯**：只需知道**五个输入**——标的价 S、执行价 K、无风险利率 r、波动率 σ、到期时间 T；**σ 越大、T 越长 → 期权越贵**
- ⚠️ 中级经济师**不要求手算 BS 公式**，重点考：**输入变量有哪些、各变量变动对期权价值的方向影响**、以及**看涨看跌平价**

# 第 09 章 货币供求与货币均衡（F-89～F-100）

> 真题池 24 题 ｜ 你的错题 12 条 ｜ 大纲：★ 新增 IS-LM ｜ 优先级 🔴 高（IS-LM 新增）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 货币需求理论（四家配对，高频）

| 理论 | 公式 / 核心 | 题眼 |
|---|---|---|
| **费雪交易方程式** | **MV = PT**（V、T 短期稳定 → **M 决定 P**） | 见"货币数量论/交易" |
| **剑桥方程式** | **Md = k·P·Y**（重视**货币作为资产**的选择） | 见"现金余额" |
| **凯恩斯三动机** | 交易动机、预防动机（**与收入正相关**）、投机动机（**与利率负相关**） | 见"利率↑→投机需求↓"（F-91） |
| **弗里德曼现代货币数量论** | 货币需求是**恒久收入**的函数，利率影响很小 | 见"恒久收入"（F-99） |

- **流动性陷阱（凯恩斯陷阱）**：利率极低时投机需求无限大 → 货币需求曲线**平行横轴** → **货币政策失效**，只能靠财政政策（F-89）

### A2. 货币层次（★年年考）

- **M0 = 流通中现金**
- **M1 = M0 + 单位活期存款**（教材口径）（F-96）
- **M2 = M1 + 定期存款 + 储蓄存款 + 其他存款 + 证券公司客户保证金**
- **M3 = M2 + 大额可转让定期存单 + 金融债券 + 商业票据**（**大额存单是 M3 独有**）（F-98）
  ⚠️ 2024 年起我国 M1 统计口径修订，纳入**个人活期存款**与**非银行支付机构客户备付金**——**若教材已更新，以教材为准**（新大纲年份教材大概率已收）

### A3. 货币供给与货币乘数（★计算）

- **基础货币 B = 流通中现金 + 存款准备金**（央行可控）
- **货币供给 Ms = B × m**
- **货币乘数 m = (1 + c) / (r_d + r_e + c)**（c=现金漏损率、rd=法定准备金率、re=超额准备金率）
- ⚠️ 三个负相关：**rd↑→m↓（央行定）、re↑→m↓（银行定）、c↑→m↓（储户定）**；**乘数越高，货币供给越大**（F-90）
- 央行改变基础货币三渠道：**公开市场操作、再贴现再贷款、外汇占款**（F-100）

### A4. ★2026 新增：IS-LM 与货币均衡

- **IS 曲线**：产品市场均衡（I = S），**向右下方倾斜**（利率↓ → 投资↑ → 产出↑）
- **LM 曲线**：货币市场均衡（L = M），**向右上方倾斜**（产出↑ → 交易需求↑ → 利率↑）
- **交点 = 两个市场同时均衡**（产品市场 + 货币市场）
- **四区域判据**（⭐必考方向题）：
  - **IS 右上方** = 产品市场**超额供给**；IS 左下方 = 超额需求
  - **LM 左上方** = 货币市场**超额供给**；LM 右下方 = 超额需求
  - 口诀「**IS 上产剩、LM 上钱剩**」（F-95）
- 移动：**扩张性财政政策 → IS 右移**；**扩张性货币政策 → LM 右移**

### A5. 通货膨胀与通货紧缩

- **类型**：需求拉上型、成本推进型（**原材料涨价 = 成本推进** F-97）、结构型
- **分级**：**温和通胀 < 10%**、**奔腾通胀（两位数）**、**恶性/超级通胀（失控）**（F-92）
- **治理**：
  - 紧缩货币（**卖国债、提准、提息**）（F-112）
  - 供给学派：**减税、简政放权、削减福利、适度控制货币供给**（F-94）
  - 收入政策（工资-物价管制）、指数化
- 通货紧缩：物价持续下降、货币供应量下降、经济衰退；治理=扩张性财政+货币

### A补充 · 缺口补空：存款货币创造过程 + 通货紧缩

**① 存款货币创造过程（★大纲"掌握"，原缺口）**
- **两个前提**：**部分准备金制度**（不必全额留存）＋ **非现金结算（转账结算）**（贷款不提现、转为存款）
- **过程（链式）**：原始存款 → 留足**法定准备金**（其余为超额准备）→ 超额部分**贷出** → 借款人用于支付 → 收款人存入银行形成**派生存款** → 再提法定准备 → 再贷 → …… 逐级派生，收敛
- **公式（简单乘数，只考虑 rd）**：
  - **存款总额 D = 原始存款 ÷ rd**
  - **派生存款总额 = 原始存款 × (1/rd − 1)**
- **完整存款乘数**：**k = 1 / (rd + c + e)**（c=现金漏损率、e=超额准备金率）
- **货币乘数**：**m = (1 + c) / (rd + c + e)**（比存款乘数多"现金漏损"这一层）
- ⚠️ 三个负相关：rd↑、c↑、e↑ → 乘数↓；**央行定 rd、银行定 e、储户定 c**
- ⚠️ 派生存款的"源头"是**原始存款**（央行投放的基础货币），不是贷款凭空产生

**② 通货紧缩（大纲"分析类型、成因及治理"）**
- **定义**：物价总水平**持续下降**（通常连续 6 个月以上），伴随货币供应量增速下降、经济衰退
- **类型**：需求不足型｜供给过剩型（产能过剩）｜结构性｜**债务-通缩型**（费雪：物价跌→实际债务加重→抛售→再跌）
- **成因**：总需求不足、货币供应收缩、生产能力过剩、债务负担加重、预期自我实现（持币待购）
- **治理（与通胀反着来）**：**扩张性货币政策**（降准、降息、买入债券）+ **扩张性财政政策**（增支减税）+ 化解过剩产能 + 稳定通胀预期
- ⚠️ 危害：债务负担加重、企业利润下滑、失业上升、"流动性陷阱"下货币政策失效

## B. 错题知识点（F-89～F-100）

## F-89　流动性陷阱：货币需求曲线躺平（平行横轴）

> 题源：D6-18

- **知识点归属**：第 09 章 · 凯恩斯流动性偏好理论
- **知识点全解**：当利率降到极低水平时，人们预期利率只会上升、债券价格只会下跌，于是**无论增加多少货币都会被持有**（投机性货币需求趋于无穷大）——货币需求曲线变成**一条平行于横轴的直线**。此时货币政策失效（流动性陷阱），只能靠财政政策。

  ⚠️ 平行于**纵轴**（A）是"货币需求完全无利率弹性"的错误画法；向下/向上倾斜（B/C）是正常状态。
- **考法**：单选问"发生流动性陷阱时货币需求曲线是（）"。
- **错因**：（Q20 选 C 向上倾斜）：E2。
- **记忆锚**：陷阱 = **躺平（横轴）**；「利率极低→需求无穷→货币政策失效」。

## F-90　货币乘数：三个负相关 + 乘数越高供给越大

> 题源：D6-53

- **知识点归属**：第 09 章 · 货币供给（货币乘数）
- **知识点全解**：货币供应量 = 基础货币 × 货币乘数。货币乘数与三个比率都**负相关**：

| 变量 | 变动 | 货币乘数 |
|---|---|---|
| **现金比率（现金漏损率）** | 越低 | **越大**（Q52 答案 B） |
| **超额存款准备金率** | 越低 | 越大 |
| **法定存款准备金率** | 越低 | 越大 |

  逻辑：漏损少、锁定少，银行可派生的存款就多。
  ⚠️ 两个反坑：①「乘数越高，货币供给量越**小**」（Q97 的 A）❌ —— 供给 = 基础货币 × 乘数，乘数越大供给**越大**；②「与存贷款**基准利率**呈正相关」（E）❌——乘数公式里没有基准利率。
- **考法**：单选考"现金比率越低乘数如何"；多选考"关于货币乘数的说法正确的有"（三负相关全勾）。
- **错因**：（Q52 选 D 越小：E1 方向反转；Q97 勾 A：E4）。
- **记忆锚**：「**漏得少、锁得少、乘得多**」；乘数三负=**现金、超额、法定**；乘数越高供给越大。

## F-91　凯恩斯货币需求三动机：交易预防看收入、投机看利率（反向）

# 第 10 章 开放经济均衡（F-101～F-111）

> 真题池 19 题 ｜ 你的错题 11 条 ｜ 大纲：★ 新增 IS-LM-BP/米德冲突/三元悖论 ｜ 优先级 🔴 高（三元悖论新增）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 国际收支平衡表（★账户归类题）

- **经常账户**：**货物、服务、初次收入（含投资收益）、二次收入（经常转移）**
- **资本与金融账户**：资本账户（资本转移、非生产非金融资产）+ **金融账户**（**直接投资、证券投资、其他投资、储备资产**）
- **净误差与遗漏**：平衡项
- **编制原则**：**复式记账（借贷记账）**，按**成交时的市场价格**计价（F-110）
- 影响因素三方向（F-101）：**国民收入（进口↑→逆差）、利率、汇率（本币贬值→出口↑）**

### A2. 国际收支失衡与调节

- 差额层次：**贸易差额 → 经常账户差额 → 基本差额 → 总差额**
- 失衡成因：**临时性、周期性、结构性、收入性、货币性**
- 调节措施：**财政政策、货币政策、汇率政策、直接管制、国际借贷、国际经济合作**
  ⚠️ 政策搭配：逆差 → 紧缩（减需求）+ 本币贬值（促出口）

### A3. 国际储备（★多选题高频）

- **构成四件套**：**货币性黄金、外汇储备、在 IMF 的储备头寸、特别提款权（SDR）**
- **作用**：弥补国际收支逆差、干预外汇市场**维持本币汇率稳定**、**维持国际资信**（对外功能）（F-102）
- **管理**：规模管理（适度）+ 结构管理（币种与资产分散）
- ⚠️ **人民币计价外债不消耗外汇储备**（F-104）；**FDI 不算外债**（F-105）

### A4. ★2026 新增三件套（IS-LM-BP / 米德冲突 / 三元悖论）

- **BP 曲线**：国际收支平衡时 (i, Y) 的组合；**向右上方倾斜**
  - **资本流动性越强 → BP 越平坦**；**资本完全流动 → BP 为水平线**（利率一偏离均衡就巨量流动）
  - BP 曲线**上方**＝国际收支**顺差**（利率高于均衡→资本流入）；**下方**＝逆差（F-103）
- **米德冲突**：**固定汇率**下，仅用支出调整政策（财政/货币）无法同时实现**内部均衡（充分就业+物价稳定）**与**外部均衡（国际收支平衡）**，必须搭配**支出转换政策（汇率/关税）**
- **三元悖论（不可能三角）**：**货币政策独立性、汇率稳定、资本自由流动——三选二**
  - 货币局制 = 汇率已锁死 → 只能在"独立货币政策 + 资本管制"或"资本自由 + 放弃独立"里挑（F-111）
  - 我国：汇率有管理的浮动 + 货币政策独立 + 资本项目部分管制

### A5. 国际债券与货币可兑换

- **判别口诀**：**计价货币 ≠ 发行地货币 → 欧洲债券**；相等且发行人为外国 → **外国债券**（在华人民币=**熊猫债**；美国=扬基债；日本=武士债）（F-109）
- **IMF 协定第八条款**的可兑换 = **经常项目可兑换**（不是完全可兑换）（F-108）
- **SDR**：IMF **无偿分配**、本质是**记账单位**、**不能直接用于贸易或非贸易支付**；篮子五币 = **美元、欧元、人民币、日元、英镑**（F-106）

### A补充 · 缺口补空：国际资本流动 + 储备规模/结构管理 + 外资外债政策

**① 国际资本流动的原因及影响（★大纲"分析"，原缺口）**
- **原因**：国际利率差异（逐利）｜汇率变动预期（套利/避险）｜分散风险（资产组合）｜国际分工与直接投资（产业链）｜资本管制放松与金融自由化｜投机冲击
- **分类**：
  - **长期资本流动**：**直接投资（FDI）**、证券投资（股票/债券）、国际中长期贷款
  - **短期资本流动**：**贸易性**（贸易信贷）、**投机性**（热钱）、**保值性**（资本外逃）、**套利性**（利差/汇差）
- **正面影响**：弥补储蓄-投资缺口、优化资源配置、技术与管理溢出、促进金融市场深化
- **负面影响**：冲击汇率稳定、催生资产泡沫、加剧外债风险、削弱货币政策独立性（**三元悖论**）、引发货币危机
- **管理思路**：外债规模与结构管理、资本项目可兑换**循序渐进**、宏观审慎工具（跨境融资参数、托宾税类）
  ⚠️ 题眼：**FDI 属长期资本流动、不算外债**；"热钱"＝短期投机性资本

**② 国际储备的规模管理与结构管理**
- **规模管理（适度规模）**：满足**3-4 个月进口额**（特里芬经验法则）+ 外债还本付息需求 + 干预外汇市场需要
  - 储备**过多**：机会成本高、本币投放增加带来通胀压力；**过少**：偿付与干预能力不足
- **结构管理**：
  - **币种结构**：分散化，与**贸易结算币种、外债币种**匹配
  - **资产结构**：在**流动性（随时可干预）**与**收益性**之间权衡

**③ 外资与外债管理政策**
- **外资**：准入**负面清单**、《外商投资产业指导目录》（鼓励/限制/禁止）、**并购安全审查**、准入前国民待遇
- **外债**：**规模管理**（余额/额度）＋**结构管理**（期限、币种、利率结构，短债占比控制）＋ **全口径跨境融资宏观审慎管理**＋ 外债登记与用途管理

## F-101　国际收支影响因素：三个方向一次记清

# 第 11 章 中央银行与金融调控（F-112～F-123）

> 真题池 24 题 ｜ 你的错题 12 条 ｜ 大纲：★ 新增结构性工具/双支柱 ｜ 优先级 🔴 高（双支柱新增）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. 中央银行（性质 / 职能 / 业务）

- **性质**：**发行的银行、银行的银行、政府的银行** → 口诀「**发银政**」
  ⚠️ **独占货币发行权是央行区别于商业银行的最基本标志**（F-117）
- **组织形式**：我国为**一元式**（单一央行制，总分行体制）（F-116）；美国为**二元式**（联邦+12 家地区联储）
- **职能边界**：**国债发行归财政、货币发行归央行**；**经理国库、持有管理外汇储备与黄金 = 国家的银行**（F-117）
- **资产负债表**（★年年考方向）：
  - **资产方**：国外资产（外汇、黄金）、**对政府债权（政府债券）**、**对其他存款性公司债权（再贴现/再贷款）** → **放款 = 资产**
  - **负债方**：**储备货币（通货发行 + 存款准备金）**、政府存款、发行债券、国外负债 → **吸收 = 负债**
  - 口诀「**通货发行是负债、政府债券是资产**」（F-113）

### A2. 货币政策目标体系

| 层级 | 内容 |
|---|---|
| **最终目标** | 币值（物价）稳定、充分就业、经济增长、国际收支平衡；**我国＝保持货币币值稳定，并以此促进经济增长** |
| **中介目标** | **货币供应量（M2）、社会融资规模、市场利率** |
| **操作目标** | **基础货币、存款准备金、超额准备金（超储率）** |

⚠️ 货币政策性质：**宏观、调节总需求、间接调控、兼顾长短**（F-122）

### A3. 货币政策工具（★归类题高频）

- **一般性工具（三大法宝）**：**法定存款准备金率、再贴现政策、公开市场业务**（F-119）
  - **逆回购属于公开市场业务 = 一般性工具**（F-114）
- **选择性工具**：消费者信用控制、证券市场信用控制、不动产信用控制、优惠利率
- **其他工具**：直接信用控制（信用配额、利率限制、流动性比率）、间接信用指导（道义劝告、窗口指导）
- **我国创新/新型工具**：**SLF（常备借贷便利）、MLF（中期借贷便利）、PSL（抵押补充贷款）、SLO、TLF、CRA**（F-115）
- **★2026 新增：结构性货币政策工具**：**支农支小再贷款、碳减排支持工具、科技创新再贷款、普惠养老专项再贷款、交通物流专项再贷款、设备更新改造专项再贷款**
  ⚠️ 结构性工具特点：**精准滴灌、先贷后借、有激励约束机制**
- 宽松操作三招：**降准、降息、买入债券（投放流动性）**；紧缩反之（F-118）

### A4. 传导机制

**政策工具 → 操作目标 → 中介目标 → 最终目标**
传导渠道：**利率渠道、信贷渠道、资产价格渠道、汇率渠道**

### A5. ★2026 新增：宏观审慎政策与"双支柱"

- **宏观审慎政策**：目标是**防范系统性金融风险、维护金融稳定**；**时间维度**（逆周期调节：逆周期资本缓冲、LTV 上限、杠杆率动态）＋**空间维度**（系统重要性金融机构附加资本、跨机构风险传染）
- **关键工具**：**MPA 宏观审慎评估（七个方面）**（F-120）、LCR/NSFR、跨境融资宏观审慎调节参数、首付比（LTV）上限
- **"双支柱"协同逻辑**：
  - **货币政策**管**总量与物价**（逆周期调节总需求）
  - **宏观审慎政策**管**杠杆与系统性风险**（防金融顺周期与跨机构传染）
  - 二者**互补不替代**：物价稳不代表金融稳，需双管齐下
- **再贷款**：比重**越来越小**（逐步被 MLF/结构性工具替代）（F-123）

### A补充 · 缺口补空：我国货币政策实践（★2026 大纲新增"理解近年来我国货币政策的实践"）

- **调控框架转型**：从**数量型**（M2、信贷规模、社会融资规模）为主 → 向**价格型**（政策利率引导）为主转变
- **政策利率体系**：**MLF 利率（中期政策利率）→ LPR（贷款市场报价利率）→ 贷款利率**；**DR007** 为市场基准利率观测锚
  - **LPR 改革（2019）**：报价行在 MLF 利率上**加点**报价，贷款利率**锚定 LPR**（打破贷款基准利率隐性下限）
- **利率走廊**：**SLF 利率（上限）** + **超额准备金利率（下限）**，把短期利率框在走廊内
- **近年实践基调**：**稳健的货币政策要灵活适度、精准有效**；总量（降准、降息、结构性降息）+ 结构（支农支小再贷款、碳减排支持工具、科创/普惠养老/设备更新专项再贷款）**组合发力**
- **不搞"大水漫灌"**：强调**精准滴灌、直达实体经济**
- **金融强国 / "强大的货币"**：币值**对内稳定（物价稳）+ 对外稳定（汇率基本均衡）**、可自由使用、跨境支付体系（CIPS）与金融基础设施完备
  ⚠️ 题眼：见"近年来我国货币政策实践"→ 选**价格型转型 / LPR 改革 / 结构性工具精准滴灌 / 不搞大水漫灌**；见"数量型为主"＝过时表述错项

# 第 12 章 金融监管（F-124～F-125）

> 真题池 3 题 ｜ 你的错题 2 条 ｜ 大纲：新增危机演化/巴塞尔 ｜ 优先级 🔴 高（真题仅3）

## A. 本章必考骨架（背完这些，本章基础分不丢）

### A1. ★2026 新增：金融脆弱性 → 金融危机的演化路径

**金融脆弱性（高杠杆、期限错配、信息不对称、资产泡沫）**
→ **外部冲击（利率上升/资产价格下跌/违约事件）**
→ **资产价格暴跌、机构资产负债表恶化**
→ **去杠杆 + 抛售资产 → 流动性枯竭**
→ **机构倒闭 / 存款人挤兑**
→ **风险跨机构跨市场传染（多米诺效应）**
→ **系统性金融危机**（实体经济衰退）

### A2. 金融危机分类与危害

- **分类**：**货币危机**（本币大幅贬值）、**银行危机（银行业危机）**、**债务危机**（主权/外债违约）、**系统性金融危机**
- **危害**：金融机构大量倒闭、金融资产价格暴跌、**实体经济衰退与失业上升**、财政负担加重（救市成本）、社会财富再分配（F-125）

### A3. 金融监管目标、原则与理论

- **目标**：维护金融体系**稳定**、保护**存款人与投资者**、提高金融**效率**
- **原则**：依法监管、**公开公正**、效率、**独立**、协调（监管主体独立性）
- **监管理论**（配对题）：
  - **公共利益论**：监管为纠正市场失灵、服务公共利益
  - **捕获论（追逐论）**：监管者最终被被监管者"捕获"
  - **经济调节论**：监管是政府调节经济的手段
  - **社会选择论**：从**公众选择**视角解释监管需求（F-124）

### A4. 监管体制

- **类型**：**分业监管（机构监管）、统一监管（混业/单一监管）、双峰监管（审慎监管 + 行为监管）**
- **我国演变**：央行统管 → 2003 银监会成立（**一行三会**）→ 2018 银监会与保监会合并（**一行两会**）→ 2023 组建**国家金融监督管理总局**（**一行一局一会**：**央行 + 金融监管总局 + 证监会**）
- **国际协调组织**：**巴塞尔银行监管委员会（BCBS）**、**IOSCO**（证券）、**IAIS**（保险）、**FSB**（金融稳定理事会）
- **协调形式**：**信息交换与披露、监管磋商、联合行动、制定并执行国际准则**（非强制）

### A5. ★2026 新增：银行监管国际规则（巴塞尔）

| 指标 | 巴塞尔 III | 我国执行 |
|---|---|---|
| 核心一级资本充足率 | ≥ **4.5%** | ≥ **5%** |
| 一级资本充足率 | ≥ **6%** | ≥ **6%** |
| 总资本充足率 | ≥ **8%** | ≥ **8%** |
| 储备资本缓冲 | **2.5%** | 已含在 5/6/8 内 |
| 逆周期资本缓冲 | 0 – 2.5% | 视情况 |
| 系统重要性银行附加 | 1% – 3.5% | 分组计提 |
| **杠杆率** | ≥ **3%** | ≥ **4%** |
| **LCR / NSFR** | ≥ **100%** | ≥ **100%** |

⚠️ 两套数字都要记：**巴塞尔裸标准 4.5/6/8 + 缓冲层**；**我国教材口径 5/6/8**。题干问"巴塞尔"用 4.5，问"我国"用 5。

### A6. 我国分业监管主要内容

| 行业 | 监管重点 |
|---|---|
| **银行业** | 资本充足率、不良贷款率、流动性、关联交易、公司治理、**存款保险** |
| **保险业** | **偿付能力监管（偿二代 C-ROSS）**、资金运用比例、产品与费率 |
| **证券业** | **净资本 / 风险资本准备**、客户交易结算资金**第三方存管**、信息披露、投资者保护 |

## F-124　金融监管理论：社会选择论 = 公众选择视角

> 题源：D6-73

- **知识点全解**：监管经济学诸论辨析：
