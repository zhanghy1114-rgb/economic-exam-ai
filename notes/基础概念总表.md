## 第一层：地基概念（贯穿全科，6 个 · 对应第①关）

| 概念 | 一句话定义 | 出现位置 |
|------|-----------|---------|
| 稀缺性 | 资源有限而欲望无限，必须做选择 | 全科起点 |
| 机会成本 | 做 A 所放弃的最高价值 B | 成本理论、投资决策、财政 |
| 边际 | 增加一单位带来的变化量 | MC、MP、MPC、边际税率 |

| 理性人假设 | 决策者追求自身利益最大化 | 全部微观分析前提 |
| 帕累托最优 | 无法在不损害他人的前提下改善任何人 | 效率判断标准、市场失灵 |

## 第二层：科目一 经济基础知识

### 微观部分（第 1-6 章）★ 你在这一层｜对应第②-⑥关

#### 第1章 市场需求、供给与均衡价格
- ⭐ 需求 / 需求量（区分：需求是整条线，需求量是线上一点）
- ⭐ 需求定理、供给定理
- ⭐ 需求变动 vs 需求量变动（线移动 vs 点移动）⚠️
- 影响需求的因素（收入、偏好、相关品价格、预期）
- 替代品 / 互补品
- ⭐ 均衡价格、均衡数量
- ⭐ 需求价格弹性（富有弹性/缺乏弹性/单位弹性）
- ⭐ 需求交叉弹性（正=替代，负=互补）⚠️
- 需求收入弹性（正常品/劣等品）
- 供给价格弹性
- ⭐ 最高限价 / 最低保护价（政府干预）

#### 第2章 消费者行为分析
- ⭐ 效用、基数效用论 / 序数效用论
- ⭐ 边际效用递减规律
- 消费者均衡（MU/P 相等原则）
- ⭐ 无差异曲线（特征：凸向原点、不相交、离原点越远效用越高）
- ⭐ 预算约束线（斜率 = 价格比）
- ⭐ 消费者均衡点（无差异曲线与预算线相切）
- 收入效应 / 替代效应 ⚠️
- 正常品 / 劣等品 / 吉芬品 ⚠️

#### 第3章 生产和成本理论
- 企业理论：科斯的企业本质（交易成本）
- 生产函数
- ⭐ 总产量 TP / 平均产量 AP / 边际产量 MP
- ⭐ 边际报酬递减规律
- ⭐ 生产三阶段（合理区间在第 2 阶段）
- ⭐ 显性成本 / 隐性成本 / 机会成本
- ⭐ 经济利润 / 正常利润 ⚠️（经济利润=0 时正常利润仍存在）
- 短期成本函数 / 长期成本函数
- ⭐ TFC / TVC / TC（总量级）
- ⭐ AFC / AVC / ATC / MC（单位级）
- ⭐ MC 穿 AVC 和 ATC 最低点（"一勾穿三线"）
- 长期成本：LTC / LAC / LMC、规模经济 / 规模不经济
- 决定短期成本的因素：要素价格、生产率

#### 第4章 市场结构理论
- ⭐ 四种市场结构：完全竞争 / 垄断竞争 / 寡头 / 完全垄断
- ⭐ 完全竞争：P = AR = MR（"水平线上三兄弟"）
- 完全竞争厂商短期均衡 / 长期均衡
- ⭐ 完全竞争厂商短期供给曲线 = MC 在 AVC 最低点以上的部分
- 垄断：需求曲线向右下倾斜，MR < P
- ⭐ 垄断厂商定价：MR = MC
- 价格歧视（一级/二级/三级）⚠️
- 寡头：古诺模型、博弈论、囚徒困境
- 垄断竞争：产品差别

#### 第5章 生产要素市场理论
- ⭐ 引致需求 / 联合需求
- ⭐ 边际收益产品 MRP / 边际要素成本 MFC
- ⭐ 生产者使用要素原则：MRP = MFC
- 完全竞争下：VMP = MRP
- ⭐ 要素需求曲线向右下倾斜
- ⭐ 向后弯曲的劳动供给曲线（替代效应 vs 收入效应）⚠️
- 土地的供给曲线：垂直 ⚠️
- 均衡工资的决定

#### 第6章 市场失灵和政府的干预 ★ 当前章节
- ⭐ 市场失灵定义（≠市场崩溃）⚠️
- ⭐ 帕累托最优
- **垄断导致失灵**：P > MC、产量不足
- ⭐ 外部性（正/负，外部经济/不经济）
- ⭐ 外部性的政府手段：征税、补贴、科斯定理
- ⭐ 科斯定理（产权清晰+交易成本为零 → 市场自己解决）⚠️
- ⭐ 公共物品两特征：非竞争性、非排他性
- ⭐ 搭便车问题
- 纯公共物品 / 准公共物品 / 公共资源 / 私人物品
- ⭐ 公共物品需求曲线：纵向相加 ⚠️
- ⭐ 信息不对称
- ⭐ 逆向选择（事前）vs 道德风险（事后）⚠️
- 柠檬市场、信号传递

## 附：概念自测法

对每个概念问自己三个问题：
1. **能不能一句话说清它是什么？**
2. **能不能举一个例子？**
3. **能不能说出它和相邻概念的差别？**（这是选择题的关键）

三个都能答上来 → 标记 ✅ 过关
第 3 个答不上来 → 标记 ⚠️ 重点复习（易混概念最容易丢分）
