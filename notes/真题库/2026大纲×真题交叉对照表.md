## 三、双轨复习法（大纲 + 真题，各司其职）

### 轨道 A：大纲 → 决定"学什么"（范围清单）

对每一章，把大纲原文的**动词分层**当作优先级：

| 动词 | 要求 | 处置 |
|---|---|---|
| **掌握** | 必须会算、会判、会区分 | 必做题 + 必背清单 |
| **理解** | 说得清是什么、为什么 | 概念题 |
| **分析** | 会多知识点联动、会解释现象 | 案例题 |
| **熟悉** | 认得、能选对 | 选择题干扰项 |
| **识记 / 了解** | 认得即可 | 只做单选题备选 |

### 轨道 B：真题 → 决定"怎么考"（手法与密度）

已知的三条实测规律（可直接执行）：

| 规律 | 数值 | 用法 |
|---|---|---|
| 取非题密度 | **25%**（60 单选中 15 道） | 每 4 道单选必出 1 道"不包括/不属于/错误的是" |
| 案例题章分布 | **只在 5/7/10/11 章**，占 75 分 | 这四章按案例规格练 |
| 计算题形态 | **全部一步到位**（贴现、β、夏普、组合标准差、戈登） | 不练多步复杂计算 |

### 轨道 C：交叉校验（每次出卷必做）

```
① 这题考点在大纲里 → 有？无？（无 → 删题）
② 大纲动词层级 → 掌握/理解/分析/熟悉/识记？（决定题型）
③ 真题考过没 → 考过：按真题手法出；没考过：标"大纲新增·无真题对标"
④ 有没有超纲术语 → 有 → 删
```
