# 科目一 · 微观部分（第 1-6 章）

## 第1章 市场需求、供给与均衡价格

| | 内容 |
|---|------|
| **前置** | 稀缺性、边际、均衡、理性人假设（第①关地基） |
| **本章新增** | 需求/供给、需求定理/供给定理、均衡价格、需求价格弹性、交叉弹性、收入弹性、供给弹性、最高限价/最低保护价 |
| **学完解锁** | 第2章（需求为何向下）、第3章（供给为何向上）、第6章（价格机制失灵） |
| **卡点预警** | ⚠️ "需求变动 vs 需求量变动"分不清 → 后面所有"曲线移动"的题都会错 |

## 第2章 消费者行为分析

| | 内容 |
|---|------|
| **前置** | 第1章的**需求定理**（本章是在解释它）、均衡、边际 |
| **本章新增** | 效用（基数/序数）、边际效用递减规律、消费者均衡（MU/P）、无差异曲线、预算约束线、收入效应/替代效应、正常品/劣等品/吉芬品 |
| **学完解锁** | 第7章消费函数（MPC 的微观基础）、第5章劳动供给曲线（替代/收入效应复用） |
| **卡点预警** | ⚠️ 无差异曲线必须放在"效用"之后学，否则是一堆无意义的弧线 |

## 第3章 生产和成本理论

| | 内容 |
|---|------|
| **前置** | 边际（**核心**）、机会成本、第1章的**供给定理** |
| **本章新增** | 生产函数、TP/AP/MP、边际报酬递减规律、生产三阶段、显性/隐性成本、经济利润/正常利润、TFC/TVC/TC、AFC/AVC/ATC/MC、LAC/LMC、规模经济 |
| **学完解锁** | 第4章（厂商定价依据）、第6章（外部性图形 MSB/MSC 的底子） |
| **卡点预警** | ⚠️ 必须先有 TP/AP/MP 才能理解 MC（两者是镜像关系）；⚠️ 经济利润=0 时正常利润仍存在 |

## 第4章 市场结构理论

| | 内容 |
|---|------|
| **前置** | 第3章**成本曲线**（尤其 MC、ATC）、均衡、边际 |
| **本章新增** | 四种市场结构、完全竞争 P=AR=MR、MR=MC 均衡、短期供给曲线、垄断 MR<P、价格歧视（一级/二级/三级）、古诺模型、囚徒困境 |
| **学完解锁** | 第6章（**垄断导致市场失灵**——马上要用）、金融第7章（市场效率） |
| **卡点预警** | ⚠️ "为什么供给曲线只是 MC 的一截"——不懂 AVC 最低点就答不上 |

## 第5章 生产要素市场理论 ★ 已学（注意 2026 口径）

| | 内容 |
|---|------|
| **前置** | 第3章**边际产量**、第4章**厂商均衡**、边际 |
| **本章新增** | 引致需求、联合需求、**边际要素成本 MFC = 边际产品价值 VMP**（2026 口径）、向后弯曲的劳动供给曲线、土地供给曲线（垂直） |
| **学完解锁** | 第7章宏观（要素收入）、第9章（工资与就业）、金融第7章（资本定价） |
| **卡点预警** | ⚠️ **2026 教材口径变化**：生产者使用要素原则改为"**边际要素成本 = 边际产品价值（VMP）**"，**旧教材的 MRP 表述已删除**，别背错；⚠️ "向后弯曲"要懂替代效应 vs 收入效应（第2章的知识）；⚠️ 只有劳动供给向后弯，土地是垂直 |

## 第6章 市场失灵和政府的干预 ★ 你在这

| | 内容 |
|---|------|
| **前置** | 第4章**垄断**（失灵原因①）、第3章**边际成本**（外部性图形）、第1章**均衡**（帕累托最优） |
| **本章新增** | 市场失灵、帕累托最优、外部性（正/负）、科斯定理、公共物品（非竞争/非排他）、搭便车、信息不对称、逆向选择、道德风险 |
| **学完解锁** | 第11章（财政职能＝弥补失灵）、第21章（金融监管＝治信息不对称） |
| **卡点预警** | ⚠️ 科斯定理是**市场解决**不是政府干预；⚠️ 逆向选择（事前）vs 道德风险（事后） |
