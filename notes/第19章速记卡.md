# 一、主线：一条链（★先记这个，别的都是配菜）

```
①工具  →  ②操作目标  →  ③中介目标  →  ④最终目标
```

| 环节 | 装什么 | 一句话 |
|---|---|---|
| **① 工具** | 存款准备金率 · 再贴现 · 公开市场操作 | **"三大法宝"** |
| **② 操作目标** | 基础货币 · 短期利率（银行间同业拆借利率） | **"离央行的**手**最近，一动就变"** |
| **③ 中介目标** | 货币供应量 · 长期利率 · 社会融资规模 | **"离终点近，跟最终目标关系强"** |
| **④ 最终目标** | 稳定物价 · 充分就业 · 经济增长 · 国际收支平衡 | **"四个大目标"** |

> **⚠️ 一句话记住三层目标**：
> **"工具一动 → 近的（操作）立刻变 → 中的（中介）跟着变 → 远的（最终）慢慢变"**
>
> **⚠️ 高频配错**：
> · **基础货币 / 短期利率 / 存款准备金** = **操作目标**（离工具近）
> · **货币供应量 / 长期利率 / 社会融资规模** = **中介目标**（离终点近）

**我国货币政策的法定最终目标**（《中国人民银行法》）：
> **"保持货币币值的稳定，并以此促进经济增长。"**

# 二、必背短名单（5 组）

### 1. 央行三大职能
| 名称 | 含义 |
|---|---|
| **发行的银行** | 垄断货币发行权 |
| **银行的银行** | 保管准备金 · **最后贷款人** · 组织全国清算 |
| **政府的银行** | **经理国库** · 代理国债发行 · 管理国际储备 · 制定执行货币政策 |

> ⚠️ **最后贷款人只救金融机构**，不救企业、不救个人。

### 2. 三大法宝（作用方向 + 特点）
| 工具 | 方向 | 特点 |
|---|---|---|
| **存款准备金率** | ↑紧缩 / ↓扩张 | **"猛药"**（最烈，不轻动） |
| **再贴现率** | ↑紧缩 / ↓扩张 | **"温和"**（弹性小） |
| **公开市场操作** | **买入=放水 / 卖出=收水** | **"最灵活、最常用"** |

> 锚：**"准备金率是猛药，再贴现温和，公开市场最灵活"**；**"买入是放水，卖出是收水"**

### 3. 金融"五篇大文章"
> **科技金融 · 绿色金融 · 普惠金融 · 养老金融 · 数字金融**
> 锚：**"科绿普养数"**

### 4. 结构性货币政策工具（2026 重点，记名称+一句话）
| 工具 | 一句话 |
|---|---|
| **SLF** 常备借贷便利 | **短期**流动性，机构主动申请（2013） |
| **MLF** 中期借贷便利 | **中期**资金，**LPR 的定价锚**（2014） |
| **PSL** 抵押补充贷款 | **定向**支持棚改、水利等领域（2014） |
| **定向降准** | 对达标银行给**更低的准备金率** |

> **结构性工具的"目标与机理"**：
> **目标** = **"精准滴灌"**，引导资源流向重点领域和薄弱环节
> **机理** = 央行资金与特定领域投放**挂钩** → **"四两拨千斤"撬动信贷**
> **特征** = **兼具"总量 + 结构"双重功能**

### 5. 非常规货币政策工具（2026 新增）
> 背景：**零利率下限 / 流动性陷阱**——利率降到 0 附近就"推绳子"，不灵了
>
> **QE 量化宽松**（大量买长期资产）· **前瞻性指引**（承诺未来方向）
> **YCC 收益率曲线控制**（钉住国债目标收益率，日本典型）· **负利率**
>
> 锚：**"买资产(QE)·说话(指引)·钉收益率(YCC)·倒收利息(负利率)"**

# 三、配菜（单选零星考，眼熟即可）

| 内容 | 要点 |
|---|---|
| **央行四类型** | **单一型**（中·英·日）｜**复合型**（"大一统"·前苏联）｜**准中央银行**（中国香港·新加坡）｜**跨国型**（**欧洲央行**） |
| **央行三大业务** | **负债**：货币发行★（最主要）· 准备金存款 · 政府存款<br>**资产**：再贷款再贴现 · 证券买卖 · 金银外汇储备<br>**中间**：清算业务 |
| ⚠️ 总原则 | **央行发出去/欠别人的 = 负债**；**买来的/拥有的 = 资产** |
| ⚠️ 反直觉 | **流通中现金是央行的负债**（印着"中国人民银行"的欠条） |
| **独立性** | **目标独立性 vs 工具独立性**；中国=**有工具独立、无完全目标独立**<br>规定：在**国务院领导下**独立执行；**不得对政府财政透支、不得直接认购包销国债** |
| **传导四渠道** | **利率 · 信贷 · 资产价格 · 汇率** |
| **学派分歧** | **凯恩斯学派→强调利率**｜**货币学派→强调货币供应量** |
| **我国实践** | 货币政策基调=**适度宽松**｜**LPR 改革**="两轨合一轨"（MLF→LPR→贷款利率）｜**数字人民币**影响货币供应量与传导机制 |
