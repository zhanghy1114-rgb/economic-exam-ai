# 第 1 章 · 四条硬核规则（曲线题地基）

> 建立：2026-10-22｜来源：第 1 章卷① 错题 Q1/Q4/Q5/Q7 讲评后固化
> 用途：第 1 章本身 + 后续所有"曲线/方向"类题（第 3、4 章市场结构，第 9 章 IS-LM，第 12 章总供求）

---

## 规则一｜坐标约定：价格竖着放（与数学相反）

| | 自变量 | 因变量 |
|---|---|---|
| 数学课 | 横轴 | 纵轴 |
| **经济学** | **纵轴＝价格 P** | **横轴＝数量 Q** |

**三条反推证据（教材自证，无需死记）**

1. **"完全竞争企业的需求曲线是平行于横轴的水平线"** → 价格不变、数量任意＝水平线 → 只有价格纵轴才成立
2. **"长期总供给曲线是一条垂直于横轴的直线"（与价格无关）** → 价格变、数量不变＝垂直线 → 同理
3. **"需求曲线向右下方倾斜、供给曲线向右上方倾斜"** → 只有价格纵轴时这两句才同时成立

**记忆锚**：**价格站得高（纵轴），数量躺得宽（横轴）。**

## 规则二｜点动 vs 线动（Q1 错点）

| | 什么引起 | 图上表现 | 术语 |
|---|---|---|---|
| **点动** | **自身价格**变 | 沿原曲线滑动 | 需求量 / 供给量变动 |
| **线动** | 价格以外的因素 | 整条曲线左移/右移 | 需求 / 供给变动 |

- **降价 → 沿需求曲线向右下方滑**（向右＝量增，向下＝价降）
- **涨价 → 沿需求曲线向左上方滑**（向左＝量减，向上＝价升）
- 需求曲线移动的诱因：收入、偏好、**替代品/互补品价格**、预期、消费者数量
- 供给曲线移动的诱因：**成本（要素价格）**、技术、预期、生产者数量

**表述铁律**：点动只说"沿曲线向右下方 / 左上方"；线动只说"**左移 / 右移**"，**不说"上移/下移"**。

**记忆锚**：**自己的价格动 → 顺着线滑；别的原因动 → 整条线搬。**

**唯一特例**：**完全竞争企业的需求曲线＝平行于横轴的水平线**（价格接受者，卖多少都是一个价）。各市场结构中仅此一例，其余企业需求曲线全部向右下方倾斜。

## 规则三｜供求同时变动：竖着比箭头（Q4 错点）

**四种单变量变动**

| 变动 | 价格 | 数量 |
|---|---|---|
| 供给↑ | ↓ | ↑ |
| 供给↓ | ↑ | ↓ |
| 需求↑ | ↑ | ↑ |
| 需求↓ | ↓ | ↓ |

**双变量组合**

| 组合 | 均衡价格 | 均衡数量 |
|---|---|---|
| 供给↑ 需求↑ | 不确定 | ↑ |
| 供给↓ 需求↓ | 不确定 | ↓ |
| **供给↑ 需求↓** | **↓** | **不确定** |
| 供给↓ 需求↑ | **↑** | **不确定** |

**规律**：**同向变动 → 数量确定、价格不确定；反向变动 → 价格确定、数量不确定。**
本质：**两股力方向相同的那个量才确定；打架的那个不确定。**

**考场动作（15 秒，不画图）**

```
供给增 →  价↓  量↑
需求减 →  价↓  量↓
─────────────────
价格：↓ ↓  同向 → 确定↓
数量：↑ ↓  反向 → 不确定
```

**竖着比箭头，同向确定、异向不确定。**

## 规则四｜限高保低（Q5 错点）

> **限**的是**高**价 → 帮**买家**（消费者）
> **保**的是**低**价 → 帮**卖家**（生产者）

| | 最高限价 | 保护价格（最低限价） |
|---|---|---|
| 图像比喻 | **天花板**（压顶） | **地板**（托底） |
| 位置 | **低于**均衡价格 | **高于**均衡价格 |
| 保护谁 | **消费者** | **生产者** |
| 后果 | **短缺** | **过剩** |
| 配套措施 | 凭票配给、限购、打击黑市 | **政府收购 + 储备系统** |
| 现实例子 | 房租管制、药品/口罩限价 | 粮食最低收购价 |

**三段口诀**

1. **"贵了帮买家，贱了帮卖家"**（记对象）
2. **"压价必缺，抬价必剩"**（记后果）
3. **"缺了配给，多了收购"**（记配套）

**一句话总纲**：
**"限高保低：限高价帮买家，保低价帮卖家；压价必缺、抬价必剩；缺了配给、多了收购。"**

**名字陷阱**：带"**保**"字的是保底、保卖家；带"**限**"字的是限涨价、护买家。Q5 的 C 项即在此设错（叫"主体错位"）。

## 附｜弹性两侧口诀（Q7 错点）

| | 需求价格弹性（4 因素） | 供给价格弹性（3 因素） |
|---|---|---|
| 口诀 | **多 · 广 · 长 · 闲** | **时 · 期 · 替** |
| 展开 | 替代品**多**、用途**广**、时间**长**、非必需品（**闲**） | 时间、生产周期、投入品替代性 |
| 方向 | 四项全为"越多越大" | **时间↑→弹性↑；投入品替代性↑→弹性↑；生产周期↑→弹性↓** ⚠️ |

**核心一句**：**供给三因素里，"生产周期"是唯一反派**（生产周期越长，越来不及调整产量 → 弹性越小）。

**两侧唯一的共同点**：**时间越长，弹性越大**（需求、供给都成立）。

**弹性数值巧记：越平越弹，竖起来的都没弹性。**

| 系数 | 名称 | 形状 |
|---|---|---|
| 0 | 完全无弹性 | 竖直（救命药） |
| 0~1 | 缺乏弹性 | 陡（食盐） |
| 1 | 单位弹性 | 中 |
| >1 | 富有弹性 | 平缓（奢侈品） |
| ∞ | 完全有弹性 | 水平（完全竞争企业需求曲线） |

## 一页速查（考前 60 秒）

1. **价格在纵轴**（反推：完全竞争企业需求曲线是水平线）
2. **自己价格变＝点滑；别的原因变＝线搬**
3. **双变量：竖着比箭头，同向确定、异向不确定**
4. **限高保低：压价必缺、抬价必剩；缺了配给、多了收购**
5. **供给三因素唯一反派＝生产周期；时间对两侧都是正向**
