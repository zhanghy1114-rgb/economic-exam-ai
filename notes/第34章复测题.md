<summary><b>答案与解析（做完再看）</b></summary>

### 单选

**1. D** ✅ 答案
- **D 错**（即本题答案）：居住权**既不得转让，也不得继承**。D 说"可以继承但不得转让"——半真半假，前半错。
- A ✅ 用益物权（不是担保物权）
- B ✅ 自**登记**时设立
- C ✅ 居住权人死亡，居住权消灭（人身专属性）

**2. B** 地役权
- **从物权四兄弟：抵 · 质 · 留 · 役**（抵押权、质权、留置权、地役权）
- 地役权依附于**需役地**，是唯一的"用益物权里的从物权"
- A 居住权、C 建设用地使用权、D 土地承包经营权 → 均为**主物权**（独立存在）

**3. C** 附合
- 瓷砖贴进卫生间：**认得出原物（那批瓷砖）+ 拆不开（撬了就碎）** → 附合
- 判断顺序：认不认得出 → 认不出=混合；认得出但拆不开=附合；变成新物=加工
- 添附属**原始取得**

**4. B**
- **易混点**：处分"共有物本身"需 2/3；但"转让**自己的份额**"不需要其他共有人同意
- 转让份额时，其他共有人在**同等条件下有优先购买权**
- A ❌ 一致同意是**共同共有**规则
- D ❌ 把"处分共有物须 2/3"错套到"转让份额"上，且否定了优先购买权

### 多选

**5. ABDE**
- C ❌ 地役权**自合同生效时设立**，登记只是对抗要件
- D ✅ 正是 C 的正确答案（两项互斥，只能取一）
- E ✅ 依附需役地 → 从物权

**6. ADE**
- 判据：**物还在、主人换了 = 相对**；**物没了 = 绝对**
- A 买卖换人 ✅ ｜ D 继承换人 ✅ ｜ E 赠与换人 ✅
- B 报废、C 震塌 → **客体灭失 = 绝对消灭** ❌
- 口诀：**死的是人，不是物**（继承≠绝对消灭）

**7. ABDE**
- C ❌ 建设用地使用权是**不动产用益物权**，只能**抵押**，不能质押（质押须转移占有）
- A ✅ 留置权法定，且可"约定排除"但不能"约定创设"
- D ✅ 保险金/赔偿金/补偿金 → **物上代位性**
- E ✅ 主债权消灭 → 担保物权消灭（**从属性**）

**8. ABCE**
- D ❌ **因继承取得物权，自继承开始时生效**（不以登记为要件）——这是特殊规则
- E ✅ 因法院判决/仲裁裁决取得，自**法律文书生效时**发生效力
- A、B、C ✅ 一般规则：不动产登记生效、动产交付生效、船舶航空器机动车等未登记不得对抗善意第三人

### 特殊生效时点（记这一张表）

| 情形 | 何时生效 |
|---|---|
| 不动产买卖、赠与 | **登记时** |
| 动产买卖 | **交付时** |
| 船舶、航空器、机动车 | 交付时生效，**未登记不得对抗善意第三人** |
| **继承、受遗赠** | **继承开始时**（不需登记） |
| **法院判决、仲裁裁决** | **法律文书生效时** |
| 合法建造、拆除房屋 | **事实成就时** |
