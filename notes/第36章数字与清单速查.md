# 第36章 公司法律制度 · 数字与清单速查

> 用法：考前 10 分钟只看这一张。全部按 **2024 新公司法**（2024.7.1 施行）。
> 生成于 2026-10-20，配套整卷 7/24（29%）的 12 道错题讲解。

---

## 一、设立：人数与资本

| 项目 | 有限责任公司 | 股份有限公司 |
|---|---|---|
| 股东/发起人人数 | **1 个以上 50 个以下** | 发起人 **1 人以上 200 人以下** |
| 住所要求 | 无 | **半数以上发起人在中国境内有住所** |
| 出资期限 | 成立之日起 **5 年内**缴足 | 成立**前全额缴纳** |
| 资本形式 | 出资额 | **等额股份** |
| 最低注册资本 | 取消（法律、行政法规另有规定除外） | 同左 |

- 成立日期＝**营业执照签发之日**
- 一人公司：新法**不再单列**，并入"1 个以上"

---

## 二、三会一层

| 机构 | 人数 | 会议 | 表决 |
|---|---|---|---|
| **股东会** | 全体股东 | 召开 **15 日前**通知 | 普通：**过半数**；特别：**2/3 以上** |
| **董事会** | **3 人以上**（无上限） | **每年至少 2 次**，**10 日前**通知 | 一人一票 |
| **监事会** | **3 人以上**，职工代表 **≥1/3** | **每 6 个月至少 1 次** | 全体监事**过半数** |
| 董事/监事任期 | **每届 ≤3 年**，可连任 | —— | —— |

**可以不设：**
- 规模较小或股东人数较少的有限公司 → 不设董事会，设 **1 名董事**；不设监事会，设 **1 名监事**
- 经**全体股东一致同意** → 可不设监事
- 董事会中设**审计委员会**（由董事组成，行使监事会职权）→ 不设监事会或监事

**2/3 特别决议事项（六项）**：**章 · 资 · 合 · 分 · 解 · 形**
修改章程／增加或减少注册资本／合并／分立／解散／变更公司形式

**法定代表人**：由**代表公司执行公司事务的董事或者经理**担任；辞任 30 日内确定新的。

## 三、股东权利（按内容分三类：管 · 钱 · 告）

| 大类 | 项下权能 |
|---|---|
| **管理权** | 参与重大决策权（表决、提案、召集）、选择管理者权（选举权、**被选举权**）、知情权 |
| **资产收益权** | 利润分配权、剩余财产分配权、新增资本优先认购权、股权转让权 |
| **诉讼权** | 股东代表诉讼、直接诉讼（决议无效/撤销、回购之诉） |

**按目的分（另一套标准）**：自益权（分红、优先认购、转让）｜共益权（表决、知情、代表诉讼）

**知情权边界：**

| 文件 | 查阅 | 复制 |
|---|---|---|
| 章程、股东名册、股东会记录、董事会决议、监事会决议、财务会计报告 | ✅ | ✅ |
| **会计账簿、会计凭证** | ✅（须书面请求说明目的） | ❌ |
| **全资子公司**相关资料 | ✅ 适用同一规则（新法） | ✅ |

被拒：公司须自请求提出之日起 **15 日内**书面答复并说明理由。

**利润分配/优先认购**：默认按**实缴**出资比例（全体股东约定除外）。

**异议股东回购**：连续 5 年盈利却不分配／合并分立转让主要财产／期满修改章程存续 → **协商 60 日、起诉 90 日**，须投**反对票**。

**决议瑕疵**：内容违法 → **无效**（无期限）；程序或表决方式违法、内容违章程 → **可撤销，60 日内**。

## 四、代表诉讼（186→189 条）

| 步 | 内容 |
|---|---|
| 原告资格 | 有限公司：**任一股东**；股份公司：**连续 180 日以上 + 合计 1% 以上** |
| 前置 | 告董事高管 → 请求**监事会**；告监事 → 请求**董事会** |
| 等待 | 收到请求 **30 日**内未起诉，或拒绝 → 自己告 |
| 例外 | **情况紧急**，不起诉将受难以弥补损害 → 直接告 |
| 名义 | **自己的名义**，为公司利益 |
| 新法扩展 | **全资子公司**受损，母公司股东可同样提起（双重代表诉讼） |

## 五、董监高：资格禁止 + 义务

**五类禁止（只看"刑"，不看"罚"）：**

| # | 情形 | 期限 |
|---|---|---|
| 1 | 无/限制民事行为能力 | 无期限 |
| 2 | 五类经济犯罪判刑／任何犯罪被剥夺政治权利 | **执行期满未逾 5 年** |
| 3 | 被宣告缓刑 | **缓刑考验期满未逾 2 年** |
| 4 | 破产清算公司的董事、厂长、经理且**负个人责任** | **清算完结未逾 3 年** |
| 5 | 被吊销执照/责令关闭公司的**法定代表人**且**负个人责任** | **未逾 3 年** |
| 6 | 失信被执行人（债务较大到期未清偿） | 无期限 |

> 记忆：**刑 5（缓刑 2）· 破 3 · 吊 3 · 失信无限**。治安拘留、罚款、普通欠债**都不禁**。

**忠实义务六红线**：侵占财产挪用资金／另开账户存公款／贿赂收回扣／佣金归己／擅自披露秘密／其他。
后果：**所得收入归公司**（归入权）＋赔偿。

**需报批（非绝对禁止）**：关联交易、竞业 → 向董事会或股东会**报告 + 决议通过**。

**勤勉义务**：为公司的最大利益尽到管理者通常应有的合理注意。（忠实＝不能贪，勤勉＝不能懒）

**事实董事/影子董事**：控股股东、实控人不当董事但实际执行事务 → 适用忠实勤勉义务；指示董监高损害公司 → **连带责任**。

## 六、股权与股份转让

**有限责任公司：**

| 转给谁 | 规则 |
|---|---|
| 其他股东 | **自由**，无需同意 |
| 股东以外的人 | **书面通知**（数量、价格、支付方式和期限）→ 其他股东同等条件下**优先购买权** |
| 未答复 | 接到通知之日起 **30 日**内未答复 → 视为放弃 |
| 多人主张 | 协商比例；协商不成按转让时**出资比例** |
| 法院强制执行 | 法院通知之日起 **20 日**内不行使 → 视为放弃 |

> **新法已删除"须经其他股东过半数同意"** —— 老题库此表述一律判错。

**股份有限公司转让限制：**

| 主体 | 限制 |
|---|---|
| 公开发行前已发行股份 | 自**上市交易日**起 **1 年**内不得转让（⚠️旧法「发起人自成立起1年」新法已删） |
| 董监高 | 每年 ≤ 所持本公司股份总数的 **25%**（分母是"其所持有"） |
| 董监高 | 股票**上市交易之日起 1 年**内不得转让 |
| 董监高 | **离职后半年**内不得转让 |
| 章程 | 只能作**更严格**规定 |

> 记忆：**成立锁 1 年、上市锁 1 年、每年卖 1/4、离职锁半年。**

**发行价格**：可平价、可溢价，**不得折价**（不得低于票面金额）。

## 七、回购本公司股份：六种例外

**"减 · 并 · 员 · 异 · 转 · 值"**
① 减少注册资本（**不是增加**）② 与持有本公司股份的其他公司合并 ③ 员工持股计划或股权激励 ④ 异议股东要求收购 ⑤ 转换可转债 ⑥ 维护公司价值及股东权益所必需

| 情形 | 决议机关 | 处置 |
|---|---|---|
| ① 减资 | **股东会** | 收购之日起 **10 日内注销** |
| ② 合并 / ④ 异议股东 | **股东会** | **6 个月内**转让或注销 |
| ③⑤⑥ | 章程规定或股东会授权，**2/3 以上董事出席**的董事会决议 | 合计 ≤ 已发行股份总数 **10%**，**3 年内**转让或注销 |

## 八、合并 / 分立 / 增减资

| 事项 | 规则 |
|---|---|
| 合并（吸收、新设） | 决议后 **10 日内通知**债权人、**30 日内公告**；债权人接到通知 **30 日**内、未接通知自公告 **45 日**内可要求**清偿或提供担保** |
| 分立（派生、新设） | 同上程序，但债权人**无权**要求清偿或担保；分立前债务由分立后公司**连带**（另有书面协议除外） |
| 减资 | 同合并程序（10/30/30/45）；按出资或持股比例减；**弥补亏损型减资不得向股东分配、不得免除出资义务** |
| 增资 | 有限公司股东**同等条件下按实缴出资比例优先认缴** |

> 区别记一句：**合并是责任主体变了，分立是责任主体变多了。**

## 九、解散与清算

**解散五情形：**
1. 章程规定的营业期限届满或其他解散事由出现
2. **股东会决议**解散（2/3）
3. 因**合并或分立**需要解散
4. 依法被**吊销营业执照、责令关闭或被撤销**
5. **司法解散**：经营管理严重困难、继续存续使股东利益受重大损失、其他途径不能解决 → **10% 以上表决权**股东请求法院

> 第 1、2 项可通过**修改章程或股东会决议**（2/3）使公司**存续**。
> **"不能清偿到期债务"是破产原因，不是解散事由。**

**清算：**

| 事项 | 规定 |
|---|---|
| **清算义务人** | **董事**（旧法为股东——新法必考变化） |
| 成立清算组 | 解散事由出现之日起 **15 日内** |
| 通知债权人 | 清算组成立之日起 **10 日内** |
| 公告 | 清算组成立之日起 **60 日内** |
| 债权申报 | 接到通知 **30 日**内／未接通知自公告 **45 日**内 |
| 期间地位 | 公司**存续**，但不得开展与清算无关的经营 |

**剩余财产分配顺序**：清算费用 → 职工工资·社保·法定补偿金 → 所欠税款 → 公司债务 → 股东按比例分配

## 十、上市公司四条特别规定（不许上抬到"股份有限公司"）

1. **独立董事**：只有**上市公司**必须设
2. **审计委员会前置**：聘用/解聘会计师事务所、聘任/解聘财务负责人、披露财务会计报告 → 须经**审计委员会全体成员过半数**通过
3. **关联董事回避**：关联董事不得表决、不得代理；**过半数无关联董事出席**即可开会，**无关联董事过半数**通过；出席无关联董事**不足 3 人** → 提交**股东会**
4. **一年内**购买/出售重大资产或担保金额**超过资产总额 30%** → 股东会**2/3**通过；**控股子公司不得取得上市公司股份**

---

## 十一、国有独资公司

- **不设股东会**，由履行出资人职责的机构行使股东会职权
- 章程由**出资人机构制定**
- 董事长、副董事长由**出资人机构从董事会成员中指定**
- 董事会成员中**应当有职工代表**，由**职工代表大会选举**
- 合并、分立、解散、申请破产、增减注册资本、分配利润 → 由**出资人机构决定**

## 十二、时间数字总表（易串味，重点看）

| 数字 | 归属 |
|---|---|
| **15 日** | 股东会开会通知／查阅请求被拒书面答复／解散后成立清算组 |
| **10 日** | 董事会开会通知／合并减资通知债权人／清算组通知债权人／减资回购注销 |
| **30 日** | 代表诉讼前置等待／股权转让未答复／债权人接到通知后主张／清算债权申报（接通知） |
| **60 日** | 决议撤销之诉／异议股东回购协商／清算组公告 |
| **90 日** | 异议股东回购**起诉** |
| **45 日** | 未接到通知的债权人自公告起主张/申报 |
| **6 个月** | 监事会开会间隔（每 6 个月至少 1 次）／董监高离职禁售期／合并·异议股东回购后处置期 |
| **1 年** | 公开发行前已发行股份禁售（**上市起**）／董监高禁售（上市起）／上市公司重大资产 30% 的统计期 |
| **3 年** | 董事监事任期上限／破产·吊照资格禁止／员工持股等回购后处置期 |
| **5 年** | 判刑/剥权后资格禁止／有限公司出资缴足期限 |
| **180 日 + 1%** | 股份公司股东代表诉讼 |
| **10%** | 提议临时股东会／请求司法解散／员工持股类回购合计上限 |
| **25%** | 董监高每年转让上限（分母＝其所持有） |
| **2/3** | 股东会特别决议（六项）／出席董事 2/3 的董事会决议（员工持股类回购）／上市公司 30% 重大资产 |
| **1/3** | 监事会职工代表比例下限 |
| **20%** | （合同章）定金上限——本章不适用 |
