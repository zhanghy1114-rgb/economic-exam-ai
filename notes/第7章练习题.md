### 一、GDP 与 GNI

**1. 答案 D**
- D 是 GDP 的完整定义 ✅
- A ❌ 错：GDP 按**国土原则**，外国企业在我国境内生产的，**算我国 GDP**
- B ❌ 错：二手房是以前年度生产的，**只算中介佣金**，房款本身不计入
- C ❌ 错：GDP 用**市场价值**计量，**没有交易就没有价格**，家务劳动不计入

**2. 答案 C（98）**
- 公式：**GNI ＝ GDP ＋ 本国居民在境外获得的收入 − 外国居民在本国境内获得的收入**
- 即：100 ＋ 2 − 4 ＝ **98**（万亿元）
- 也可理解为：GDP 认"地"、GNI 认"人"，外国人在本国赚得多，GNI 就小于 GDP

**3. 答案 B**
- 判断标准是**当期有没有被最终使用**，不是"它是第几道工序"
- 30 万元 → 居民买去直接吃，**最终使用** → 计入 ✅
- 70 万元 → 还要进面包厂继续加工，属**中间产品**，其价值会体现在面包里 → 不单独计入 ❌
- D ❌ 错：面粉只要卖给面包厂当投入，就是中间产品

### 二、核算方法与恒等式

**4. 答案 C**
- G ＝ **政府购买**，必须是政府**买到了商品和劳务**
- C 修高速公路，买到了水泥、钢材、施工劳务 → **计入 G** ✅
- A、B、D 都是**转移支付**（养老金、救济金、补贴）—— 政府**没有买到任何东西**，只是把钱转出去 → **不计入 G** ❌
- 🔑 记住：**"买东西"算，"发钱"不算**

**5. 答案 A**
- **支出法**（考试重点）：GDP ＝ C ＋ I ＋ G ＋（X − M）
- B 是"收入—储蓄—税收"的分解写法，不是支出法标准式
- C 是**收入法**的要素构成（工资＋利息＋租金＋利润等）
- D 是**生产法**（各行业增加值加总）

**6. 答案 A（储蓄 500，投资 500）**
- 收入法角度：GDP ＝ C ＋ S → 2000 ＝ 1500 ＋ S → **S ＝ 500**
- 两部门恒等式：**I ＝ S** → **投资 ＝ 500**
- 🔑 这题的思路：**先算储蓄，投资直接搬同一个数**

### 三、消费函数与储蓄函数

**7. 答案 A**
- C ＝ a ＋ bY 中，**b 就是 MPC** → MPC ＝ **0.75**
- 收入只有"消费 / 储蓄"两个去处 → **MPC ＋ MPS ＝ 1** → MPS ＝ 1 − 0.75 ＝ **0.25**
- a ＝ 300 是**自发消费**（收入为 0 时也要花的），不是倾向值

**8. 答案 A（APC ＞ MPC）**
- C ＝ 300 ＋ 0.75 × 2000 ＝ **1800**
- APC ＝ C / Y ＝ 1800 / 2000 ＝ **0.9**
- MPC ＝ 0.75 → **APC（0.9）＞ MPC（0.75）** ✅
- 🔑 通用结论：**APC ＝ MPC ＋ a/Y**，只要 a ＞ 0，APC 就恒大于 MPC；收入越高，APC 越接近 MPC（即**APC 随收入递减**）

**9. 答案 B（S ＝ −200 ＋ 0.2Y，收入 1000）**
- 推导：S ＝ Y − C ＝ Y −（200 ＋ 0.8Y）＝ **−200 ＋ 0.2Y**
- 收支相抵点即 S ＝ 0：−200 ＋ 0.2Y ＝ 0 → **Y ＝ 1000**
- A ❌ 符号错（储蓄函数常数项必须是**负**的，对应"没收入也要花钱"）
- C ❌ 斜率错（储蓄函数斜率是 **MPS ＝ 0.2**，不是 0.8）
- D ❌ 数值错（500 是 C ＝ 100 ＋ 0.8Y 那组题的答案，别混）

### 四、总需求与总供给

**10. 答案 B**
- 🔑 **只有"物价"能让人在 AD 曲线上滑动；其他任何因素变了，都是整条线搬家**
- A、C 都是**物价总水平**变动 → 只是**沿着同一条线**滑动，线本身没挪 ❌
- B 是**消费 C** 变动（价格以外的因素）→ **整条 AD 右移** ✅
- 其他能"搬家"的：I ↑、G ↑、X − M ↑ → 都是右移；反向则左移

**11. 答案 A**
- 原材料涨价 = **成本上升** = 价格以外的因素 → **整条线搬家**（不是沿线滑），排除 C
- 成本升高 → 每个价格水平下企业都**不愿意像以前那样多产** → **供给减少 → 左移** ✅
- D ❌ 错："垂直"是**长期** AS 的**形状**，跟本题问的"移动方向"无关；形状也不会因成本变化而改变
- 🔑 **方向规律：左 = 变少，右 = 变多**（成本↑→左移；成本↓→右移）

**12. 答案 C**
- **长期 AS 是一条垂直于横轴的直线**，位置由**劳动、资本、技术**决定，对应**潜在产出水平** ✅
- A、B ❌：向右上方倾斜是**短期** AS 的形状
- D ❌：长期看，**价格涨成本也涨**，产量回到原位 → 长期 AS 的位置**与物价水平无关**

## 🔑 一句话总纲

> **GDP 认"地"、GNI 认"人"；支出法 C＋I＋G＋(X−M)；钱要么消费要么储蓄（MPC＋MPS＝1）；短期看价格、长期看家底。**

**方向类题通用动作**（跨章节高频错点）：
> 遇到"往哪边走 / 用税还是补贴 / 偏多还是偏少" —— **先问：量是变多还是变少？**
> 变多 → 右移 ／ 补贴　｜　变少 → 左移 ／ 征税
