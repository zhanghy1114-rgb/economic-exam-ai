### 一、价格总水平指标

**1. 答案 B**
- **CPI（消费者价格指数）** 衡量居民购买的消费品和服务价格变动，**衡量通货膨胀最常用**
- A ❌ PPI 是生产者（出厂）环节；C ❌ 平减指数覆盖最广但不是"最常用"；D ❌ 商品零售价格指数不是教材口径的"最常用"答案

**2. 答案 B**
- **GDP 平减指数**覆盖全部最终产品和服务，**覆盖面最广** ✅
- A ❌ 那是 CPI 的定义；C ❌ 那是 PPI 的定义（刚好对调）
- D ❌ PPI 常被看作 CPI 的**先行指标**，PPI 上涨通常**会传导**给 CPI（同向），不是"一定下降"

---

### 二、就业与失业的含义

**3. 答案 A**
- 失业三条件：有劳动能力 ＋ **愿意工作** ＋ **正在找但没找到** —— 赵某全部满足 ✅
- B ❌ 放弃寻找 → "丧失信心的求职者"，不算失业
- C ❌ 无就业意愿，不算
- D ❌ 学生，不算

**4. 答案 B**
- 放弃求职的人**不计入失业人数**，也没了工作 → 官方失业率**低估**真实的就业困难程度
- 🔑 记住方向：**灰心者退出 → 统计"变好看" → 低估**

---

### 三、失业的类型

**5. 答案 A**
- 辞职后**正在找新工作** = 换工作"在路上"的时间差 → **摩擦性失业**
- 🔑 线索：**摩擦 = 在"找"**

**6. 答案 B**
- **不具备新岗位所需技能** = 技能不匹配 → **结构性失业**
- 🔑 线索：**结构 = 不"匹配"**（需要培训、再教育）
- C ❌ 不是经济衰退引起的普遍裁员，是产业/技术变革造成的个体错配

**7. 答案 A**
- **摩擦性 + 结构性 = 自然失业**，任何经济中都存在，难以避免 ✅
- B ❌ 周期性失业恰恰**与经济周期同步**（经济衰退→总需求不足→失业增加）
- C ❌ 由总需求不足引起的是**周期性**失业；结构性失业是**技能/结构错配**
- D ❌ 自然失业永远存在，**失业率不可能为零**；目标只是"充分就业"（消除周期性失业）

---

### 四、失业率

**8. 答案 B**
- 第一步：**劳动力总数 = 就业 + 失业 = 5000 + 500 = 5500 万**
- 第二步：失业率 = 500 ÷ 5500 ≈ **9.1%**
- A ❌ 把学生 300 万加进了分母（学生不属于劳动力）；C ❌ 分母用成就业人数；D ❌ 数字拼凑
- 🔑 老口诀：**先分类（就业/失业/其他），分母只放"就业＋失业"，别的一根手指都不碰**

---

### 五、奥肯定律与菲利普斯曲线

**9. 答案 B**
- 原文：失业率每高于自然失业率 **1 个百分点** → 实际 GDP 比潜在 GDP 低约 **2 个百分点**
- 🔑 **1 : 2** 的换算比例

**10. 答案 B（4 个百分点）**
- 失业率高出自然失业率：6% − 4% ＝ 2 个百分点
- GDP 缺口 ＝ 2 × 2 ＝ **4 个百分点**

**11. 答案 B**
- **菲利普斯曲线 = 失业率与通货膨胀率反向变动（负相关）** ✅
- A ❌ 那是**奥肯定律**（失业与经济增长反向）
- C ❌ 方向说反；D ❌ 与货币供给相关的是货币数量论视角，不是菲利普斯曲线
- 🔑 对照：**奥肯 ↔ 增长；菲利普斯 ↔ 物价；两条都是"反"的**

---

### 六、宏观经济治理

**12. 答案 D（选不属于）**
- 四大目标：**促进经济增长、充分就业、稳定物价、国际收支平衡**
- 股市涨跌是市场波动，**不是**宏观调控目标
- 干扰项常见套路：把"缩小贫富差距""股市上涨"混进来

## 📌 易错点自查表

| 易错点 | 正确口径 | 自检 |
|---|---|---|
| 衡量通胀最常用 | **CPI**（不是 PPI、不是平减指数） | ☐ |
| 三指标分工 | CPI 看消费端 / PPI 看出厂端（**先行指标**）/ 平减指数**最全** | ☐ |
| 失业三条件 | 有劳动能力 + **愿意工作** + **正在找**，缺一不算 | ☐ |
| 灰心放弃者 | 不算失业 → 失业率被**低估** | ☐ |
| 摩擦性失业 | 换工作"**在路上**"（时间差） | ☐ |
| 结构性失业 | **技能/地域不匹配**（需培训） | ☐ |
| 周期性失业 | **经济衰退、总需求不足**（调控要治的） | ☐ |
| 自然失业 | **摩擦 + 结构**，永远存在，失业率不可能为零 | ☐ |
| 失业率分母 | **劳动力 = 就业 + 失业**；学生/灰心者/退休者都不进分母 | ☐ |
| 奥肯定律 | 失业 ↔ **增长**，反向；**1 : 2** 换算 | ☐ |
| 菲利普斯曲线 | 失业 ↔ **通胀**，反向；通胀与失业**不可兼得** | ☐ |
| 宏观经济治理 | 四目标：**增长/就业/物价/国际收支**；手段：**财政 + 货币** | ☐ |

---

## 🔑 一句话总纲

> **通胀看 CPI，失业看三条件；类型认"找/配/差"，分母只装就业加失业；奥肯管增长、菲利普斯管物价，两条都是反着走；治理四目标，财政加货币。**
