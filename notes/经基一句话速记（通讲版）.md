## 第 1 章 社会主义基本经济制度

| # | 知识点 | 一句话 |
|---|---|---|
| 1 | 基本经济制度三组成 | **所有制 + 分配制度 + 市场经济体制，三层缺一不可。** |
| 2 | 公有制地位 | **公有制是主体，公有资产在社会总资产中占优势。** |
| 3 | 国有经济地位 | **国有经济起主导作用，主导看控制力不看资产量。** |
| 4 | 非公有制地位 | **非公有制经济是社会主义"市场"经济的重要组成部分（漏"市场"即错）。** |
| 5 | 公有制两种形式 | **公有制 = 全民所有制 + 集体所有制，另含混合所有制里的国有、集体成分。** |
| 6 | 两个毫不动摇 | **毫不动摇巩固发展公有制，毫不动摇鼓励支持引导非公有制。** |
| 7 | 民营经济促进法三平等 | **平等使用生产要素、公平参与市场竞争、同等受到法律保护。** |
| 8 | 分配三层次 | **初次靠市场、再分配靠政府、第三次分配靠自愿捐赠。** |
| 9 | 再分配手段 | **税收 + 社会保障 + 转移支付，三样都归再分配。** |
| 10 | 按劳分配范围 | **只在公有制经济内部按劳分配，非公企业的工资属按要素分配。** |
| 11 | 参与分配的要素 | **劳动、资本、土地、知识、技术、管理、数据（"数据"是新增）。** |
| 12 | 初次分配新口径 | **多劳者多得、技高者多得、创新者多得。** |
| 13 | 市场与政府的作用 | **市场起决定性作用，政府更好发挥作用（"基础性"已作废）。** |
| 14 | 根本目标与基本标志 | **根本目标是共同富裕，基本标志是公有制为主体。** |
| 15 | 农村土地三权分置 | **所有权归集体、承包权归农户、经营权可流转。** |

## 第 2 章 市场需求、供给与均衡价格

### 块① 需求与供给

| # | 知识点 | 一句话 |
|---|---|---|
| 16 | 需求定义 | **想买 + 买得起，缺一个都不叫需求。** |
| 17 | 需求六因素 | **偏好、收入、自身价、替代价、互补价、预期。** |
| 18 | 自身价格 | **自己涨价自己少卖，这是唯一会造成"点动"的因素。** |
| 19 | 消费者收入 | **正常品同向、低档品反向。** |
| 20 | 替代品价格 | **替代品涨价我也多买，同向。** |
| 21 | 互补品价格 | **互补品涨价我就少买，反向。** |
| 22 | 预期（买方） | **预期涨价，现在抢购，需求增加。** |
| 23 | 需求规律 | **价格越高买得越少，反向变动。** |
| 24 | 需求曲线 | **向右下方倾斜。** |
| 25 | 需求量变动 | **自身价格变了，沿同一条曲线滑动的点动。** |
| 26 | 需求变动 | **非价格因素变了，整条曲线平移的线动。** |
| 27 | 供给定义 | **愿卖 + 能卖，缺一个都不叫供给。** |
| 28 | 供给六因素 | **自身价、成本、技术、相关品价、预期、厂商数。** |
| 29 | 生产成本 | **成本涨供给减，反向。** |
| 30 | 生产技术 | **技术进步，供给增加。** |
| 31 | 相关商品价格 | **替代品涨价，生产者转产走人，本商品供给减少。** |
| 32 | 生产者预期 | **预期涨价就囤货惜售，当前供给减少（与买方方向相反）。** |
| 33 | 供给规律 | **价格越高卖得越多，同向变动。** |
| 34 | 供给曲线 | **向右上方倾斜。** |
| 35 | 供给量变动与供给变动 | **自身价格点动，其他因素线动，规则与需求一致。** |

### 块② 均衡价格与价格管制

| # | 知识点 | 一句话 |
|---|---|---|
| 36 | 均衡价格 | **需求量＝供给量时的价格，市场价围着它转。** |
| 37 | 价格偏离的自我修正 | **高于 P₀ 供大于求就降价，低于 P₀ 供不应求就涨价。** |
| 38 | 最高限价 | **低于 P₀ 的价格，保护买方，结果短缺。** |
| 39 | 保护价格 | **高于 P₀ 的价格，保护卖方，结果过剩。** |
| 40 | 最短缺的后果 | **排队、黑市、配给制。** |
| 41 | 过剩的处理 | **政府收购或限产。** |
| 42 | 最低工资 | **保护价格的典型例子，结果是劳动力过剩即失业增加。** |
| 43 | 管制的共同点 | **把价格钉死在 P₀ 之外，就必然出现缺口。** |

### 块③ 弹性

| # | 知识点 | 一句话 |
|---|---|---|
| 44 | 需求价格弹性 | **价格变动 1%，需求量变动百分之几，＝需求量变动率 ÷ 价格变动率。** |
| 45 | 点弹性与弧弹性 | **价格变动小用点弹性，变动大（如从 A 到 B）用弧弹性。** |
| 46 | 弧弹性分母 | **分母取两点价格、需求量的平均值，不是起点值。** |
| 47 | 五种弹性类型 | **>1 富有、<1 缺乏、=1 单一、=0 完全无弹性、=∞ 完全弹性。** |
| 48 | 弹性与销售收入（最常考） | **>1 降价增收（薄利多销），<1 提价增收，=1 收入不变。** |
| 49 | 薄利多销的前提 | **只在 |Ed|>1 时成立，缺乏弹性的商品降价是自杀。** |
| 50 | 影响需求弹性的因素 | **替代品越多、用途越广、越非必需、时间越长 → 弹性越大。** |
| 51 | 需求交叉弹性 | **正号是替代品，负号是互补品，零是无关商品。** |
| 52 | 需求收入弹性 | **>1 高档品，0~1 必需品，<0 低档品（负号即为低档）。** |
| 53 | 供给价格弹性 | **价格变动 1%，供给量变动百分之几，一般为正。** |
| 54 | 供给弹性的时间规律 | **时间越长供给弹性越大，长期＞短期＞瞬时。** |
| 55 | 供给弹性影响因素 | **时间第一，其次生产周期、库存、要素供给的难易。** |
| 56 | 两类弹性的方向 | **需求价格弹性为负（取绝对值），供给价格弹性为正。** |

## 第 3 章 生产和成本理论

### 块① 生产者的组织形式与企业形成

| # | 知识点 | 一句话 |
|---|---|---|
| 57 | 生产者组织形式 | **个人独资企业、合伙企业、公司制企业，三类。** |
| 58 | 个人独资企业的责任 | **投资人以个人财产对企业债务承担无限责任。** |
| 59 | 合伙企业的责任 | **普通合伙人无限连带，有限合伙人以出资额为限。** |
| 60 | 公司制企业的责任 | **股东以出资额为限承担有限责任，这是它最大的优势。** |
| 61 | 企业形成理论（科斯） | **企业是市场机制的替代，存在目的是节约市场交易费用。** |
| 62 | 企业规模边界 | **企业内部组织成本＝市场交易费用时，规模最优，不是越大越好。** |
| 63 | 生产者的目标 | **利润最大化（教材分析的基本假设）。** |

### 块② 生产函数与产量曲线

| # | 知识点 | 一句话 |
|---|---|---|
| 64 | 生产函数 | **技术水平不变时，要素投入量与所能生产的最大产量之间的关系。** |
| 65 | 短期与长期之分 | **短期至少有一种要素不能变（通常是资本），长期所有要素都可变。** |
| 66 | 边际产量 MP | **每多投入一单位要素所增加的产量，＝ΔQ÷ΔL。** |
| 67 | 平均产量 AP | **总产量除以要素投入量，＝Q÷L。** |
| 68 | 边际报酬递减规律 | **技术不变、其他要素不变，连续增加某要素，MP 先增后减、最终为负。** |
| 69 | MP 与 AP 的关系 | **MP＞AP 时 AP 上升，MP＜AP 时 AP 下降，MP＝AP 时 AP 达到最大。** |
| 70 | MP 与 TP 的关系 | **MP＝0 时 TP 最大，MP＜0 时 TP 开始下降。** |
| 71 | 生产三阶段 | **第一阶段 AP 递增，第二阶段 AP 递减而 MP＞0，第三阶段 MP＜0；理性生产者选第二阶段。** |
| 72 | 规模报酬 | **全部要素同比例增加：产量增得更多＝递增，同比例＝不变，更少＝递减。** |

### 块③ 成本函数

| # | 知识点 | 一句话 |
|---|---|---|
| 73 | 成本两分 | **固定成本 FC 不随产量变（厂房租金），可变成本 VC 随产量变（工资、原料）。** |
| 74 | 总成本 | **TC ＝ FC ＋ VC，短期里 FC 始终不变。** |
| 75 | 平均固定成本 | **AFC＝FC÷Q，唯一一条一路下降的线，因为固定成本总量没少、只是被摊薄。** |
| 76 | 平均可变成本 | **AVC＝VC÷Q，先降后升的 U 形。** |
| 77 | 平均成本 | **AC＝TC÷Q＝AFC＋AVC，U 形，永远在 AVC 上方，差距随产量扩大而缩小。** |
| 78 | 边际成本 | **MC＝ΔTC÷ΔQ，多做一件多花多少，先降后升。** |
| 79 | MC 与两条平均线 | **MC 分别穿过 AVC 和 AC 的最低点（和 MP 穿 AP 同一个道理）。** |
| 80 | 成本的镜像公式 | **MC＝工资÷MP，AVC＝工资÷AP：MP 最大处 MC 最小，AP 最大处 AVC 最小。** |
| 81 | 长期平均成本 | **LAC 是无数条短期 AC 的包络线，先降后升，源于规模经济与规模不经济。** |
| 82 | 两个最低点的位置 | **AC 最低点必定在 AVC 最低点的右边，因为 AC＝AVC＋还在下降的 AFC。** |
