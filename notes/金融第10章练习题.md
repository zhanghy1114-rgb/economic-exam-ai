**单选解析**

1. **B**。国际收支平衡表用**复式记账法**（每笔交易记两笔，**借贷总额始终相等**）。⚓ "有借必有贷，表必平"。
2. **A**。"**收益**"（含投资收益）属**经常账户**，不是资本与金融账户。⚠️ 高频坑：别看到"投资"就划资本账户。
3. **C**。国际储备必须是**货币当局（央行）持有**；商业银行、企业、居民持有的外币**都不算**。
4. **B**。**SDR（特别提款权）**由 **IMF 创设**，可兑换硬通货补充储备。A/C 虽是储备构成，但不是 IMF"创设"的记账单位。
5. **C**。**周期性失衡** = 国际经济周期波动所致。
6. **A**。**三元悖论：三者只能实现两个**。A 是"三个都要"→ **不可能**；B/C/D 都是"三选二"→ 都能实现。
7. **C**。**固定汇率 + 资本自由流动 → 必舍货币政策独立**（利率被迫跟随他国）。典型=中国香港。
8. **A**。**米德冲突**：汇率固定下，内部失衡（失业要扩张）与外部失衡（逆差要紧缩）政策方向相反 → 顾此失彼。⚓ "内外要的方向相反，一把工具摆不平"。
9. **C**。**BP = 国际收支均衡**曲线；IS 管产品、LM 管货币、**BP 管对外**，三市场同时均衡。A/B 张冠李戴、D 说"封闭"错。
10. **C**。资本流动动因=**利差（利率低的国家资金流向利率高的国家）**、汇率预期、投机。A 说反了；B 热钱**冲击**稳定（不是有助于）；D 忽视负面影响。
11. **B**。外资外债管理核心=**控规模、优结构、防风险**（重点防**短期外债**）。A/C/D 均错。
12. **C**。**政策调节**=财政/货币/汇率政策/**国际协调**/直接管制；A/B/D 都是**自动调节**（自发作用）。
13. **C**。储备**过多**会占压资金、增加持有成本（机会成本）。A 错（非越多越好）；B 说反（**规模**管"多少"、**结构**管"搭配"）；D 错（可用于弥补逆差+干预汇市+维持信誉）。

**多选解析**

14. **ABC**。三大账户=**经常账户 + 资本与金融账户 + 误差与遗漏**；D 财政、E 货币账户均不属（编造项）。
15. **ABCD**。国际储备四构成=**金·汇·头·权**（货币性黄金/外汇储备/IMF 储备头寸/SDR）；**E 商业银行持有不算**（必须央行持有）。
16. **ABCDE**。五类原因=**周期·结构·货币·偶发·收入**，全对。
17. **ABCD**。E 错——**外汇储备再多也买不来"三者同时实现"**（这是理论约束，不是钱的问题）。
18. **ABCD**。E 错——米德冲突说明"一把工具不够"，**不是"永远无法内外同时均衡"**（加工具即可破解，如支出转换政策）。

## 易错点自查表（做完扫一眼）

| 考点 | 一句话锚 | 常见坑 |
|---|---|---|
| **复式记账** | 借贷总额**始终相等**，"表一定平衡" | 把"表平衡"≠"收支平衡"混为一谈 |
| **收益归属** | **投资收益 → 经常账户** | 一看"投资"就划资本账户 |
| **国际储备持有者** | 必须**央行（货币当局）持有** | 商业银行/企业外币当成储备 |
| **储备四构成** | **金 · 汇 · 头 · 权**（外汇储备=主体） | 漏 SDR、把商业行资产算进来 |
| **储备管理** | **规模管"多少"、结构管"搭配"** | 两者对调 |
| **失衡四原因** | 周期·结构·货币·偶发（+收入） | 原因与类型错配 |
| **调节手段** | **自动调节**（汇率物价自发）vs **政策调节**（人为出手/国际协调） | 把自发当政策 |
| **三元悖论** | **三选二必舍一**：资本自由流动·固定汇率·货币政策独立 | 以为"储备够多就能三个都要" |
| **典型搭配** | 中国香港=舍货币政策独立｜美国=舍固定汇率｜中国内地=舍资本自由流动 | 三个例子配错 |
| **米德冲突** | **内外失衡要求方向相反 → 一把工具摆不平** | 说成"永远无法兼顾" |
| **丁伯根法则** | **几个目标就要几把工具** | — |
| **BP 曲线** | **BP = 国际收支均衡**（IS 产品 · LM 货币 · BP 对外） | 把 BP 当产品/货币市场 |
| **多选保命** | **勾每项前问"教材真这么写吗？反例是什么"** | 漏选 / 错选 |

## 一句话总纲

> **第10章讲开放经济的三层约束：第一层，账要平——国际收支平衡表用复式记账（借贷总额恒等、表必平衡），三大账户为经常（含收益）、资本与金融、误差与遗漏，失衡原因分周期/结构/货币/偶发/收入五类，可用自动调节或政策调节（财政·货币·汇率·管制·国际协调）治理；第二层，家底要够——国际储备由**货币性黄金·外汇储备（主体）·在IMF的储备头寸·特别提款权**构成，须央行持有，并做规模（多少）与结构（搭配）管理，国际资本流动由利差·汇率预期·投机驱动、有利有弊（热钱最危险），外资外债须控规模优结构防短期风险；第三层，目标要取舍——**三元悖论**指出资本自由流动、固定汇率、货币政策独立三者只能取二（中国香港舍货币独立、美国舍固定汇率、中国内地舍资本自由流动），**米德冲突**则说明汇率固定下内外失衡方向相反时一把工具摆不平，须按**丁伯根法则**配齐工具（支出增减管总需求、支出转换管方向），IS-LM-BP 即用 BP 曲线把对外部门补进三市场均衡框架。**
