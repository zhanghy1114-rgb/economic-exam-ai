**单选解析**

1. **C**。**费雪（现金交易数量说）：MV = PT**。A 是剑桥、B 是凯恩斯、D 是弗里德曼。
2. **B**。**M1 = 流通中现金（M0）+ 单位活期存款**（狭义货币·现实购买力）。C 已含准货币（那是 M2）。
3. **D**。凯恩斯三动机中，**只有投机动机跟利率走（L₂(i)，负相关）**；交易、预防动机跟收入走。⚓ "吃饭花钱看收入，投资留钱看利率。"
4. **A**。**基础货币 = 流通中现金 + 商业银行准备金**（法定 + 超额）。B 是 M1，D 混入财政存款。
5. **C**。**弗里德曼（现代货币数量论）**&#x7528;**恒久性收入**替代当期收入，货币需求函数更稳定。
6. **B**。K = 1 ÷ 10% = **10**；M = B × K = 200 × 10 = **2000 亿元**。
7. **D**。**k = 1/V**，是**持币比例（货币流通速度的倒数）**；费雪看 V（钱在跑）、剑桥看 k（钱在停）。
8. **A**。总存款 = 100 ÷ 20% = 500 万；**派生存款 = 500 − 100 = 400 万**。⚠️ 问"派生存款"要减原始存款；问"存款总额"才是 500。

**⚠️ 第 9 题起为 IS-LM 与通胀通缩（🔥2026 新增区）**

1. **C**。**IS = 产品市场均衡（I = S，投资 = 储蓄）**，向右下倾斜；A 是 LM（货币市场）。
2. **B**。央行放水（公开市场买入债券）→ **货币供给增加 → LM 右移 → 利率↓、收入↑**。⚓ "看主语定曲线（央行→LM / 政府→IS），看松紧定方向（松→右移）。"
3. **A**。钱多（M > L）→ 拿多余的钱**买债券** → **债价↑ → 利率↓ → 持币机会成本降 → 货币需求回升** → 回到 L = M。⚓ "钱多买债、债贵息低"（债价与利率**反向**）。
4. **D**。总需求 > 总供给、货币过多 → **需求拉动型**。⚓ "钱多了（需求）、货贵了（成本）、路子歪了（结构）。"
5. **C**。通缩需**扩张**性政策治理（和治通胀相反）。A 错（通缩**加重**实际债务负担）；B 错（物价持续**下降**）；D 错（通缩时货币购买力**上升**）。

**多选解析**

1. **ABCD**。E 错——**古典数量说（费雪）认为货币需求与利率无关**，把利率引入货币需求的是**凯恩斯**。
2. **ABD**。**准货币 = M2 − M1 = 单位定期存款 + 个人存款 + 其他存款**。C（单位活期）、E（流通中现金）属 **M1**。
3. **ABCD**。E 错——**财政政策动 IS、货币政策动 LM**；扩张性财政使其 **IS 右移（不是 LM）**，结果是利率↑、收入↑。
4. **ABCE**。D 错——需求拉动型通胀应采**紧缩**性政策（把钱收回来），不是扩张。
5. **ABCD**。E 错——通缩时物价下跌、**货币购买力上升**（不是下降）。

## 易错点自查表（做完扫一眼）

| 考点             | 一句话锚                                                       | 常见坑                         |
| -------------- | ---------------------------------------------------------- | --------------------------- |
| **四大需求理论**     | 费雪 MV=PT（交易量）·剑桥 M=kPY（持币比例 k）·凯恩斯 L=f(Y,i)（利率）·弗里德曼（恒久收入） | 把"利率"配给古典；把"恒久收入"配给凯恩斯      |
| **k 与 V**      | **k = 1/V**（一个看停、一个看跑）                                     | 说"k 就是 V"                   |
| **凯恩斯三动机**     | 交易·预防 → **收入(+)**；投机 → **利率(−)**                           | 说"投机动机跟收入正相关"               |
| **货币层次**       | M1 = 现金 + **单位活期**；**准货币 = 单位定期 + 个人存款 + 其他**              | 把"个人活期存款"塞进 M1（个人存款最高只到 M2） |
| **基础货币**       | = **流通中现金 + 商业银行准备金**                                      | 混入单位活期存款 / 财政存款             |
| **货币乘数计算**     | K = 1 ÷ (存款准备金率 + 货币结构比率)；**M = B × K**                    | 四率**上升**→乘数**下降**（"雁过拔毛"）   |
| **派生存款**       | 存款总额 = 原始 ÷ 准备金率；**派生存款 = 总额 − 原始**                        | 问"派生存款"错答存款总额               |
| **IS / LM 归属** | **IS = 产品市场（I=S）·右下斜；LM = 货币市场（L=M）·右上斜**                  | 两者对调                        |
| **曲线移动**       | **央行→LM、政府→IS**；松→右移                                       | 把财政政策说成动 LM；把"实施主体"和"曲线"配错  |
| **移动结果**       | LM 右移→**利率↓**&#x6536;入↑；IS 右移→**利率↑**&#x6536;入↑（收入都涨）      | 混淆利率方向                      |
| **均衡机制**       | 钱多→**买债**→债价↑→**利率↓**（债价与利率反向）                             | 债价与利率同向（第 7 章老坑）            |
| **通胀三类型**      | 需求拉动（钱多）·成本推进（货贵）·结构型（路子歪）                                 | 治理方向配反（需求拉动应**紧缩**）         |
| **通缩**         | 物价持续**跌**、债务负担**变重**、用**扩张**政策治                            | 说"通缩减轻债务""购买力下降"            |
| **多选保命**       | **勾每项前问"教材真这么写吗？反例是什么"**                                   | 漏选 / 错选                     |

## 一句话总纲

> **第9章讲一条链：社会想要多少钱（货币需求：费雪 MV=PT 看交易、剑桥 M=kPY 看持币比例、凯恩斯看收入与利率、弗里德曼看恒久收入）→ 经济体能造多少钱（货币供给：央行投放基础货币=现金+准备金、商业银行放贷创造存款，货币乘数 K=1÷(准备金率+结构比率)、货币供应量 M=B×K）→ 两者相等会怎样（IS-LM：IS 管产品市场 I=S 右下斜、LM 管货币市场 L=M 右上斜，交点同时定出均衡利率与收入；钱多买债、债贵息低）→ 不相等会怎样（供给>需求→通胀：需求拉动/成本推进/结构型，分别用紧缩、收入政策、调结构治理；供给<需求→通缩：物价持续跌、债务负担加重，须用扩张政策治理）。**
