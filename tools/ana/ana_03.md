kp: 第7章·金融工程的分析方法
model: 选非题 · 体系补全（「不包括」）
chain:
- 金融工程的基本分析方法有三：<b>积木分析法</b>、<b>风险中性定价法</b>、<b>状态价格定价法</b>
- 积木分析法：把金融工具像积木一样拆分组合（教材原话"金融工程的核心技术是组合与分解"）
- 风险中性定价法：假设投资者风险中性，用无风险利率贴现期望收益
- 状态价格定价法：为未来每种状态定价，再按状态价格加权求和
fast: ⚡三方法口诀「<b>积、中、状</b>」（积木 / 风险中性 / 状态价格）。先圈「不包括」→ 找不属于这三个的 → <b>利差定价法</b> = C。
traps:
- 先圈「不」字，否则会正向选一个熟悉的方法
- 「利差」是信贷定价里的概念，被借来做干扰项，金融工程里没有这一方法
mother: 母题抽象：<b>凡是"××方法/××理论包括/不包括"的题，先把标准体系背成口诀</b>，再拿选项逐个对号入座，对不上的就是答案。
analysis: <p>金融工程的基本分析方法包括<b>积木分析法</b>（将金融工具分解与组合，构造满足特定需求的金融产品）、<b>风险中性定价法</b>（在风险中性世界中以无风险利率对期望收益贴现）和<b>状态价格定价法</b>（为未来各种可能状态分别定价后加权）。<b>利差定价法</b>不属于金融工程的基本分析方法，故选 C。</p>

### 44
kp: 第7章·零息债券的定价
model: 关系方向判断型（变量 A 与变量 B 的相关性）
chain:
- 零息债券（贴现债券）：期内不付息，到期按面值一次性偿付
- 内在价值 V = F /(1+r)ⁿ，n 为剩余期限（期数）
- n 越大 → 分母越大 → V 越小
- 所以内在价值与剩余期限<b>负相关</b>
fast: ⚡零息债券只有一个公式：<b>V = 面值 ÷ (1+r)ⁿ</b>。期限 n 在<b>分母的指数</b>上，越大值越小 → <b>负相关</b> = A。看到"零息"就画这个公式，图形题立刻解。
traps:
- 误以为"期限越长、累计利息越多、价值越高"—— 零息债券<b>没有票息</b>，只有一次终值
- D「受政策利率影响」是半真半假的干扰：利率确实影响价值，但题目问的是<b>与剩余期限</b>的关系
mother: 母题抽象：<b>一切贴现类估值（零息债券、贴现贷款），现值都与期限负相关、与贴现率负相关</b>。两个方向永远一致：分母上任何东西变大，值都变小。
analysis: <p>零息债券不支付期间利息，到期按面值偿付，其内在价值等于面值按市场利率（贴现率）贴现的现值：V = F/(1+r)ⁿ。剩余期限 n 越长，贴现期数越多，现值越小，因此零息债券的内在价值与剩余期限呈<b>负相关</b>。A 正确。</p>

kp: 第7章·股票内在价值（戈登股利增长模型）
model: 数值计算型（不变增长模型）
chain:
- 不变增长（戈登）模型：V = D₁ /(r − g)，其中 D₁ = D₀ × (1+g)
- D₁ = 2 × (1 + 2%) = 2.04 元
- r − g = 8% − 2% = 6%
- V = 2.04 / 0.06 = <b>34 元</b>
fast: ⚡公式钉死：<b>V = D₀(1+g)/(r−g)</b>。三步：先算分子 2×1.02=2.04，再算分母 8%−2%=6%，最后 2.04÷0.06=<b>34</b> → A。
traps:
- <b>忘了乘 (1+g)</b>：2 ÷ 0.06 = 33.33 → 正好是 C 项，这是本题的头号陷阱
- 用 D₀ 直接除：2 ÷ (0.08−0.02) 是错在把"当期股息"当"下期股息"
mother: 母题抽象：<b>戈登模型三要素</b> —— 分子必须是<b>下一期</b>股利 D₁（=D₀×(1+g)）；分母是<b>超额贴现率</b>(r−g)；适用前提是 g &lt; r（否则公式无意义）。
analysis: <p>不变增长模型（戈登模型）：V = D₁/(r − g)。其中 D₁ = D₀(1+g) = 2 × 1.02 = 2.04 元，r − g = 8% − 2% = 6%，故 V = 2.04 ÷ 6% = <b>34 元</b>。A 正确。</p><p>C（33.33 元）是误用 D₀ 直接计算 2 ÷ 6% 的结果，属典型陷阱；B（100 元）相当于把 2% 当作股息率；D（25 元）为 2 ÷ 8%。</p>

kp: 第7章·资产组合的有效边界
model: 选非题 · 图形性质判断（「错误的是」）
chain:
- 有效边界（有效前沿）：给定风险下期望收益最高、或给定收益下风险最小的组合集合
- 形状：<b>向右上方倾斜</b>（高风险高收益）、<b>向上凸</b>（凸向原点，边际替代递减）
- 有效边界上<b>不存在凹陷</b>（凹陷处意味着同样风险有更高收益的组合，与"有效"矛盾）
- 所以"可能有凹陷"是<b>错误</b>说法
fast: ⚡圈「错误」→ 逐项打勾：向右上倾斜✓、高风险高收益✓、向上凸✓、<b>有凹陷✗</b> → 只勾 ❌ 的那个 = C。有效边界"有效"二字本身就排除了凹陷。
traps:
- 选非题最容易正向作答，务必先圈「错误」
- "向上凸"与"向上凹"的方向描述易混，记住教材原话是<b>向上凸</b>（凸向原点）
mother: 母题抽象：<b>有效边界三性质</b> —— 向右上倾斜、向上凸、无凹陷。凡说"有凹陷/有折返/向下倾斜"必错。同时它体现"高风险高收益"原则。
analysis: <p>多种风险资产组合的有效边界是一条<b>向右上方倾斜</b>、<b>向上凸</b>的曲线，反映"高风险、高收益"的原则；曲线上<b>不可能存在凹陷</b>的部分 —— 若存在凹陷，则该凹陷处的组合在同等风险下可获得更高收益，与"有效"的定义矛盾。因此 C 说法错误，为本题答案。</p>

kp: 第7章·无风险资产与组合的标准差
model: 数值计算型（组合风险线性缩放）
chain:
- 无风险资产的特征：σ_f = <b>0</b>，且与市场组合的相关系数为 0
- 组合标准差 σ_p = w × σ_m（w 为投资于市场组合的比例）
- = 90% × 3% = <b>2.7%</b>
- （本题背景：市场组合标准差为 3%）
fast: ⚡一句话：<b>掺入无风险资产只会线性缩小风险，不会增加风险</b>。σ_p = 市场组合权重 × σ_m = 0.9 × 3% = <b>2.7%</b> → D。看到"无风险资产"先想到它的 σ = 0。
traps:
- 用方差加权（0.9² × 3%）—— 标准差是<b>线性</b>缩放，不是平方
- 把 90% 和 10% 反过来算成 0.1 × 3% = 0.3%（A 项 1.5% / C 项 2% 都是乱凑）
mother: 母题抽象：<b>无风险资产 + 风险资产组合</b>：期望收益 = w·R_m + (1−w)·R_f（线性）；标准差 = w·σ_m（线性）。两式都线性，这是资本市场线（CML）的基础。
analysis: <p>无风险资产的标准差为 0，与市场组合的相关系数也为 0，因此新组合的标准差只来自风险资产部分：σ_p = w_m · σ_m = 90% × 3% = <b>2.7%</b>。D 正确。</p><p>即：把 10% 的资金换成无风险资产，风险按投入风险资产的比例<b>同比例缩小</b>至原来的 90%，这是资本市场线上风险—收益线性替换关系的体现。</p><p>（题干引自案例材料，市场组合标准差为 3%。）</p>

model: 场景识别型（监管动机 → 风险类型）
chain:
- 场景关键词：<b>挤兑</b> + 监管部门 + <b>防止多米诺骨牌效应</b>（连锁倒闭）
- "多米诺骨牌效应" = 一家倒下传染整个银行体系 = <b>系统性风险</b>
- 监管出手正是因为系统性风险具有<b>负外部性</b>，单家机构不会内部化
fast: ⚡抓关键词：<b>「多米诺骨牌 / 传染 / 整个体系」→ 系统性风险</b>。合规、声誉、市场都是<b>单家机构层面</b>的风险，只有系统性风险会让监管担心连锁反应 → C。
traps:
- 挤兑本身像"流动性风险"，但题干问的是监管<b>防控的对象</b>——是传导扩散后的系统性风险
- 声誉风险只是个中环节，不足以解释"多米诺骨牌效应"
mother: 母题抽象：<b>风险层级</b> —— 个体风险(信用/市场/操作/流动性/声誉/合规) ⊂ <b>系统性风险(传染·负外部性·波及整个体系)</b>。凡出现"连锁、传染、体系、多米诺"字样，一律上升到系统性风险。
analysis: <p>单家银行的挤兑若引发公众对其他银行的信心动摇，会沿同业往来、支付清算与公众预期等渠道<b>传染扩散</b>，形成"多米诺骨牌效应"，危及整个金融体系 —— 这正是<b>系统性风险</b>的典型表现。监管部门介入处置，防范的正是系统性风险。C 正确。</p><p>合规风险、声誉风险、市场风险均属<b>机构个体层面</b>的风险，无法解释监管对"连锁反应"的担忧。</p><p>（题干原文有个别缺字，已按语义修复为"进行处置"。）</p>

### 52
kp: 第9章·货币乘数与现金比率
model: 关系方向判断型（变量变动 → 乘数方向）
chain:
- 现金比率（现金漏损率）c = 公众持有的现金 / 存款
- 货币乘数 m = (1 + c) / (r + e + c)，c 同时出现在分子与分母
- 数学关系：m 随 c 上升而<b>下降</b>（分子中 c 的系数小于分母，可证 m 对 c 求导为负）
- 所以现金比率越低 → 货币乘数<b>越大</b>
fast: ⚡直观理解更快：<b>公众少拿现金 → 更多钱留在银行体系内反复派生 → 乘数变大</b>。见"现金比率越低" → 乘数<b>越大</b> = B。不用算，用"钱回到银行里就能多派生"这句常识判断。
traps:
- 被分子分母同时含 c 迷惑，以为关系不确定（C 项）—— 教材明确：现金漏损率与货币乘数<b>负相关</b>
- 把"现金比率"和"存款准备金率"搞混（两者方向一致，都是越高乘数越小）
mother: 母题抽象：<b>货币乘数四变量的方向统一</b> —— r(法定)、e(超额)、c(现金漏损)、t(定期存款比率) <b>任何一个上升，货币乘数都下降</b>。记"分母四兄弟，越高压得越死"。
analysis: <p>现金比率（现金漏损率）c 提高，意味着公众从银行体系抽走的现金增多、可用于派生存款的基础资金减少，货币乘数随之<b>下降</b>；反之，现金比率越低，漏出银行体系的资金越少，存款派生能力越强，货币乘数<b>越大</b>。B 正确。</p><p>货币乘数 m = (1+c)/(r+e+c)，对 c 求导为负，故二者呈反向关系。</p>

fast: ⚡配对表一句话：<b>「交易、预防看收入；投机看利率，利率越低需求越大」</b>。见"市场利率越低 + 投机" → D。三个动机别串，一秒钟定位。
traps:
- 把三种动机的影响因素互相串（最高频错误）
- C 项把"收入水平越低"说成需求越大 —— 方向反了
mother: 母题抽象：<b>凯恩斯三动机配对表</b> —— 交易动机(收入·正)｜预防动机(收入·正)｜投机动机(利率·负)。凡"利率"出现，只能配投机；凡"收入"出现，配交易或预防。
analysis: <p>凯恩斯认为，交易动机与预防动机的货币需求主要取决于<b>收入水平</b>（收入越高，交易与备用需求越大），与利率关系不密切；投机动机的货币需求取决于<b>利率水平</b>，且与利率<b>负相关</b> —— 市场利率越低，人们越倾向持有货币以待债券价格回升，投机性货币需求越大。D 正确。</p><p>A、B 把利率作为交易/预防动机的决定因素，错误；C 把收入与交易需求的方向说反。</p>
