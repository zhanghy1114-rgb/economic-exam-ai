kp: 第7章·资产组合 β 的计算与应用
model: 多选 · 计算反推型（给约束条件 → 反推不可选的资产）
chain:
- 目标：组合波动<b>小于</b>市场 → 组合 β &lt; 1（市场组合 β = 1）
- 等权持有两种资产：β_p = 0.5·β₁ + 0.5·β₂ = (β₁ + β₂)/2
- 要求 (β₁ + β₂)/2 &lt; 1 → <b>β₁ + β₂ &lt; 2</b>
- 逐项试：能与某个其他资产配对使和 &lt; 2 的<b>可能入选</b>；怎么配都 ≥ 2 的<b>不可能入选</b>
- 1.5：最小搭配 0.7 → 2.2 ≥ 2 → <b>不可能</b>；1.3：最小搭配 0.7 → 2.0，不小于 2 → <b>不可能</b>；1.1 + 0.7 = 1.8 ✓；0.8、0.7 均可
fast: ⚡先把目标翻译成一个不等式：<b>β₁ + β₂ &lt; 2</b>。然后对每个选项问"它能找到搭档吗" —— 用<b>最小</b>的 β(0.7) 去配：1.5+0.7=2.2✗、1.3+0.7=2.0✗（要严格小于）、1.1+0.7=1.8✓ → 不可能入选的是 <b>B、D</b>。
traps:
- 边界陷阱：1.3 + 0.7 = 2.0，组合 β = 1.0，是<b>等于</b>市场波动，"小于"不满足 → 必须排除
- 问的是"不可能被选入"，别正向去选能入选的
mother: 母题抽象：<b>β 的三条性质</b> —— ①β 是<b>可加权平均</b>的（组合 β = Σwᵢβᵢ）；②β=1 与市场同步、&lt;1 波动小于市场、&gt;1 波动大于市场；③β 衡量<b>系统性风险</b>，可通过资产配置调节。凡"组合波动小于市场"的题，一律写成 β_p &lt; 1 的不等式来解。
analysis: <p>市场组合的 β = 1。要使组合波动小于市场，需 β_p &lt; 1。等权配置两种资产时 β_p = (β₁ + β₂)/2，故要求 <b>β₁ + β₂ &lt; 2</b>。</p><p>逐项检验：β = 1.5（B）即使与最小的 0.7 搭配，1.5 + 0.7 = 2.2 &gt; 2，无法入选；β = 1.3（D）与 0.7 搭配得 2.0，β_p = 1.0，<b>等于</b>市场波动、不满足"小于"，也无法入选。而 1.1 + 0.7 = 1.8 &lt; 2、0.8 与 0.7 均有可行搭配。</p><p>故不可能被选入的 β 值为 <b>B、D</b>。</p>

kp: 第9章·紧缩性货币政策工具
model: 多选 · 操作方向型（降通胀 → 哪些操作）
chain:
- 目标：降低通胀 → 需要<b>紧缩</b>（减少货币供给、抬高利率）
- A 降低再贴现率、再贷款率 → 放松 → <b>不选</b>
- B 公开市场<b>出售</b>政府债券 → 回笼货币 → <b>选</b>
- C 提高法定存款准备金率 → 冻结更多资金 → <b>选</b>
- D 提高利率水平 → 抑制需求 → <b>选</b>
- E 公开市场<b>购买</b>政府债券 → 投放货币 → <b>不选</b>
fast: ⚡先定方向：<b>降通胀 = 收紧</b>。再判每条操作是"放钱"还是"收钱"：卖券(收)✓、提准(收)✓、加息(收)✓；降贴现率(放)✗、买券(放)✗ → BCD。
traps:
- 公开市场方向最易记反：<b>央行买券 = 放钱（宽松）；央行卖券 = 收钱（紧缩）</b>。记法：央行"买"东西，钱就出去了
- A、E 都是宽松操作，方向完全相反
mother: 母题抽象：<b>三大法宝的松紧对照</b> —— 降准/降贴现率/买券 = 宽松（放钱）；提准/提贴现率/卖券 = 紧缩（收钱）。<b>凡是"降××、买××"都是宽松，"提××、卖××"都是紧缩。</b>
analysis: <p>中央银行要降低通货膨胀率，需采取<b>紧缩性</b>操作以减少货币供给、抑制总需求：在公开市场<b>出售</b>政府债券回笼基础货币（B 正确）、<b>提高</b>法定存款准备金率以降低货币乘数（C 正确）、<b>提高</b>利率水平以抑制投资与消费需求（D 正确）。故选 <b>BCD</b>。</p><p>A 降低再贴现率与再贷款率属宽松操作；E 在公开市场<b>购买</b>政府债券会投放基础货币，同样属宽松操作，均与目标相反。</p>

kp: 第9章·货币乘数的影响因素
model: 多选 · 关系判断型（正确的有）
chain:
- 货币乘数 m = (1 + c)/(r + e + c)，决定于 r(法定)、e(超额)、c(现金漏损)
- A 货币乘数越高，货币供给量越小？货币供给 = 基础货币 × 乘数，乘数越高供给越<b>大</b> → <b>不选</b>
- B 与现金漏损率负相关 → <b>选</b>
- C 与超额存款准备金率负相关 → <b>选</b>
- D 与法定存款准备金率负相关 → <b>选</b>
- E 与存贷款<b>基准利率</b>正相关？基准利率不在乘数公式中（它通过影响行为间接起作用，不是直接变量）→ <b>不选</b>
fast: ⚡记公式里的三个字母就行：<b>r、e、c 都在分母上 —— 谁升，乘数就降；三者全是负相关</b> → BCD。A 把方向说反、E 引入公式外的变量，都排除。
traps:
- A 极易误选：把"乘数高"错想成"供给小"，实际供给 = 基础货币 × 乘数，是<b>正</b>相关
- E 的基准利率确实会影响银行与公众行为，但<b>不是乘数的直接变量</b>
mother: 母题抽象：<b>货币乘数公式 = 一切乘数题的总钥匙</b>：m = (1+c)/(r+e+c)。<b>分子分母同时出现的 c，方向由求导决定（负相关）。</b>凡问"与××的关系"，先查它是不是 r/e/c。
analysis: <p>货币供给 = 基础货币 × 货币乘数，因此<b>乘数越高，货币供给量越大</b>（A 错误）。货币乘数 m = (1 + c)/(r + e + c)，其中 r 为法定存款准备金率、e 为超额存款准备金率、c 为现金漏损率，三者上升都会使分母扩大、乘数变小，故<b>货币乘数与现金漏损率、超额存款准备金率、法定存款准备金率均呈负相关</b>（B、C、D 正确）。故选 <b>BCD</b>。</p><p>E 错误：存贷款基准利率不直接出现在货币乘数公式中，不是货币乘数的直接决定变量。</p>

kp: 第10章·外债的构成
model: 多选 · 范围判断型（哪些算外债）
chain:
- 外债的核心特征：<b>需偿还</b>的对外负债（与"投资"相对）
- A 国际金融组织的贷款 → <b>选</b>（需还本付息）
- B 外商对华<b>直接投资</b> → 是股权投资，<b>不需偿还</b>，不构成外债 → <b>不选</b>
- C 发行的外币债券 → <b>选</b>
- D 外国企业的贷款 → <b>选</b>
- E 外国金融机构的贷款 → <b>选</b>
fast: ⚡外债判据一句话：<b>「要不要还？」</b> —— 贷款、债券是要还的 ✓（ACDE）；直接投资是"入股"，不形成债务 ✗（B）。这是本题唯一的判断开关。
traps:
- 外商投资（FDI）与外债常被并列提及，容易混淆 —— <b>FDI 不计入外债</b>，因为它没有还本付息义务
- 外国企业与外国金融机构的贷款都算外债，别漏选
mother: 母题抽象：<b>外债 vs 外资的界线</b> —— 外债 = 契约性偿还义务（贷款、债券、贸易信贷、延期付款）；非外债 = 股权类（FDI、证券投资中的股票）。<b>判据永远是"有没有还本付息义务"。</b>
analysis: <p>按国家外汇管理局规定，我国外债包括国际金融组织贷款（A）、境外发行外币债券（C）、外国企业贷款（D）、外国金融机构贷款（E）等<b>具有契约性偿还义务</b>的对外负债。故选 <b>ACDE</b>。</p><p>B 外商对华<b>直接投资</b>属股权投资，投资者按出资比例享有收益并承担风险，<b>无还本付息义务</b>，不计入外债。</p>

mother: 母题抽象：<b>国际收支表两大账户</b> —— 经常账户(货物+服务+初次收入+二次收入)；资本与金融账户(资本转移/非生产非金融资产交易 + 直接投资/证券投资/其他投资/储备资产)。<b>凡"买地、买专利、债务减免"归资本账户。</b>
analysis: <p>国际收支平衡表中的经常账户反映居民与非居民之间<b>实际资源</b>的流量，包括<b>货物</b>（C）、<b>服务</b>（D）、<b>初次收入</b>（E，雇员报酬与投资收益等）和<b>二次收入</b>（B，即经常转移）。故选 <b>BCDE</b>。</p><p>A 出售土地属于<b>非生产非金融资产</b>的交易，记入<b>资本账户</b>，不属于经常账户。</p>

### 102
kp: 第11章·宽松货币政策的操作
model: 多选 · 操作方向型（宽松 → 哪些操作）
chain:
- 目标：宽松 → 增加货币供给、降低利率
- A 降低再贴现率 → 融资成本下降、鼓励向央行借款 → <b>选</b>
- B 减少货币发行 → 收缩 → <b>不选</b>
- C 降低准备金率 → 提高乘数、释放流动性 → <b>选</b>
- D 压缩再贷款额 → 收缩 → <b>不选</b>
- E 购买有价证券 → 公开市场投放基础货币 → <b>选</b>
fast: ⚡先定方向：<b>宽松 = 放钱</b>。再判每条：降贴现率(放)✓、降准(放)✓、买券(放)✓；减少发行(收)✗、压缩再贷款(收)✗ → ACE。用"放钱/收钱"二分法，10 秒做完。
traps:
- 公开市场方向：<b>买券 = 放钱</b>（宽松），别记反
- "减少货币发行""压缩再贷款"字面上带"减少/压缩"，都是收紧，方向明确
mother: 母题抽象：<b>松紧二分总表</b> —— 宽松：降准、降贴现率/再贷款利率、买券、增加再贷款、放松窗口指导；紧缩：反之。<b>凡是"降××、买××、增××"→ 宽松；"提××、卖××、压××"→ 紧缩。</b>
analysis: <p>宽松货币政策旨在增加货币供给、降低融资成本，其操作包括：<b>降低再贴现率</b>（A，降低商业银行向央行融资的成本）、<b>降低法定存款准备金率</b>（C，提高货币乘数、释放可贷资金）、在公开市场<b>购买有价证券</b>（E，投放基础货币）。故选 <b>ACE</b>。</p><p>B 减少货币发行、D 压缩再贷款额均会减少货币供给，属<b>紧缩性</b>操作。</p>

### 103
kp: 第11章·一般性货币政策工具（三大法宝）
model: 多选 · 体系补全型
chain:
- 一般性货币政策工具的"三大法宝"：<b>存款准备金政策</b>(A)、<b>再贴现政策</b>(E)、<b>公开市场操作</b>(D)
- B 再贷款政策 → 属央行其他工具，不在"三大法宝"之列 → <b>不选</b>
- C 窗口指导 → 属<b>间接信用指导</b>（选择性/其他工具）→ <b>不选</b>
fast: ⚡三大法宝就三个词：<b>准备金、再贴现、公开市场</b> → ADE。凡是"再贷款、窗口指导、道义劝告、利率政策"都不在三大法宝里（它们属于其他或选择性工具）。
traps:
- 再贷款（B）与再贴现（E）都带"再"字，极易混淆 —— <b>三大法宝里的是再贴现</b>
- 窗口指导（C）名气很大，但它属于<b>间接信用指导</b>，不在一般性工具三件套内
mother: 母题抽象：<b>货币政策工具四层</b> —— ①一般性(准备金/再贴现/公开市场) ②选择性(消费信用/证券信用/优惠利率) ③直接信用控制(信用配额/利率限制/流动性比率) ④间接信用指导(道义劝告/窗口指导)。<b>问"三大法宝"只答第①层的三个。</b>
analysis: <p>中央银行一般性货币政策的"三大法宝"是<b>存款准备金政策</b>（A）、<b>公开市场操作</b>（D）和<b>再贴现政策</b>（E），三者通过调节货币总量发挥作用。故选 <b>ADE</b>。</p><p>B 再贷款政策属于中央银行的其他货币政策工具；C 窗口指导属于<b>间接信用指导</b>，二者均不在"三大法宝"之列。</p>

### 105
kp: 第12章·金融危机的危害
model: 多选 · 后果判断型（哪些属于危害）
chain:
- A 降低货币政策效率、增加实施难度 → <b>选</b>（危机中利率传导失灵、"流动性陷阱"使政策失效）
- B 抑制经济复苏、打击经济增长 → <b>选</b>
- C 信用过度扩张、企业信用过分紧缩 → 这是危机的<b>成因与表现</b>，不是"危害"的规范表述 → <b>不选</b>
- D 中央银行财政负担加重、<b>地方政府财政大量盈余</b>？后半句明显与危机现实相反（危机中财政是赤字/紧张） → <b>不选</b>
- E 使金融机构陷入经营困境 → <b>选</b>
fast: ⚡排除法最快：<b>凡是半句对半句错的（C、D）直接划掉</b> —— D 的"地方政府财政大量盈余"在危机中根本不可能出现。剩下危害层面清晰的三条 → ABE。
traps:
- C 描述的是危机的形成过程（信用扩张→紧缩），不是危害 —— <b>成因/表现 ≠ 危害</b>
- D 后半句"大量盈余"与常识相反，属<b>方向反转</b>型干扰
mother: 母题抽象：<b>"危害"题的排除三原则</b> —— ①属于成因的不选（C）②半真半假的不选（D）③不属于该主体影响范围的不选。剩下的即为危害：政策失灵（A）、实体经济受损（B）、机构困境（E）。
analysis: <p>金融危机的主要危害包括：使<b>货币政策效率降低、实施难度增加</b>（A，如利率传导机制失灵、陷入流动性陷阱）；<b>抑制经济复苏、打击经济增长</b>（B，信贷萎缩、需求下滑）；<b>使金融机构陷入经营困境</b>（E，资产质量恶化、流动性枯竭甚至倒闭）。故选 <b>ABE</b>。</p><p>C 描述的是危机形成过程中的信用扩张与紧缩，属成因与表现，并非危害的规范表述；D 中"中央银行财政负担加重"表述不当，且"地方政府财政大量盈余"与危机时期财政普遍紧张的现实相反。</p>
