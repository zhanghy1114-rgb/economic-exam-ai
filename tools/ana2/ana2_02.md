# 第二套解析 · 批2（单选 21-40）

### 21
kp: 第3章·商业银行市场营销
ask: 概念定位题 —— 服务营销的中心
chain: 银行产品高度同质化、可复制 → 差异化只能靠服务和客户关系 → 市场营销中心是<b>客户</b>（以客户需求为导向）
fast: ⚡「银行服务营销中心」→ 锁「客户」；「服务/产品/利润」都是围绕客户的派生要素
traps:
- 「服务」是银行营销的表现形式（题干已说"表现为服务营销"），不是中心
- 「利润」是结果不是中心
mother: 母题抽象：<b>营销中心的演进</b>——产品中心 → 销售中心 → 客户中心（4P → 4C），金融业因同质化直接进入客户中心阶段。
analysis: <p>商业银行市场营销主要表现为服务营销，其营销中心是<b>客户</b>——银行产品同质化程度高，竞争的本质是争夺和维护客户，营销活动围绕客户需求展开。故选 D。</p>

### 22
kp: 第3章·商业银行成本管理
ask: 归类题 —— 固定资产折旧的支出性质
chain: 商业银行成本（费用）分为：利息支出、工资性支出、<b>补偿性支出</b>（折旧）、税费支出、其他 → 折旧是对固定资产损耗的补偿 → 补偿性支出
fast: ⚡「折旧」在银行成本分类里 = 补偿性支出，四选一直接锁
traps:
- 「营业外支出」是会计利润表概念（与经营无关的损失），不是成本管理分类
- 折旧不是利息支出（那是付给储户的）
mother: 母题抽象：<b>银行成本五分类</b>——利息｜工资｜补偿（折旧）｜税费｜其他。考法就是"某项 → 归哪类"。
analysis: <p>在商业银行成本管理中，固定资产折旧是对固定资产价值损耗的补偿，属于<b>补偿性支出</b>。故选 B。</p>

### 23
kp: 第3章·商业银行理财业务（投资者适当性）
ask: 规范做法题 —— 卖理财的正确姿势
chain: 资管新规打破刚性兑付 → 不得承诺保本保收益 → 销售须「卖者尽责、买者自负」→ 正确做法 = 充分揭示风险
fast: ⚡见「保本 / 预期收益率宣传」都是错，锁「充分提示风险」
traps:
- A「宣传预期收益率」：误导性宣传，资管新规后用"业绩比较基准"
- B/C 任何"保本"字眼都违反打破刚兑精神
mother: 母题抽象：<b>理财销售三禁一须</b>——禁承诺保本、禁承诺收益、禁误导宣传；须充分揭示风险、评估风险承受能力。
analysis: <p>商业银行销售理财产品应遵循风险匹配原则，<b>向投资者充分提示风险</b>，不得承诺保本保收益。故选 D。</p>

### 24
kp: 第3章·商业银行负债业务
ask: 来源判断题 —— 负债资金的主要来源
chain: 商业银行负债 = 存款（被动负债，占比最大）+ 借入负债（同业拆借、向央行借款、回购）→ 「主要」来源 = 存款
fast: ⚡「主要来源」→ 存款；同业拆借/央行借款是补充性、短期性来源
traps:
- B/D 都是借入负债，是"主动负债"工具，量级远小于存款
- A「贷款」是资产运用不是资金来源
mother: 母题抽象：<b>银行负债两大块</b>——存款（主）＋借入款（辅：拆借、央行借款、回购、发行债券）。
analysis: <p>商业银行负债资金的最主要来源是<b>存款</b>（含企业存款、储蓄存款等），同业拆借、向央行借款等借入负债只是补充。故选 C。</p>

### 25
kp: 第3章·商业银行经营制度
ask: 制度归属题 —— 我国商业银行的业务经营制度
chain: 银行制度类型：单一银行制（美国历史）、分支银行制（组织形态）、综合性银行制（全能银行，欧陆）、分业经营制 → 我国《商业银行法》确立<b>分业经营</b>（银行业、证券业、保险业分立）
fast: ⚡我国 = 分业经营；德国 = 综合性（全能）；美国历史上 = 单一银行制
traps:
- C「分支银行制」是我国银行的<b>组织形式</b>（总分行制），但题干问"业务经营制度"
- 综合化经营是近年趋势（子公司试点），但制度基础仍是分业
mother: 母题抽象：<b>经营制度 vs 组织制度两维度</b>——业务维度：分业/综合；组织维度：单一/分支/持股公司。我国：分业经营 + 分支银行制。
analysis: <p>《商业银行法》规定商业银行不得在境内从事证券经营等业务，我国商业银行实行<b>分业经营银行制度</b>（银证保分业经营、分业管理）。故选 D。</p>

### 26
kp: 第3章·商业银行资本管理（资本扣减项）
ask: 归类题 —— 资本充足率计算中的扣减项
chain: 计算资本充足率：资本净额 = 总资本 − 扣减项 → 扣减项包括商誉、其他无形资产、非自用不动产等 → 商誉从资本中<b>全额扣除</b>
fast: ⚡扣减项口诀「商誉 + 无形资产 + 递延税净额」—— A/D 是资本项、C 是无形资产（部分扣），商誉必扣
traps:
- A「一般风险准备」、D「超额贷款损失准备」是资本的组成部分（可计入），方向完全相反
- C「土地使用权」属于无形资产，需扣除的是超额部分，但最标准答案是商誉
mother: 母题抽象：<b>资本的"进与出"</b>——进：实收资本、资本公积、盈余公积、一般风险准备、超额贷款损失准备；出（扣减）：商誉、其他无形资产、递延所得税净负债。
analysis: <p>商业银行计算资本充足率时，应从资本中扣除的项目包括<b>商誉</b>、其他无形资产（土地使用权除外部分）等；而一般风险准备、超额贷款损失准备是可计入资本的项目。故选 B。</p>

### 27
kp: 第3章·存款创造（法定准备金率与放贷能力）
ask: 方向判断题 —— 准备金率↓ → 放贷资金？
chain: 法定存款准备金率↓ → 每笔存款需缴存央行的部分↓ → 银行可自由运用（放贷）资金↑ → 放款数额越多
fast: ⚡「准备金率与放贷能力反向」—— 率越低，能贷的越多
traps:
- 别把「准备金率低 = 风险高」混入，题干问的是放贷资金量
mother: 母题抽象：<b>准备金率的杠杆效应</b>——率↓→货币乘数↑→派生存款↑→信用扩张；率↑则反向（紧缩）。
analysis: <p>存款总额一定时，法定存款准备金率越低，须缴存中央银行的准备金越少，商业银行可用于发放贷款的资金<b>越多</b>，存款派生能力越强。故选 A。</p>

### 28
kp: 第3章·存款经营的影响因素
ask: 选非题 —— 不影响存款经营的因素
chain: 影响存款经营的因素：①存款创造的调控（央行货币政策）②支付机制的创新（电子支付改变存款形态）③政府的监管措施 → 「LPR 报价机制」是贷款定价机制，与存款经营无关
fast: ⚡LPR = 贷款端的事，存款经营题直接选 LPR
traps:
- D 原文有排版错字「LPP」，实为 LPR
- 别因「报价机制」字眼联想到利率市场化而误选 A
mother: 母题抽象：<b>"三因素"清单题定位法</b>——教材列点题用排除法：三个在教材清单里、一个在清单外，选清单外的。
analysis: <p>影响商业银行存款经营的因素包括存款创造的调控、支付机制的创新、政府的监管措施。<b>LPR 报价机制是贷款市场报价利率的形成机制</b>，属于贷款定价范畴，不影响存款经营。故选 D。</p>

### 29
kp: 第3章·商业银行金融创新
ask: 选非题 —— 金融创新的错误说法
chain: 金融创新基本原则：合法合规、公平竞争、知识产权保护、成本可算、风险可控、信息充分披露 → 「通过创新实现监管套利」违反创新精神，是错误说法
fast: ⚡见「监管套利」必错 —— 创新是服务实体经济，不是钻监管空子
traps:
- C 有排版错字「遵盾」=「遵循」，本身说法正确
mother: 母题抽象：<b>创新六原则背法</b>——合法合规｜公平竞争｜知识产权｜成本可算｜信息充分｜风险可控；凡"绕开监管/套利"字眼即反例。
analysis: <p>商业银行金融创新应遵循合法合规、公平竞争等原则，不得侵犯他人知识产权；<b>以规避监管为目的的"监管套利"违背金融创新原则</b>。故选 D。</p>

### 30
kp: 第3章·商业银行资本构成
ask: 构成题 —— 总资本三层级
chain: 《商业银行资本管理办法（试行）》：总资本 = 核心一级资本 + 其他一级资本 + <b>二级资本</b> → 对应核心一级/一级/资本充足率三档监管要求
fast: ⚡三级「核心一级、其他一级、二级」—— 见「附属资本」是 1996 年老办法用语、「核心二级」是编造词
traps:
- A「附属资本」：老《商业银行资本充足率管理办法》的表述（核心资本+附属资本），已废
- C「核心二级资本」不存在
mother: 母题抽象：<b>资本金字塔</b>——核心一级（普通股+留存收益）⊂ 一级（+其他一级/永续债/优先股）⊂ 总资本（+二级：二级资本债、超额贷款损失准备）。
analysis: <p>《商业银行资本管理办法（试行）》规定商业银行总资本由<b>核心一级资本、其他一级资本和二级资本</b>组成。故选 D。</p>

### 31
kp: 第3章·商业银行法（经营原则）
ask: 表述辨析题 —— 商业银行"四自"原则
chain: 《商业银行法》：商业银行以安全性、流动性、效益性为经营原则，实行<b>自主经营、自担风险、自负盈亏、自我约束</b>
fast: ⚡四自钉子「经营、风险、盈亏、约束」—— 见「分摊风险/自我开发/自行负责」划掉
traps:
- A/B 用「自主管理」偷换「自主经营」
- 「分摊风险」≠「自担风险」：风险要自己承担，不是摊给别人
mother: 母题抽象：<b>法条"四自"裸背法</b>——每个词都是教材原词，干扰项总有一个字被换，逐词比对。
analysis: <p>《商业银行法》第四条：商业银行以安全性、流动性、效益性为经营原则，实行<b>自主经营、自担风险、自负盈亏、自我约束</b>。故选 D。</p>

### 32
kp: 第3章·商业银行业务运营模式
ask: 职责划分题 —— 新模式下中后台职责
chain: 新型业务运营模式：前台直接面对客户（营销与服务），中后台集中处理（账务处理、稽核监督、合规管理、财务核算、数据运行）→ 「产品营销」是前台职责
fast: ⚡「营销」永远在前台，中后台题选营销为"不包括"
traps:
- 别把「财务核算」当代前台职责 —— 新模式核心就是账务/核算大集中（后台集中作业）
mother: 母题抽象：<b>前中后台分工</b>——前台=营销获客；中台=风险合规；后台=账务核算；新模式 = 中后台集中化、工厂化。
analysis: <p>商业银行新型业务运营模式下，中后台集中承担业务稽核监督、合规管理、财务核算、数据集中处理等职能；<b>产品营销由前台（客户经理等）承担</b>。故选 A。</p>

### 33
kp: 第3章·商业银行资产管理
ask: 范围题 —— 资产管理内容
chain: 资产管理 = 对<b>资产方</b>的管理：贷款管理、债券投资管理、现金资产管理 → 「存款管理」属于负债管理
fast: ⚡资产 vs 负债定位：存款/借款 → 负债；贷款/投资/现金 → 资产
traps:
- 别选「现金资产管理」——现金（准备金）是银行第一线资产
mother: 母题抽象：<b>资产负债表定位法</b>——题干问"资产/负债管理包括啥"，先给选项标资产/负债方向再排除。
analysis: <p>商业银行资产管理主要包括贷款管理、债券投资管理、现金资产管理等内容；<b>存款管理属于负债管理</b>范畴。故选 D。</p>

### 34
kp: 第3章·商业银行市场风险（黄金的归属）
ask: 归类题 —— 黄金价格波动属于哪类风险
chain: 巴塞尔市场风险四要素：利率、汇率、股价、商品价格 → 但我国监管实践中，<b>黄金被视为外汇（汇率）风险</b>的一部分（黄金曾长期按汇率类风险计量）
fast: ⚡我国监管口径钉子：「黄金 → 汇率范畴」；国际口径里商品价格才含黄金，注意题干问"我国商业银行"
traps:
- D「商品范畴」是巴塞尔国际口径的归类，我国教材按汇率处理
- A「利率范畴」：金银与利率无关
mother: 母题抽象：<b>"特殊归类"考点</b>——黄金按汇率、票据贴现按信用+利率、表外按信用等价系数，特殊归类是高频坑。
analysis: <p>在我国商业银行市场风险管理口径中，<b>黄金价格波动被纳入汇率（外汇）风险范畴</b>计量管理——这与巴塞尔框架下"商品价格风险"的国际口径不同，是教材明确的中国化处理。故选 C。</p>

### 35
kp: 第3章·商业银行外汇业务
ask: 目的判断题 —— 参与即期外汇交易的主要目的
chain: 商业银行持有外币资产/负债 → 产生外汇头寸（敞口）→ 参与即期外汇交易的首要目的 = <b>轧平头寸、防范汇率风险</b>
fast: ⚡「银行做外汇交易的目的」→ 稳健口径选「平衡头寸/避险」；「投机」是主动承担风险的词，银行主要目的不选它
traps:
- B「外汇投机」：个别银行可投机，但不是"主要目的"的一般表述
- C「稳定本国货币汇率」是央行的职责，主体错位
mother: 母题抽象：<b>主体-目的配对</b>——央行=稳定汇率｜企业=套期保值｜银行=平衡头寸｜投机者=赚钱。主体错位是高频干扰。
analysis: <p>商业银行参与银行间即期外汇交易的主要目的是<b>平衡自身外汇头寸、防范汇率风险</b>——通过买入超卖部分、卖出超买部分将敞口轧平。故选 A。</p>

### 36
kp: 第3章·商业银行风险管理策略
ask: 策略识别题 —— 留存准备金属哪种策略
chain: 风险管理四大策略：对冲（衍生品反向操作）、转移（保险/担保/转让）、补偿（定价加成）、<b>预防</b>（自留准备金、内部制度防损）→ 持有法定/超额准备金 = 事前自留缓冲 = 风险预防
fast: ⚡「准备金 / 拨备 / 资本缓冲」→ 风险预防；「买保险/担保」→ 转移；「做反向衍生品」→ 对冲
traps:
- B「风险补偿」是事前定价（提高利率覆盖损失），与"持有资产缓冲"不同
- D「风险预防」与「风险自留」的区别：这里强调"以资产形式预留"，教材归为预防策略
mother: 母题抽象：<b>风险策略四分法对号</b>——对冲=反向头寸｜转移=换人承担｜补偿=价格溢价｜预防=自建缓冲（准备金、拨备、内控）。
analysis: <p>商业银行在资产中保持法定存款准备金和超额存款准备金，是事前自留风险缓冲以抵御流动性等风险的安排，属于<b>风险预防</b>策略。故选 D。</p>

### 37
kp: 第3章·信用风险管理（3C 分析法）
ask: 缩写还原题 —— "3C"指什么
chain: 商业银行信用风险过程管理的"3C"：<b>现金流（Cash flow）、管理（Control）、业务连续性（Continuity）</b>——评价借款人经营稳定性的三维度
fast: ⚡教材版 3C = 「现金流、管理、业务连续性」，与MBA版 3C（Character/Capacity/Capital）区分开
traps:
- B 选项「偿还能力、资本和品格」是传统授信 5C 里的要素，混淆经典信用分析 5C 与本题 3C
- C 混搭（担保品属于 5C 的 Collateral）
mother: 母题抽象：<b>信用分析字母缩写全家桶</b>——5C：品格/能力/资本/担保/环境；3C（过程管理）：现金流/管理/连续性。看清题干问哪个。
analysis: <p>商业银行信用风险过程管理中的"3C"分析方法指<b>现金流、管理和业务连续性</b>——从现金流量状况、管理与控制能力、经营持续性三个维度评估借款人信用状况。故选 A。</p>

### 38
kp: 第3章·商业银行负债（短期借款）
ask: 范围题 —— 不属于短期借款的项目
chain: 短期借款：同业拆借、向中央银行借款、证券回购（回购协议）、转贴现 → 「发行普通金融债券」是<b>长期</b>借入负债
fast: ⚡「债券 = 长期，回购/拆借/央行借款 = 短期」—— 发行金融债选"不包括"
traps:
- C 原文有重复错字「向中央银行中央银行借款」=「向中央银行借款」
- 别选「证券回购」——回购以债券作押、期限极短，是典型短期借款
mother: 母题抽象：<b>负债期限谱</b>——隔夜（拆借/回购）→ 数天至数月（转贴现、央行借款）→ 数年（普通金融债、二级资本债）。
analysis: <p>商业银行短期借款主要包括同业拆借、向中央银行借款、证券回购等；<b>发行普通金融债券期限通常在 1 年以上，属于长期借入负债</b>。故选 B。</p>

### 39
kp: 第3章·商业银行法（业务范围）
ask: 选非题 —— 商业银行不能从事的业务
chain: 《商业银行法》43 条：商业银行在境内<b>不得从事证券经营业务</b>（分业经营）→ 结算、结售汇、公司贷款均在经营范围内
fast: ⚡分业经营红线：「证券经营 / 信托 / 不动产」三不碰
traps:
- B「结售汇」：银行外汇业务牌照内可做，不是禁区
- 注意「境内」限定：境外可依当地法从事
mother: 母题抽象：<b>商业银行法三禁令</b>——境内不得从事证券经营、不得向非自用不动产投资、不得向非银行金融机构和企业投资（国家另有规定除外）。
analysis: <p>依据《商业银行法》分业经营规定，商业银行在境内<b>不得从事证券经营业务</b>；结算业务、结售汇业务、公司贷款业务均属其法定经营范围。故选 D。</p>

### 40
kp: 第3章·商业银行资本（核心一级资本构成）
ask: 选非题 —— 不属于核心一级资本的项目
chain: 核心一级资本 = 实收资本/普通股 + 资本公积 + 盈余公积 + 一般风险准备 + 未分配利润 + 累计其他综合收益 + 少数股东资本可计入部分 → 「超额贷款损失准备」计入<b>二级资本</b>
fast: ⚡「超额损失/超额贷款损失准备 → 二级资本」，核心一级全是"股 + 留存收益"类
traps:
- A 是干扰主角：超额准备只进二级资本，核心一级与它无关
- 别把「一般风险准备」（核心一级）与「超额贷款损失准备」（二级）混
mother: 母题抽象：<b>资本三层归属速查</b>——核心一级：股本+公积+利润；其他一级：优先股/永续债；二级：超额贷款损失准备+二级资本工具。
analysis: <p>核心一级资本包括实收资本、资本公积、盈余公积、一般风险准备、未分配利润、累计其他综合收益等；<b>超额贷款损失准备计入二级资本</b>，不属于核心一级资本。故选 A。</p>
