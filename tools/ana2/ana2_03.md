# 第二套解析 · 批3（单选 41-60）

### 41
kp: 第4章·信托财产范围
ask: 选非题 —— 不能作为信托财产的选项
chain: 信托财产须具有<b>可转让性（积极财产）</b>——股权、房产、保险单（现金价值）均可 → 「债务」是消极财产/负债，不能作为信托财产设立信托
fast: ⚡信托装的是「财产权利」，装「债」的叫负债，秒选 C
traps:
- 保险单可以：人身保险单的现金价值可质押、可作信托财产（保险金信托）
- 别把「债权」与「债务」混——债权（应收款）可以信托，债务不行
mother: 母题抽象：<b>信托财产三要件</b>——合法性（委托人合法所有）、可转让性、确定性（可度量）。消极财产（债务）不合格。
analysis: <p>信托财产必须是委托人合法所有的、具有可转让性的积极财产。公司股权、房产、具有现金价值的保险单均可作为信托财产；<b>债务属于消极财产，不能作为信托财产</b>。故选 C。</p>

### 42
kp: 第4章·保险合同主体
ask: 主体识别题 —— 谁是保险人
chain: 保险合同四主体：保险人 = 承保并承担赔偿责任的<b>保险公司</b>；投保人 = 交钱买保险的人（甲）；被保险人 = 受保障的人（丁）；保险代理人（乙）只是中介
fast: ⚡「保险人 = 保险公司」铁律，无论经过几个代理环节
traps:
- 乙是保险代理人（以保险人名义代为办理业务，责任由保险人承担），不是保险人
- 甲是投保人、丁是被保险人，都别选
mother: 母题抽象：<b>保险四方对号入座</b>——交钱的=投保人｜被保的=被保险人｜赔钱的=保险人｜跑腿的=代理人/经纪人。
analysis: <p>保险人是与投保人订立保险合同，并承担赔偿或给付保险金责任的<b>保险公司</b>。本题中丙保险公司承保，故保险人为丙；乙只是保险代理人。故选 C。</p>

### 43
kp: 第4章·保险理赔（赔偿给付形式）
ask: 形式判断题 —— 保险赔偿给付形式
chain: 保险的职能是经济补偿，理赔的赔偿给付以<b>货币</b>形式为主（财产保险全额货币支付；人身保险给付保险金也是货币）
fast: ⚡「理赔给付」→ 货币，与 Q45 同考点重复印证
traps:
- 「实物给付」：极少数健康险提供医疗服务等实物形态，但"通常/主要"形式是货币
mother: 母题抽象：<b>保险给付形式钉子</b>——赔偿/给付通常为货币；这正体现保险"经济补偿"职能的本质。
analysis: <p>保险事故发生后，保险人的赔偿给付形式通常为<b>货币</b>——通过支付保险金实现经济补偿职能。故选 C。（本卷第 45 题为同一考点的重复考查。）</p>

### 44
kp: 第4章·保险经营（逆向选择）
ask: 机理判断题 —— 逆向选择对谁不利
chain: 信息不对称 → 高风险者更愿意投保（因为他们最需要保障）→ 保险公司承保的风险池劣于预期 → 对保险公司不利；对个人投保人而言能按统一费率获得保障 = 有利
fast: ⚡逆向选择方向钉子：「个人有利、公司不利」→ 选逆向选择；正向选择反之
traps:
- 「正向选择」（低风险者投保）对公司有利
- 别与「道德风险」混：道德风险是投保后行为改变（疏于防范），逆向选择是投保前的信息优势
mother: 母题抽象：<b>保险市场信息不对称两兄弟</b>——事前逆向选择（挑客户失败）、事后道德风险（行为失控）；与银行信贷、二手车市场同源。
analysis: <p>逆向选择源于投保人与保险人之间的信息不对称：高风险个体更倾向投保，导致承保标的整体风险高于平均假设，<b>对个人投保人有利、对保险公司不利</b>。故选 B。</p>

analysis: <p>保险理赔的赔偿给付形式通常为<b>货币</b>（给付保险金），体现保险的经济补偿职能。故选 A。</p>

### 46
kp: 第5章·证券投资基金分类（按资金来源与用途）
ask: 分类识别题 —— 本国募集 + 投资本国
chain: 按资金来源和用途：在岸基金（本国募集 → 投资本国市场）｜离岸基金（一国基金组织在他国发售 → 投资本国或第三国）｜国际基金（国内资本 → 投资国外，如 QDII）→ 本题「本国募集 + 投资本国」= 在岸基金
fast: ⚡「本国→本国」在岸｜「他国发售→本国/第三国」离岸｜「本国资本→国外」国际（QDII）
traps:
- <b>⚠ 答案键校正：</b>本题题库答案键标 C（离岸基金），与教材口径不符。中基协官方定义：「在岸基金是指在本国募集资金并投资于本国证券市场的证券投资基金」，故正确答案为 <b>A（在岸基金）</b>。
mother: 母题抽象：<b>基金地理三分法</b>——两头都在国内=在岸；发售在国外=离岸；钱出国外=国际基金（QDII）。
analysis: <p>根据基金的资金来源和用途，在本国募集资金并投资于本国证券市场的基金是<b>在岸基金</b>；离岸基金是在他国发售份额并将资金投资于本国或第三国市场。依据教材口径本题应选 <b>A</b>（⚠ 原答案键 C 有误，已校正）。</p>

### 47
kp: 第5章·证券公司监管（市场退出监管）
ask: 主体识别题 —— 证券公司退出由谁监管
chain: 《证券公司监督管理条例》第 15 条：证券公司<b>停业、解散或破产</b>，应当经<b>国务院证券监督管理机构</b>批准 → 退出监管主体 = 证监会
fast: ⚡「退出/停业/解散/破产 + 证券公司」→ 国务院证券监督管理机构；「协会」是自律组织无审批权
traps:
- <b>⚠ 答案键校正：</b>题库答案键标 C（中国证券业协会）。协会仅承担自律管理职责，无市场退出审批权；依据《证券公司监督管理条例》，正确答案为 <b>D（国务院证券监督管理机构）</b>。
- A 工商登记机关只办注销登记，不是退出监管主体
mother: 母题抽象：<b>证券市场三层管理</b>——证监会（准入/退出/行为监管）｜交易所（一线自律）｜证券业协会（行业自律）。凡涉"许可/批准/退出"必归证监会。
analysis: <p>依据《证券公司监督管理条例》，证券公司停业、解散或破产（市场退出）须经<b>国务院证券监督管理机构</b>批准并由其实施监管。本题应选 <b>D</b>（⚠ 原答案键 C 有误，已校正）。</p>

### 48
kp: 第5章·基金管理人
ask: 表述辨析题 —— 基金管理人相关规定
chain: 逐项验伪：A 由财务公司总经理担任 ❌（基金管理人由依法设立的基金管理公司担任）；B 基金所有者 ❌（所有者 = 基金份额持有人）；C 管理人可参与基金收益分配 ✅（收取管理费，符合约定时可参与收益分配/业绩报酬）；D「可以由依法成立的基金管理公司担任」——教材表述为「由依法<b>设立</b>的基金管理公司担任」，且是"应当"而非"可以"，措辞失真
fast: ⚡基金四方权利钉子：持有人=所有者｜管理人=经营＋收费｜托管人=保管｜「谁所有」一票否决 B
traps:
- B 是最典型干扰：所有者是持有人，管理人只是受托经营
- D 与 C 的取舍：D 的「可以 + 成立」两处措辞与法条不符
mother: 母题抽象：<b>基金治理四主体权责表</b>——持有人（所有+收益）｜管理人（投资运作+管理费）｜托管人（保管+监督）。
analysis: <p>基金份额持有人是基金的所有者；基金管理人由依法设立的基金管理公司担任，负责基金财产的投资运作，并<b>可以参与基金收益分配</b>（收取管理费及按约定参与业绩分成）。故选 C。</p>

### 49
kp: 第10章·货币可兑换（IMF 协定）
ask: 定义题 —— IMF 语境下的"货币可兑换"
chain: 《国际货币基金协定》第八条款：不得限制经常性国际交易支付与转移、不得实行歧视性货币措施/复汇率、应购回对方持有的经常性交易本币结存 → 成员国接受第八条款义务 = 经常项目可兑换 → IMF 语境的"货币可兑换"主要指<b>经常项目可兑换</b>
fast: ⚡钉子：IMF 协定谈可兑换 = 经常项目；「完全可兑换 = 经常 + 资本」是学术口径，不是协定口径
traps:
- <b>⚠ 答案键校正：</b>题库答案键标 C（货币完全可兑换）。本题为 2020 真题原题，官方答案为<b>经常项目可兑换</b>；教材明确「IMF 对可兑换的要求主要指经常项目可兑换」。本题应选 <b>B</b>。
mother: 母题抽象：<b>可兑换三档</b>——经常项目可兑换（IMF 第八条款）→ 资本项目可兑换 → 完全可兑换（两者叠加）；我国 1996 年 12 月实现经常项目可兑换。
analysis: <p>根据《国际货币基金协定》（第八条款），一国货币可兑换主要是指<b>经常项目可兑换</b>——对经常性国际交易支付和资金转移不得施加限制。本题应选 <b>B</b>（⚠ 原答案键 C 有误，已按真题官方答案与教材口径校正）。</p>

### 50
kp: 第5章·私募资产管理业务（推介渠道限制）
ask: 合规判断题 —— 资管计划可以用的推介渠道
chain: 特定客户资管业务是私募性质 → <b>不得公开宣传</b> → 推介只能向特定对象进行：基金销售机构网站（设置特定对象确认程序）可以；中央广播电台、经济日报、中国证券报均为公开媒体 ❌
fast: ⚡「私募 + 公开媒体」必错；「官网 + 特定对象确认」是唯一合法渠道
traps:
- 别选「中国证券报」——财经专业报 ≠ 特定对象渠道，公开发行的报纸都是公开宣传
mother: 母题抽象：<b>公募 vs 私募推介红线</b>——公募：广告、报纸随便宣传；私募：仅特定对象、设置确认程序，公开媒体一律禁。
analysis: <p>资产管理人推介具体资产管理计划属私募行为，不得向不特定对象公开宣传。可通过设置特定对象确认程序的<b>基金销售机构网站</b>推介；通过报刊、广播等公开媒体宣传均被禁止。故选 A。</p>

### 51
kp: 第5章·证券公司高管任职资格
ask: 范围题 —— 须任职资格核准的人员
chain: 《证券公司监督管理条例》：董事、监事、高级管理人员（含合规负责人、首席风险官、首席财务官等）任职须核准 → 「分支机构部门负责人」不在任职资格核准之列
fast: ⚡「董监高 + 首席××官」要核准；「部门负责人 / 分支机构部门负责人」不要
traps:
- B 是干扰主角：部门负责人属于内部管理岗位，不属高管任职资格范围
mother: 母题抽象：<b>任职资格范围钉子</b>——董、监、高（经理层+合规/风控/财务负责人）须核准；部门经理、营业部总经理以下不需要。
analysis: <p>依据《证券公司监督管理条例》，证券公司的董事、监事、高级管理人员（含首席财务官等）任职须取得任职资格核准；<b>分支机构部门负责人</b>不属于须核准范围。故选 B。</p>

### 52
kp: 第5章·投资银行（证券交易市场中的身份）
ask: 范围题 —— 投行在交易市场的身份
chain: 投行在证券交易市场（二级市场）中的三重身份：<b>证券经纪商</b>（代客买卖）、<b>证券自营商</b>（自营买卖）、<b>证券做市商</b>（双边报价）→ 「证券清算商」不是其身份（清算是登记结算机构的职能）
fast: ⚡二级市场投行三商「经纪 + 自营 + 做市」，出现第四种"商"就划掉
traps:
- A「证券清算商」：清算交收由中国结算等登记结算机构承担，投行只是参与人
- 一级市场身份才是承销商，别混
mother: 母题抽象：<b>投行双市场身份表</b>——发行市场：承销商/保荐人；交易市场：经纪商/自营商/做市商。
analysis: <p>在证券交易市场中，投资银行以<b>证券经纪商、证券自营商、证券做市商</b>三重身份参与交易；证券清算（登记、清算、交收）由专门的登记结算机构承担，不属于投行的市场身份。故选 A。</p>

### 55
kp: 第5章·证券投资基金组织形式
ask: 归类题 —— 公募货币基金的组织形式
chain: 我国公募基金（含货币市场基金）依据《证券投资基金法》以信托原理设立，通过基金合同约束各方 → 属<b>契约型基金</b>（我国公募基金全部为契约型）
fast: ⚡我国公募 = 契约型；公司型是美式（如美国共同基金公司形态）
traps:
- B「公司型基金」：依据公司法设立、持有人是股东——我国公募基金不是
- D「混合类基金」是投资标的分类（固收/权益/混合），维度错位
mother: 母题抽象：<b>组织形式两分法</b>——契约型（信托/合同，我国主流）vs 公司型（法人实体，美国主流）；与开放式/封闭式（运作方式）、公募/私募（募集方式）三个维度别混。
analysis: <p>我国公募货币市场基金依据基金合同设立，基金管理人、托管人与持有人以信托契约连接，属<b>契约型基金</b>。故选 C。</p>

### 56

fast: ⚡数字阶梯「固 30 / 混 40 / 权 100」——风险越高门槛越高
traps:

### 60
kp: 第7章·期权（看涨期权损益）
ask: 判断题 —— 看涨期权买方的正确说法
chain: 逐项验伪：A 买方最大收益是期权费 ❌（那是卖方的最大收益；买方收益理论上无限）；B 市场价格 > 执行价格时行权 ✅；C 买方预期市场<b>上涨</b> ❌；D「最大潜在损失为无穷大」❌（买方最大损失 = 期权费，有限；无穷大是卖方风险）
fast: ⚡看涨期权口诀：「买方损失封顶（期权费）、收益无限；卖方收益封顶、损失无限」→ B
traps:
- D 表述有文字陷阱："可以规避的最大潜在损失为无穷大"——恰恰说反，规避的意思是损失有限
- A 偷换买卖双方角色
mother: 母题抽象：<b>期权四方损益图</b>——看涨买方：付费换无限上行；看涨卖方：收租担无限下行。所有期权题先分买卖双方再判损益。
analysis: <p>看涨期权买方支付期权费获得按执行价格买入的权利：<b>当市场价格高于合约执行价格时行使合约</b>（B 正确）。买方最大损失为期权费（有限）、最大收益理论上无限（A、D 错）；买方预期价格上涨而非下跌（C 错）。故选 B。</p>
