# 第二套解析 · 批5（单选 81-95）

### 81
kp: 第11章·中央银行职能
ask: 职责归属题 —— 管理国际储备属于哪个职能
chain: 央行三大职能：「发行的银行」（垄断货币发行）｜「银行的银行」（最后贷款人、集中准备金、清算）｜「国家的银行」（代理国库、保管外汇和黄金储备、制定执行货币政策）→ 管理国际储备 = 政府的银行（国家的银行）
fast: ⚡「国库、储备、国际往来」→ 国家的银行；「最后贷款人」→ 银行的银行
traps:
- B「银行的银行」盯的是国内金融机构（再贴现、清算），不管国际储备
mother: 母题抽象：<b>央行三职能对号表</b>——发钞=发行的｜最后贷款人/准备金=银行的｜国库/储备/政府往来=国家的。
analysis: <p>作为「国家的银行」，中央银行代理国库、<b>保管和管理国际储备</b>（外汇、黄金）、代表政府参与国际金融活动。故选 C。</p>

### 82
kp: 第10章·国际收支调节政策
ask: 政策功能题 —— 同时调节经常账户与资本账户
chain: 支出增减型政策（财政、货币）：货币政策通过利率影响<b>资本流动（资本账户）</b>，通过总需求/吸收影响<b>贸易收支（经常账户）</b> → 可两头调节；汇率政策（支出转换型）主要作用于经常账户；关税只作用于贸易
fast: ⚡汇率政策标签「主要管经常」；要"经常+资本双管"→ 货币政策（利率管资本、需求管经常）
traps:
- C「汇率政策」是最强干扰：贬值改善经常账户，但对资本账户的作用方向不确定
- D「关税政策」仅贸易层面
mother: 母题抽象：<b>国际收支调节工具箱</b>——支出增减（财政/货币，双账户）｜支出转换（汇率/关税，主经常）｜直接管制（临时）。
analysis: <p>货币政策一方面通过利率变动影响跨境资本流动（资本账户），另一方面通过调节总需求与吸收影响进出口（经常账户），<b>既可调节经常账户又可调节资本账户</b>。故选 B。</p>

### 83
kp: 第10章·内外均衡冲突（米德冲突）
ask: 现象命名题 —— 衰退失业 + 国际收支逆差
chain: 米德冲突：内部均衡（经济增长/充分就业）与外部均衡（国际收支平衡）出现<b>方向不一致</b>的冲突 → 国内衰退失业（需扩张）+ 国际收支逆差（需紧缩）= 典型米德冲突
fast: ⚡「内冷外逆 / 内热外顺」这类组合 → 米德冲突；特里芬难题讲国际货币发行国两难
traps:
- A「特里芬难题」：国际货币供应与信心不可兼得（美元困境）
- C「不可能三角」：汇率稳定、资本流动、货币政策独立三选二
- D「流动性陷阱」：利率极低时货币政策失效
mother: 母题抽象：<b>内外均衡命名四件套</b>——米德冲突（内外目标矛盾）｜丁伯根法则（N 个目标需 N 个工具）｜斯旺模型（支出转换+支出增减搭配）｜蒙代尔搭配（财政管内、货币管外）。
analysis: <p>国内经济衰退、失业严重（内部失衡：需扩张政策）与国际收支逆差（外部失衡：需紧缩政策）同时并存、政策方向矛盾，称为<b>米德冲突</b>。故选 B。</p>

### 84
kp: 第10章·三元悖论（政策组合选择）
ask: 推理题 —— 货币局制度下的政策组合
chain: 三元悖论：汇率稳定、资本自由流动、货币政策独立三者只能取二 → 货币局制锁定了<b>汇率稳定</b> → 在剩余两目标中二选一；阿根廷陷米德冲突、亟需自主政策空间调节内外失衡 → 放弃资本自由流动、<b>保货币政策独立 + 资本管制</b>
fast: ⚡推理链：货币局制→汇率已锁→剩"独立货币 vs 自由资本"二选一→解决米德冲突需要自主政策→选独立+管制
traps:
- D「浮动汇率 + 资本自由流动」是放弃货币局制的组合，与题干"货币局制度下"矛盾
- C「独立 + 自由流动」：与已锁定的汇率稳定构成"三全其美"，违背三元悖论
mother: 母题抽象：<b>三元悖论解题三步</b>——①题干已锁定哪个目标 ②剩余两目标二选一 ③结合情境（是否需要政策自主）定组合。
analysis: <p>货币局制度下汇率稳定已被制度锁定，按三元悖论须在「货币政策独立」与「资本自由流动」之间取舍。阿根廷面临米德冲突、需要自主的政策空间调节内外失衡，故应选择<b>货币政策独立 + 资本管制</b>。故选 B。</p>

### 85

ask: 主体识别题 —— 股权众筹由谁监管
chain: 互联网金融监管分工（十部委《指导意见》）：股权众筹融资 → <b>证监会</b>监管；网络借贷（P2P）→ 银监；互联网支付 → 央行

- B 银保监管"借贷"类互联网业态，股权众筹是股权投资性质
- D 金融委是协调机构，不直接监管具体业务

analysis: <p>依据互联网金融监管分工，股权众筹融资业务具有股权融资属性，由<b>中国证监会</b>负责监管。故选 A。</p>

### 86

ask: 工具作用题 —— 央票互换（CBS）的主要作用
chain: 2019 年 1 月央行创设央行票据互换工具（CBS）：以央行票据换入银行永续债 → 提高<b>银行永续债</b>的市场流动性 → 支持银行发行永续债<b>补充资本</b> → 增强银行信贷投放能力
fast: ⚡CBS 关键词「永续债 + 补充资本」——央行公告原文即此
traps:
- <b>⚠ 答案键校正：</b>题库答案键标 D（加大金融直接支持中小企业力度）。CBS 并不直接投放流动性、不直接支持中小企业，其公告定位是「提高银行永续债的市场流动性，支持银行发行永续债补充资本」，正确答案为 <b>C</b>。
- B「临时流动性需求」是 SLA/SLO 等工具的作用
mother: 母题抽象：<b>央行新型工具"作用卡"</b>——CBS=永续债增流动｜MLF=中期流动性｜SLF=短期应急｜PSL=定向长期（棚改）｜TMU/再贷款=定向信贷。
analysis: <p>央行票据互换（CBS）以央行票据与银行持有的永续债互换，目的是<b>提高银行永续债的市场流动性，支持银行发行永续债补充资本</b>（央行持有的互换票据不可用于交易抵押，且到期换回，不投放基础货币）。本题应选 <b>C</b>（⚠ 原答案键 D 有误，已按央行公告口径校正）。</p>

### 90
kp: 第11章·中央银行业务（资产负债表定位）
ask: 归类题 —— 再贴现属于哪类业务
chain: 央行资产负债表：再贴现 = 央行<b>买入</b>商业银行持有的未到期票据、提供资金 → 体现为央行资产端「对其他存款性公司债权」→ <b>资产业务</b>
fast: ⚡资金流出央行 = 资产业务（再贴现、再贷款、买卖外汇/国债）；资金流入 = 负债业务（存款准备金、发行央行票据）
traps:
- B「负债业务」：准备金、央行票据发行才是负债端
- A「中间业务」：商业银行语境的概念，央行清算服务可算，但再贴现不是
mother: 母题抽象：<b>央行资产负债定位法</b>——央行出钱的都是资产：再贷款、再贴现、公开市场买入；央行收钱/欠别人的都是负债：准备金、央票。
analysis: <p>再贴现是中央银行对商业银行贴现的未到期票据提供资金融通，形成央行对存款机构的债权，属于中央银行的<b>资产业务</b>。故选 D。</p>

### 92
kp: 第11章·货币政策目标
ask: 判断题 —— 货币政策目标的正确说法
chain: 逐项验伪：A「同时实现低通胀与低失业」❌（菲利普斯曲线揭示二者短期权衡）；B《人民银行法》：货币政策目标是<b>保持货币币值稳定，并以此促进经济增长</b> ✅；C 物价与国际收支的矛盾≠菲利普斯曲线 ❌；D 物价稳定时国际收支未必平衡 ❌
fast: ⚡我国目标钉子「币值稳定 → 以此促进增长」——单一目标加促进式表述
traps:
- C 偷换矛盾对：菲利普斯曲线 = 物价（通胀）与<b>失业/产出</b>的矛盾，不是国际收支
- D 用"一定"绝对化——内外均衡并无必然联动
mother: 母题抽象：<b>目标间四大矛盾</b>——通胀↔失业（菲利普斯）｜物价↔国际收支｜增长↔物价｜币值对内↔对外稳定。搭配命名要精确。
analysis: <p>《中国人民银行法》规定：货币政策目标是<b>保持货币币值的稳定，并以此促进经济增长</b>。A 违背菲利普斯曲线权衡；C 对矛盾对象张冠李戴；D 过于绝对。故选 B。</p>

### 94
kp: 第11章·再贷款
ask: 选非题 —— 再贷款的错误说法
chain: 逐项验伪：A「近些年再贷款占基础货币投放比重逐渐增加」❌——教材口径：随着外汇占款变化与公开市场操作发展，再贷款占基础货币投放的比重总体<b>下降</b>；B PSL 是抵押补充贷款、可视为再贷款的延伸形式 ✅；C 新增再贷款主要用于促进信贷结构调整（支农支小、定向）✅；D 再贷款利率按期限事先确定、发放后保持不变 ✅
fast: ⚡教材表述题：A 的"逐渐增加"与教材"比重下降"相抵，秒选 A
traps:
- 直觉上"近年央行大量用 MLF/PSL/再贷款 → 比重增加"容易误判——注意题干问"说法错误"，且教材表述以"下降"为准
mother: 母题抽象：<b>再贷款考点四句</b>——比重总体下降｜PSL 视作再贷款延伸｜新增定向调结构｜利率发放后不变。
analysis: <p>关于再贷款：PSL 可视为再贷款的一种形式、新增再贷款主要用于促进信贷结构调整、再贷款利率在发放后保持不变，说法均正确；教材口径下再贷款占基础货币投放的比重总体<b>下降</b>而非"逐渐增加"。故选 A。</p>

### 95
